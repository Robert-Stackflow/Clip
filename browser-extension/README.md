# Clip 图片拖放扩展

普通图片和浏览器提供的图片文件可以直接拖入 Clip。只有浏览器内可访问的登录图片、Blob 图片，以及需要页面登录状态的原图，可以通过这个配套扩展拖入。

1. 在 Edge 打开 `edge://extensions`，启用“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择这个 `browser-extension` 文件夹。
3. 打开图片所在页面，点击扩展图标，图标显示 `ON` 后，将鼠标移到图片上，再拖入 Clip。

刷新或切换页面后需要重新点击扩展。扩展只在你点击后启用当前页面，不读取 Cookie，不上传图片，不需要网站的永久访问权限。登录状态保留在浏览器中；拖放时将图片内容交给 Clip。

支持页面内的 Blob 图片、登录图片、`data-original` 原图地址和高分辨率 `srcset`，并识别 CloudChewie 的原图地址。预取尚未完成时会尝试获取当前已显示的像素或图片地址；被网站限制读取、尚未加载、超过大小限制的图片仍可能失败，此时可以下载原图后拖入。

扩展文件与 Clip 接收端配套使用，无需启动本地服务器。
