# Clipper 0.19 验收

2026-10-01。Windows x64 目录包，未签名。新增托盘最近记录和预览，继续参考 OneClip 公开功能与本地 One。此版本不代表全部功能对齐或真实应用兼容性已完成。

## 本次交付

- 左键托盘图标打开最近 80 项；右键保留系统控制菜单。全文、来源、标签、文件名、类型、收藏与自定义分类筛选。
- 悬停与方向键预览正文、原图、文件/目录名称，左键或 Enter 复制，右键或 Ctrl+Enter 返回原窗口粘贴，Esc 收起。
- 图片和文件/已保存目录原生拖出；浅深主题、工作区内定位、窄屏上下布局。
- 专用窗口、预加载和 IPC；短时令牌绑定查询、内容哈希和会话，窗口关闭/记录变化后失效。预览不读取原磁盘文件，不生成附件缓存，不执行 HTML。
- Windows 原生前台状态补充失焦事件；模拟休眠恢复、加密锁定、迁移关闭面板并撤销旧操作。schema/备份 6、同步 4 不变。

## 证据

最终发布回归进行中；发布前填写结果及哈希。

最终候选包通过真实托盘入口专项：系统可访问性定位可见的 Windows 隐藏图标按钮，原生鼠标展开后重新定位 Clipper 图标并点击；面板稳定显示，右键记录后原接收窗口得到完整文字。具体 Windows 隐藏图标区布局已验证，其他布局仍待补充。

开发态 tray-ui、tray-boundaries、tray-drag 通过；tray-native 在最终候选包通过。原生拖放从面板进入独立进程的本地 HTTP 接收页，逐字节核对图片、目录中的文件，并核对空目录及只提供根路径。接收页为测试工具，不会向外部站点传输内容。

## 问题与处理

- Windows 前台已切回接收应用时，Electron 的 isFocused/blur 曾仍保留旧状态。复现后加入原生前台窗口核对，连续三次失焦收起（间隔 150ms），菜单等所属窗口视为同一面板。确认后的粘贴/拖出期间不会被自己的焦点切换取消。
- 测试导入备份会重建记录编号，初版测试仍查询导入前编号，等待后由清理步骤关闭面板。改为按内容哈希查找导入后的编号。
- 空剪贴板可能返回没有 MIME 类型的条目，测试接收工具曾因此启动失败；现在跳过空条目，仍保留并恢复可读取的原始格式。
- 键盘复制/关闭可能在 Playwright 的释放按键响应前销毁页面；测试以窗口关闭及真实剪贴板/接收内容作为最终断言。

- 托盘定位测试需去除可访问名称前导空格，并核对隐藏图标区父窗口的实际可见性；仅检查元素 offscreen 会误用隐藏面板的旧位置。修正后实际托盘点击通过。通用桌面控制工具没有返回任务栏窗口，最后采用仓库中的 C# 只读定位器与原生输入测试夹具验证。

- 通过后台 API 打开面板的测试不具有真实点击授予的前台切换权限，初次打包回归触发了正确的失焦收起。测试接收进程现仅向本次 Clipper 测试进程授权前台切换；产品逻辑不作放宽，真实托盘入口仍单独使用原生点击验证。方向键预览与组字 Enter 保护也加入界面测试，其中组字事件为模拟。

- 原有 folders-boundaries 在一次发布回归中得到 OLE 的“目标应用无法提供附件内容”，未进入预期的非法父目录校验。未修改该测试和发布二进制的严格专项复测通过；完整回归随后从头重跑。单次失败原因尚未确认，失败日志保留为 work/folders-boundaries-transient-0.19.log，不能据此承诺所有实际来源均无瞬时失败。

- selection-native 的 WinForms 测试窗口未获 Windows 前台切换权限，读取器正确返回 stale；诊断确认点击位置仍由其他前台窗口占有。测试现在先聚焦自己的接收窗口，再仅授权 WinForms 测试进程切换前台，严格选区/空选区/超长选区/密码框校验通过。未修改 SelectionHost 或产品二进制。保留同一二进制已通过的前 27 组证据，从该失败套件继续验证余下 18 组；最终清单合并两段哈希一致的记录，运行段和初次失败日志均保留。

- 原生选区专项的隔离复测通过后，续跑中原剪贴板哨兵被脚本外内容替换，导致“剪贴板未改变”断言失败。已停止桌面输入并请求重新确认独占键鼠/剪贴板的测试环境。当前保留前 27 组已通过记录，后 18 组尚未完成最终续跑；不能将外部改写忽略并计为通过。日志：work/selection-native-external-clipboard-0.19.log。

## 验收范围与限制

自动化复制/粘贴使用独立测试接收窗口与隔离历史目录，桌面测试串行执行，用户已退出日常 Clipper 并同意暂时停用键鼠。测试结束恢复可读取的原剪贴板格式。

锁定历史验证使用实际加密/解锁流程；休眠与屏幕变化使用事件模拟，不能替代物理系统休眠和多屏实测。Windows 托盘位置、混合 DPI、自动隐藏任务栏、其他置顶程序，以及真实 Office/邮件/管理员目标仍需要逐项兼容性验收。托盘内的文字预览有长度上限，搜索结果列表最多 80 项；复制保留完整原内容。普通磁盘目录引用仍为路径，不自动遍历或保存其成员。

字体设置、主窗口紧凑布局、完整双语、安装/更新/回退及签名仍未完成。历史版本归档保持不变。
