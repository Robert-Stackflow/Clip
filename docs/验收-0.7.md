## 回归细节

套件：electron、integration、advanced-ui、capture、drag、text-tools-ui、text-tools-boundaries、data-ui、recovery-ui、backup-performance、sync-ui、upgrade-ui、web-ui、vault-ui、vault-boundaries。

115,274,532 字节（约 110 MiB）资料的后台备份用时 6,293 ms，期间完成 4 次实际剪贴板采集；测得元数据请求 160–278 ms。快照保留 128 条，最终本机有 134 条；正常退出等待完整备份落盘。此数据来自当前机器的一次回归，不作为所有设备的性能保证。初次回归发现新增锁定的取消逻辑影响普通退出，已分开两个路径并在最终包重测全部套件。锁定会取消未完成的备份；已完成原子写入的文件可能仍存在，可以重新校验使用。

本轮网页共享在隔离 Edge 中验证，只在测试上下文接受证书，不改变系统信任。Chrome 和 95 秒空闲保活的结果见 v0.6 记录，本轮未重复执行。旧版升级由 v0.4.1 EXE 建立资料后验证新版本打开，未启用加密的资料保持兼容。启用加密后不再支持旧 EXE 直接打开同一数据库。

可重跑：`npm run typecheck`、`npm test`、`npm run package`、`node scripts/verify-packaged.mjs`。结果位于 `work/unit-0.7.log`、`work/package-0.7.log`、`work/packaged-0.7.0-results.json` 与各套件日志。

最终已测 `resources/app.asar` SHA-256：`7951e335c33fb7472647a7439f433f9441a7cfac0170456ff239ba8cc50b7268`。归档时逐字节核对 EXE、app.asar 与 Windows x64 加密原生模块，源码不包含测试资料、密钥、依赖安装目录或工作区缓存。

## 未覆盖与后续

- Windows Hello 真人 PIN/人脸/指纹、无 Hello 设备、系统策略禁用场景；不将可用性查询或 mock 视为真人验证通过。
- 实际锁屏、休眠/唤醒、断电、磁盘空间不足、磁盘故障及全容量长期驻留。程序按事务/原子位置切换处理失败，不能替代真实故障硬件验证。
- JS 字符串/原生运行时副本/系统交换文件不保证立即擦除。OCR/图片拖出存在短暂明文临时文件；原明文库、旧备份、源文件与用户导出需另行管理。
- Hello 使用应用层验证和当前 Windows 用户 DPAPI，未实现 TPM 绑定密钥。没有独立密码学或渗透审计。
- 物理跨设备/防火墙/移动浏览器与人工证书流程、混合 DPI、多应用粘贴、真实 AI 质量仍需补充。
- 边缘停靠/卡片方向/划词菜单/桌面拖放架、录屏/录音/长截图、签名安装包与更新仍在开发计划中。
