# v0.16 候选 1：搜索历史与模板快捷键验收

2026-10-01，Windows 11 x64、Electron 44.5.1、150% 缩放。使用隔离测试资料；桌面测试串行执行，结束后恢复支持的原剪贴板内容。

## 验证范围

搜索历史覆盖默认关闭、主动开启、完整词条提交、键盘复用、保持当前筛选、单条删除、清空、关闭清空、重启持久化，以及词条数量/长度/去重边界。输入法用 DOM composition 事件验证组合期间不保存、不触发 Enter 粘贴，不等同于所有实体输入法兼容性实测。

使用真实 Windows 全局热键，从受控外部窗口唤起回复页、直接粘贴文字、填写变量后返回原窗口、粘贴图片与文件；原文件内容保持不变。填写期间切换至另一窗口后，确认仍粘贴到最初目标；目标销毁时，在改变剪贴板前拒绝。浅深界面按发布包截图核验。

模板保存与热键注册遇到占用/重复时，模板内容、历史选项与原有按键全部保持。快捷键录入暂停本应用热键，Esc/失焦后恢复。启动时由另一进程占用一个模板键，其他入口和模板仍正常；释放占用并重新保存后恢复。启动重复键的优先级、临时回调不执行和注册失败回滚由逻辑测试覆盖。

修改模板后旧预览不能执行；取消不粘贴；迁移保留本机历史与绑定并撤销旧预览；实际数据库加密、锁定及解锁撤下并恢复热键。休眠通过 powerMonitor 事件模拟；十分钟过期用虚拟时钟检查。删除模板释放绑定，普通备份排除搜索历史及本机热键。虚拟附件共用已有模板粘贴路径，原有附件套件回归；本版独立热键专项的格式用例是文字、图片和本机文件。

区域录制回归发现既有界面竞态：后台来源刷新在选区过程中返回空列表，清空已选屏幕。修复为选择区域时撤销旧请求，忽略迟到结果与录制期间的来源刷新；受控延迟空列表和真实重新开始区域录制共同验证，保留显示器变化后停止录制的检查。

## 限制与后续

快捷键能否注册、自动焦点恢复和粘贴接收由 Windows 与目标应用决定；管理员窗口、Office/邮件应用、多种实体输入法和键盘布局仍需逐项实测。HWND/PID 校验避免一般窗口失效情形，不宣称涵盖所有第三方应用生命周期。输入法事件和系统休眠模拟不替代物理环境验收。

schema/备份保持 5、同步保持 4。搜索历史和热键绑定不进入普通备份；完整资料目录迁移保留。Windows 10、真人 Hello、真实锁屏/休眠、混合 DPI、物理多设备和长期满容量验收仍待补充。堆栈自动捕获、其他格式、中英界面、安装/更新及签名继续按开发计划推进。本版为未签名 Windows x64 目录包。
