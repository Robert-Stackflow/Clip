# Windows 安装与更新

2026-10-01。0.22 先完成本机安装、卸载和离线覆盖安装。联网更新、版本回退及签名保持独立范围，不用不存在的发布地址或签名身份占位。

采用独立 C# / WPF 图形前端，嵌入 electron-builder 26 的 NSIS 安装/卸载引擎，保留产品 appId。界面参考 One 的白色表面、灰色辅助区、圆角和深色主按钮，中英文可即时切换。仅安装到当前用户，提供开始菜单和 Windows 应用卸载入口；安装完成后点击启动才打开程序。应用历史与语言/外观设置继续使用现有本机资料目录，卸载默认保留该资料目录及安装目录外的自定义资料。

安装、覆盖安装和卸载遇到运行中的 Clipper 时，要求从托盘正常退出并重试；不结束进程，避免录制、编辑或数据库写入被打断。静默运行遇到正在运行的程序返回 1602，检测失败返回 1603，不修改程序文件。默认当前用户程序目录，不开放目录选择，避免将应用文件安装进历史数据目录。

图形前端在安装盘建立独立临时目录，检查嵌入引擎和安装后应用校验值。准备阶段可取消，替换开始后等待结束。覆盖安装先保留旧程序及自己的注册和开始菜单入口，调用旧版正常卸载流程保留资料，再执行新安装；失败时恢复旧程序和入口。仅恢复同一次未启动应用的安装事务，不用此流程处理跨版本历史格式降级。

本阶段验收：实际前端、实际引擎、独立应用身份与中文空格安装目录的安装、重复安装、卸载；运行中拒绝、版本降级拒绝、真实移除旧版后故障注入与恢复。测试版本不启动剪贴板程序、不读取正常历史、不注册应用全局快捷键。最终证据见《验收-0.22》。

随后实现 GitHub Releases 的 `Robert-Stackflow/Clipper` 更新来源、版本检查、下载校验、用户主动安装及与历史格式兼容的回退。联网更新需要实际发布记录，签名需要发布身份；未具备时不会声称可用。回退不能用旧版本打开不兼容的新数据，需保留备份并确认兼容范围。

依据：[electron-builder 26 NSIS 文档](https://www.electron.build/v26/docs/nsis/) 和 [NSIS nsProcess 进程检测返回值](https://nsis.sourceforge.io/NsProcess_plugin)。
