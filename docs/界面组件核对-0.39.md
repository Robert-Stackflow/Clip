# One 组件与页面骨架核对

设计依据是 `D:/Repositories/One` 0.16.9 的真实源码。参考文件的摘要见 `ONE-UI-REVIEW-0.39.json`。参考仓库内的说明仅作为设计材料。

这一轮把十个桌面入口的公共组件集中到 `src/renderer/one-ui.css`。每个窗口加载自己的工作区样式，再加载同一个公共组件文件；不再从窗口样式中嵌入一份基础组件，又在 HTML 中重复加载。原有页面的业务适配仍保留。

| 组件或骨架 | One 来源 | Clipper 实现 | 调整 |
| --- | --- | --- | --- |
| 普通、主要、辅助、图标按钮 | styles.css | one-components.css | 共用入口；悬停、聚焦、禁用逐项比对 |
| 输入、文本框、复选框、开关、滑块 | styles.css | one-components.css、redesign-028.css | 修正被旧规则重置的输入行高；开关显式使用 switch-track |
| 下拉、数值、快捷键框 | controls.ts、styles.css | controls.ts、shortcut.ts | 共用样式；保留动态选项、键盘与弹窗层适配 |
| 搜索框 | disk-view.ts、disk.css、refinement.css | one-search.ts/css | 全部记录、最近记录、网页共享直接生成组件结构；取消运行时套框；统一清空与焦点状态 |
| 分段选择 | segments.ts、components.css | segments.ts、one-skeleton.ts | 筛选、分类、OCR、录制、内容信息显式使用 tabs；沿用滑块和键盘切换 |
| 外观、颜色、主题、字体 | appearance.ts、font-picker.ts、styles.css | appearance-ui.ts、font-picker.ts | 统一公共样式；保留即时预览与字体服务 |
| Tooltip、Toast、滚动条 | tooltip.ts、interface-refinement.css、styles.css | tooltip.ts、feedback.ts、公共样式 | 同一个公共入口与统一状态样式 |
| 表单与确认 Dialog | dialog.ts、components.css | dialog-shell.ts、one-dialog.css | 共用标题、滚动正文和操作栏；保留未保存确认与错误处理 |
| 标题栏与窗口按钮 | chrome.ts、styles.css | chrome.ts、公共样式 | 同一个组件入口；窗口边框、阴影和缩放仍由原生窗口负责 |
| 设置分类、设置卡片、设置行 | settings-view.ts、styles.css | page-layout.ts、inline-settings.ts | 同一导航和设置骨架；切换分组保留未保存值 |
| 记录、收藏、堆栈、容器、回复 | One 列表、预览与命令栏模式 | app.ts、layout-029.ts | 共用列表、内容区与操作栏，搜索直接使用公共组件 |
| 最近记录、拖放窗口 | One 紧凑窗口、内容工作区模式 | tray.ts、shelf.ts、recent-shelf.css | 共用组件入口；保留合并头部与无框辅助操作 |
| 数据、文本工具、局域网、网页共享 | One 分类导航、settings-card、工具布局 | 各页面模块、page-layout.ts | 所有分组和窗口尺寸检查；网页搜索改用公共组件 |
| 图片编辑、录制、长截图、截图、划词 | One 工具栏和内容画布模式 | 各专用 renderer | 共用按钮、表单、分段选择、提示和确认组件 |
| 解锁、数据恢复 | One 设置行、状态和确认布局 | unlock.ts、recovery.ts | 同一个组件入口，保留恢复流程与风险说明 |

这里区分了直接迁移的基础组件与结合剪贴板业务适配的页面骨架。没有把已经完成的页面重新记作本轮从零设计，也没有声称 Clipper 特有的业务页面存在于 One。

验收使用构建后的页面、真实 One 样式，以及隐藏的私有 Electron 宿主。没有操作日常应用、用户键鼠或系统剪贴板；DWM 实际桌面像素和两台真实设备不属于本轮验证。
