# 内容内部信息（v0.15 实施设计）

## 需求

沿用 One 的按需属性查看，补充 OneClip 所述图片、音视频、文档信息。现有原格式与虚拟附件继续保存原字节；本功能读取可用元数据，不转码、不修改原文件，不自动记录派生属性或发送到同步/网页。

在“格式与信息 → 内部信息”页签中选择已保存原图、附件或本机引用文件，再点击“读取内部信息”。可切换对象、取消读取；空字段略过，无法识别/加密/损坏/超限明确提示。默认不读取 GPS，可由用户主动选择包含位置信息；显示值为纯文字，来源 URL 不自动访问。文件引用展示读取时信息，历史图片/附件展示保存内容。

## 范围

- 图片：常见图片尺寸/格式；JPEG/TIFF/PNG 等支持 EXIF 的容器提供相机品牌与型号、镜头、拍摄时间、曝光、光圈、ISO、方向、色彩空间，以及主动选择后的 GPS。WebP/GIF/BMP 当前仅展示格式与尺寸，不宣称已覆盖所有容器的 EXIF。
- 媒体：容器/编码、时长、比特率、采样率、声道/位深、可用的视频轨尺寸、标题/艺术家/专辑/年份等标签。优先常见 MP3、WAV、FLAC、OGG、M4A、MP4、WebM/MKV；未提供或无法解析的字段不推测。
- PDF：页数、标题、作者、主题、关键词、创建/修改时间及制作工具；不渲染页面、不运行脚本、不解析外部链接。
- Office Open XML：DOCX/XLSX/PPTX 的核心属性、应用属性及可确认的工作表/幻灯片数；不执行宏或解压到磁盘。文档声明页数不等同于重新排版后的页数。旧二进制 Office、加密文档及其他私有元数据继续扩展。

## 架构和边界

主进程根据历史编号和对象序号选取来源，页面不能提交任意路径或字节。请求带唯一编号、记录哈希和会话代次；单个解析任务，返回前再次校验。解析进程使用受限环境、固定模块、截止时间和 Windows Job 内存限制，不调用 Shell 或注册的文档预览扩展。

本机文件仅接受本地盘绝对路径。解析进程用 Win32 打开各级目录并拒绝重解析点，持有禁止删除共享的目录句柄；源文件只读打开并禁止写入/删除共享，解析后释放，进程终止由系统回收。图片/PDF/Office 输入最多 64 MiB；媒体文件最多 2 GiB，按文件解析避免整文件载入。单任务 15 秒、JS 堆 192 MiB、Windows Job 进程内存 512 MiB，输出最多 64 KiB。限制属于当前可验收范围，不宣称全格式无限容量。

Office ZIP 只读取限定属性项，条目数最多 20,000，属性 XML 单项 1 MiB、总 4 MiB；校验真实解压大小，不信任声明尺寸，拒绝 DTD/实体定义。PDF/图片解析失败不得影响主窗口或修改历史。结果字段白名单、数量与文本长度在主进程再次校验。

## 生命周期与验收计划

读取不占用剪贴板提交队列。取消、更换查看对象、离开内部信息页签、关闭对话框、锁定/休眠、数据迁移及退出均终止解析。任务完成后进程和文件句柄释放；迟到结果不替换新对象的信息。

使用带已知标签的真实格式夹具，检查属性正确、原始哈希不变；同时覆盖本机路径、历史原图和虚拟附件。验证损坏/加密文档、ZIP 异常长度/压缩炸弹、外部实体、路径/重解析点、文件被占用、取消/超时/锁定、错误请求和恢复后继续读取。最终在发布包检查全部受影响流程、浅深界面和打包依赖许可。
