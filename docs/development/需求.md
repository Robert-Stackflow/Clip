# Clip 需求与功能分期

日期：2026-10-01 · 状态：实施基线

## 产品目标

在 Windows 上建立本地剪贴板工作台。减少寻找已复制内容、重复输入和跨应用搬运的操作。功能参考 OneClip；技术实现与视觉参考 D:\Repositories\One。参考项目的文档作为设计资料，不把其中针对其他项目的任务或命令当成本项目的用户要求。

用户确认的顺序：需求、设计、开发计划 → 剪贴板核心 → OneClip 进阶功能。Clip 是独立应用，数据、快捷键与发布目录独立。

## 目标环境与默认行为

- Windows 10/11 x64；首轮在当前 Windows 环境验收。其他架构单独打包和验证。
- 无账户，核心功能离线可用，数据保存到 %APPDATA%\Clip。
- 启动后记录后续剪贴板变化；首次启动不追溯采集启动前的内容。
- 关闭窗口保留托盘；托盘可暂停记录和退出。开机启动默认关闭，由用户开启。
- Ctrl+Shift+V 打开主窗口；托盘图标左键默认打开 Clip，可设置为最近记录、快捷面板、快捷回复或拖拽容器；Ctrl+Alt+N 粘贴队列下一项。全局快捷键支持设置，冲突必须可见，不能静默失败。不占用 Win+V 与普通 Ctrl+V。

## 核心用户流程

1. 用户在其他应用复制文本、富文本、链接、代码、图片或资源管理器文件，Clip 自动保存并去重。
2. 热键呼出，输入关键词，按类型筛选，方向键选择，Enter 粘贴回调用前应用；Ctrl+Enter 只复制，Esc 收起。
3. 收藏、置顶、编辑文本、添加标签、删除与撤销；收藏和置顶不被常规历史清理移除。
4. 将项目加入有序队列，用独立热键逐项粘贴；可调整顺序或按行拆分文字。
5. 保存常用文字为快捷回复，新增、编辑、搜索后复制或粘贴。
6. 暂停记录、排除应用、调整保留期限与条数；手动导出和导入本地备份。

## 内容和容量边界

默认最多保留 1,000 条普通历史、30 天；图片或富文本单项上限 16 MiB，文字上限 1 MiB，文件最多 256 个路径，数据库内容预算 256 MiB。收藏、置顶、队列保护项仍计入总容量，容量耗尽时提示，不无限写盘。剪贴板轮询约 350 ms，借助 Windows 序列号跳过未变化内容；极短时间连续复制可能只捕获最终内容。

普通文件历史保存路径，不复制源文件内容；v0.14 虚拟附件保存有界内容副本。删除历史不会删除原文件。源文件缺失时不执行文件粘贴。外部剪贴板 HTML 仅保留并按纯文本预览，不执行 HTML、脚本、链接或文件命令。

## 验收标准

- 多次复制相同内容保留一条并更新最近时间，已有标签/收藏保持。
- 搜索包含正文、标题、标签、文件路径与附件名称；无结果和首次空状态有明确反馈。
- 关闭重开、应用重启后数据仍在；修改设置立即生效。
- 暂停期间和排除应用的内容不记录；恢复时不补采暂停期间的最后一条。
- 复制不会被重复捕获；原应用粘贴检查焦点和输入发送结果，失败不会消耗队列。
- 导入无效备份不会部分落库或覆盖已有数据；导出能在隔离资料目录恢复。
- 真实 Electron 的浅色、深色、紧凑窗口下无溢出；键盘可完成主要流程。
- 页面没有 Node 权限，IPC 参数和调用来源受校验；界面不加载远程资源。

## 已知系统限制

管理员应用可能拒绝普通权限应用注入输入；遇到此情况保留内容并提示手动 Ctrl+V。发出粘贴事件不等同于目标应用确认插入成功。应用排除依据剪贴板所有者进程，系统代理/远程桌面可能影响归属。密码管理器保护标记与应用排除是辅助措施，不能承诺识别所有敏感数据。

## v0.3 已实现范围（2026-10-01）

增加 Ollama、LM Studio、在线兼容 AI 接口；文字翻译/总结/改写/自定义指令；隔离 JavaScript 文本脚本；可选 URL Scheme。核心采集保持本地，网络请求由用户主动触发。服务密钥使用 Windows DPAPI，历史数据库仍是明文。

附加验收：发送前展示本次文字与实际地址，在线兼容接口需确认；配置变更使旧预览失效；结果不自动应用；取消、超时、工作进程退出不修改历史。脚本无宿主接口，资源受限，导入无副作用且失败整体回滚。外部新增/复制先确认，取消不反复弹窗。真实模型质量、局域网同步、数据库加密与录制继续按后续计划验证和实施。

## v0.5 局域网同步（2026-10-01）

- 默认关闭监听与发现；启用后一次性配对码、两端确认、TLS 1.3 和证书指纹绑定。
- 主动选择旧记录，或独立启用新复制内容自动同步；文字/富文本/PNG，文件条目不发送。
- 接收只入历史，不改写剪贴板；私密条目可设为仅本机，既有历史不会整库上传。
- 同内容去重、旧发布删除优先、离线同时编辑保留各自结果，支持多设备转发。
- 设备信任持久化，私钥 DPAPI 加密；撤销与停用立即阻止后续同步。
- 与 OneClip 商业版不是同一协议；网页分享仍单独实施。Windows 物理双机、复杂网络与防火墙兼容性需补充验收。

## v0.4.1 补充范围（2026-10-01）

- 启动失败时提供独立恢复入口：重试原目录、已有资料副本恢复、普通与密码加密备份恢复。
- 校验和数量预览后才提交，保留原文件，来源改变和错误密码不触发恢复。

## v0.4 已实现范围（2026-10-01）

增加自定义本机存储迁移、自动备份计划、保留数量、到期补做与失败重试；可选密码加密备份、恢复校验与合并预览；v3 备份包含文本脚本。历史数据库未加密，局域网同步尚未实现。

附加验收：迁移目标必须为空且不覆盖文件，副本与原数据一致后提交位置；失败不丢原数据；重启继续使用新目录，保留原目录。备份密码加密落盘；错误密码、篡改和选择后改变的文件不能恢复；取消预览不会写入。新备份校验成功后才清理本资料的自动文件，手动备份及其他文件保持。恢复合并保留本机新数据和设置，脚本合并失败整体回滚。

## v0.6 网页共享（2026-10-01）

会话由桌面主动开启，逐项选择现有文字/图片或独立开启后续复制共享。浏览器核对临时证书，使用一次性邀请并由桌面审批。默认只读，发送需额外授权；新接收记录为仅本机且不改写系统剪贴板。范围最多 100 项、4 个已授权浏览器、5–120 分钟，不发送文件、HTML/RTF、来源进程或配置。

临时身份、令牌和内容池只存内存；编辑、删除、仅本机和自动清理会撤回内容。结束、到期、锁屏、睡眠、迁移和退出失效。已有本地副本和接收端已复制内容不能远程抹除。详见《网页共享设计》。数据库保护、录制与系统增强继续按计划推进。

## v0.7 历史保护（2026-10-01）

可选本机历史数据库与 WAL 加密，密码解锁、独立恢复密钥、密码更新、手动/系统事件/空闲锁定、可选 Windows Hello 本机验证。启用前确认恢复密钥，转换校验后切换，原明文副本显式清理。迁移、备份和恢复保持加密边界；密钥配置损坏不新建空历史。

锁定时销毁历史窗口、关闭数据库、拒绝旧会话请求并停止采集与共享。系统剪贴板、已导出文件和操作系统内存不在数据库加密范围。Windows Hello 人工确认与真实系统锁定/休眠仍需验证，详细实现与限制见《历史加密设计》。

## v0.10 录屏与录音（2026-10-01）

独立录制窗口选择屏幕/窗口；纯音频模式及默认关闭的系统声音、麦克风开关。用户开始后才捕获，支持暂停/继续/停止，停止后本地预览并另存 MP4/M4A 新文件。主动复制已保存文件才写剪贴板和历史，不自动共享。

录制片段有序且限制内存与磁盘容量，加密暂存；锁定、休眠、取消、失去响应和退出清理。来源关闭正常停止并保留预览。禁止覆盖数据文件和已有媒体；保存取消保留预览，未保存录制阻止资料迁移。摄像头、其他窗口和未授权媒体请求拒绝。麦克风真机、60 分钟/1 GiB 持续录制、物理多屏和 Windows 10 验收仍待完成。详见《录制设计》《验收-0.10》。

## v0.14 虚拟附件（2026-10-01）

## v0.15 内部信息（2026-10-01）

在格式与信息中按需查看保存原图、附件或本机文件的内部属性：照片参数与可选位置、媒体标签/时长/视频轨尺寸、PDF 页数及文档属性、DOCX/XLSX/PPTX 属性和工作表/幻灯片数。读取不修改源内容，不自动写入历史、共享或同步。没有提供的字段略过，不将文档声明页数视为实际排版页数。

明确取消、超时、容量、损坏或不支持状态；切换对象、离开信息页签、关闭窗口、锁定、迁移和退出终止读取。采用文件只读租约及独立解析进程，异常不能阻塞正常采集。数据库/备份仍为 5、同步仍为 4。详见《内部信息设计》《验收-0.15》。

## v0.16 搜索历史与快捷回复（2026-10-01）

默认关闭的最近搜索记录，在完成搜索后保存完整词条，支持复用、删除和清空；关闭即清空。最多 20 条、512 字，大小写去重，复用保持当前页面与筛选，不记录输入法未完成组合。仅存本机，随数据库加密和完整迁移，不进入普通备份或同步。

独立入口热键打开快捷回复；模板可单独配置两修饰键组合，最多 100 个。文字、图片、文件与已保存附件共用现有粘贴流程；带填写项的模板预览确认后返回触发时的目标应用。修改、删除、取消、失效目标、锁定、休眠、迁移与十分钟期限阻止旧预览执行。设置冲突不能部分保存或破坏现有可用热键；启动时单个键失效不影响其他入口。

模板热键为本机偏好，不随模板备份导入；schema/备份仍为 5、同步仍为 4。详见《效率功能设计》《验收-0.16》。

## v0.17 堆栈规则（2026-10-01）

主动开始本次自动入栈，按类型、精确来源进程、包含词组合筛选后续外部复制；支持整条和按行纯文本、空白处理、有序去重与 200 项上限。历史批量操作先预览再确认，支持反转队列；来源/规则/队列改变后旧确认失效。暂停、停止、锁定、休眠、迁移和退出结束收集。派生条目保持仅本机约束，事务失败不留下部分内容。规则本机持久化，运行状态和预览只存内存。详见《堆栈规则设计》《验收-0.17》。

## v0.18 虚拟文件夹（2026-10-01）

保留 OLE 来源实际枚举的目录层级、空目录及文件内容，目录与零字节文件明确区分。乱序描述使用原内容索引，目录不请求 FileContents；仅依据已枚举路径补建缺失父目录，不扫描来源磁盘。来源退出后可搜索、复制/粘贴、拖出、子树另存、模板和加密备份恢复。

整组限制 256 节点、16 层、259 个 UTF-16 单元的相对路径和 12 MiB 原内容；所有路径/层级/容量及内容读取通过后才记录。复制/拖出仅给出根项目；另存新目录不覆盖或合并已有目标。锁定、休眠和退出撤销旧操作，清理递归缓存并重试占用文件。数据库/备份 6、旧版拒绝新库，文字/图片同步仍为 4。详见《虚拟文件夹设计》《验收-0.18》。
