# Clip 需求

更新：2026-10-10 · 当前源码基线：0.51.2。本文维护产品范围与验收要求；实现、交付和待办只在 [当前状态与待办](当前状态与待办.md) 维护。

## 产品目标与环境

Windows 本地剪贴板工作台，减少寻找复制内容、重复输入和跨应用搬运的操作。支持 Windows 10/11 x64；其他架构需单独打包和验证。核心功能离线可用，正式数据默认保存在 `%APPDATA%\Clip`，开发使用独立资料。功能参考 OneClip，界面与工作流参考 One；来源见 [调研索引](../README.md#调研)。

## 核心流程与默认行为

1. 启动后采集后续剪贴板变化，首次启动不追溯采集此前内容；暂停或排除期间的内容不补采。
2. 搜索或筛选记录，选择后复制、回贴到原应用，或整理到分类、堆栈、快捷回复与拖拽容器。
3. 修改设置立即生效并持久化；关闭主窗口保留托盘，从菜单退出才结束程序。开机启动默认关闭，启用后只驻留托盘。
4. 默认主窗口快捷键为 Ctrl+Shift+V，堆栈下一项为 Ctrl+Alt+N；快捷键允许清空。Win+V 接管由快捷面板设置控制，冲突必须可见，不占用普通 Ctrl+V。
5. AI、脚本、同步与网页共享由用户显式配置或触发；发送内容和服务选择应清楚可见。

默认保留 1,000 条普通历史、30 天，历史容量预算 256 MiB；具体上限与校验以 `src/shared/core.ts` 为准。收藏、置顶及堆栈保护项仍计入容量，不能无限写盘。普通文件历史保存路径，虚拟附件保存有界内容副本；删除历史不得删除原文件。

## 总体验收

- 同内容去重并保留标签/收藏；搜索覆盖正文、标题、标签、路径与附件名称，空状态清楚。
- 重启后历史和设置保留；暂停、应用排除、锁定与容量限制生效。
- 自身回写不形成循环；回贴检查目标窗口与焦点，失败不消耗队列。
- 无效备份不部分落库；备份可以在独立资料目录恢复，取消导出不留下文件。
- 页面无 Node 权限，IPC 校验调用来源和参数，外部 HTML 不执行；敏感资料与日志遵循所属资料目录的保护规则。
- 浅色、深色、中英文和紧凑布局可操作，主要流程支持键盘，错误可见且可恢复。
- 桌面、跨设备、安装与长期运行验收按真实环境记录；逻辑测试或单机双实例通过不等于这些验收完成。

管理员权限目标、复杂 OLE 来源、系统代理剪贴板与瞬时连续复制存在系统边界。发送粘贴事件不等于目标应用确认插入成功；应用排除及密码管理器标记不能保证识别全部敏感内容。具体待验收环境见 [当前状态与待办](当前状态与待办.md)。
