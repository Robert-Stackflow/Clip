**已经实现的四项，不再列作未实现功能：**文件与附件跨设备同步、DIB/可持久化应用格式保留、加密/旧 Office 信息和扩展录制导出、堆栈重复副本。证据见 [0.27 验收](../history/验收-0.27.md) 和 [设计](四项功能设计-0.27.md)。

剩余工作主要是实际应用与物理设备兼容性、未支持的来源格式/加密方案，以及正式发布链路和签名。不能把合成接口、TLS 回环或隐藏窗口测试表述为双机或真实桌面验收；没有公开发布和干净系统证据，因此整体目标尚未完成。

Windows Explorer 原生提供文件剪切移动，历史回放使用复制语义；不替换系统文件移动。此前 0.26 审计所列四项缺口已由 0.27 更新，历次开发计划的未勾选项需结合其版本阅读。

0.30 至 0.32 持续改进列表与全文搜索、隐藏窗口刷新、按需追踪、大内容导出和图片传输。0.32 的图片缓存、原子另存为、拖拽图标及会话恢复证据见《验收-0.32.0》，其模拟文件选择/拖拽边界不替代真实桌面验证。

0.33 继续减少大图片复制、原始格式回放及容量检查的重复处理；图片编辑与通用原子另存为合并。私有内存、接口适配和实际图像证据见《验收-0.33.0》；同步图像解码仍有开销，未以此次范围代替物理设备验收。

0.33.1 补上 32 种原始格式与五种生成块共存的组合上限，验证 37 个格式块，详见补丁验收。

## 0.39 界面组件复核

基础组件与全部桌面入口统一到 one-ui.css。18 类组件与本机 One 0.16.9 逐项比较；公共搜索直接生成组件结构；设置导航与行间距修正旧覆盖。页面和业务骨架沿用并复验，不将既有迁移重复算作从零实现。明细见界面组件核对-0.39.md 与验收-0.39.0.md。

## 0.46.4 至 0.46.6 性能与操作

0.46.4 改进大图编辑的重画和按屏幕尺寸分配动画位图；0.46.5 实现一次选区后的长截图自动稳定采样、悬浮控制条和最近记录轻量查询、无文字骨架；0.46.6 将大内容发送准备移到有界短期线程，并直接编码 SQLite 正文。对应验收包含固定源码对照与隔离样本，没有以这些结果证明所有真实桌面场景。

性能剩余项明确包括同步接收校验/写入、文件发布最终提交、真实来源应用响应和长时间驻留内存。真实双物理设备、多屏、休眠、麦克风、签名和干净系统发布验收仍未完成，持续优化目标保持进行中。

## 0.46.7 同步接收

大正文的解析、校验和写入移到有界短期线程，共享标记与内容只保存一次；原子提交经过现有串行队列。新增回归与包内加密写入检查覆盖隐私、撤回、重复项、本机保留权和取消。五轮固定对照显示主进程停顿明显下降，总进程峰值工作集仍接近基线，未宣称长期驻留内存降低。PNG 原生解码、文件发布提交和真实物理设备验收继续保留为剩余项，详见《验收-0.46.7》。

## 当前阶段：0.50.0 设置与窗口整合

快速粘贴与最近记录复用同一窗口，数据保护、自动备份、备份记录、升级恢复点和程序回退统一进分组设置；划词菜单退役。证据见《验收-0.50.0》。0.49.11 已按用户要求结束性能/响应阶段，上文性能剩余项为历史阶段记录，不自动启动新调查。整体目标仍缺物理设备和实际桌面兼容性、正式发布链路等证据，保持进行中。

0.50.0 的追加调整：AI 服务为工具分组首项，文本脚本为第二个独立入口；外部链接改名 URI，放在连接与分享。三页只读取并渲染各自资料，继续复用原编辑、运行及外部请求确认逻辑；AI/脚本卡片右边缘与标题操作栏对齐。局域网同步使用设备同步图标，URI 使用链接图标。旧工具导航及无服务/无脚本引导改为新入口。

0.50.1 统一了 AI 服务与文本脚本的空列表引导，依据实际独立窗口截图调整。验证边界见《验收-0.50.1》。

当前源码的布局检查 `node tests/redesign-layout.cjs` 在 1 倍、设置 `CLIPPER_TEST_DEVICE_SCALE=1.5` 和设置 `CLIPPER_TEST_DEVICE_SCALE=2` 后各通过 296 个双语、主题、窗口与字号组合；输出分别保存在 `work/redesign`、`work/redesign-dpi-1.5`、`work/redesign-dpi-2`。这是隔离浏览器的高 DPI 渲染检查，仍不能替代物理多屏和 Windows 缩放切换验收。

0.50.2 收拢近期交互与布局改进：对话框关闭动画支持中途反转，输入标签与 Escape 行为保持一致；最近记录键盘选中保持焦点，网页共享访客刷新保留焦点和滚动；资料页、侧边栏、录制与图片编辑在窄窗口和放大字体下继续调整。目录包与隔离窗口证据见《验收-0.50.2》。

0.50.3 修正空记录提示的窄行孤字及暂停状态下的误导性说明；表情符号和 CheetSheet 的分类控件在初次渲染时即暴露选中状态。实际打包程序启动和包内资源检查见《验收-0.50.3》。

2026-10-04 的系统记事本试用发现一项失败回退问题：Windows 拒绝恢复原目标窗口时，内容已复制，但最近记录窗口先隐藏，错误提示随之消失。现在主窗口会显示“无法恢复目标窗口，已复制，请手动 Ctrl+V”。这次记事本自动粘贴未通过，仍列为真实应用兼容性待验证；隔离窗口的正常粘贴和最近记录边界回归通过。

0.50.4 目录包通过资源一致性检查和实际 `Clipper.exe` 隔离资料启动检查，主界面、样式及原生组件正常；签名状态为 `NotSigned`。详见《验收-0.50.4》。这不改变记事本自动粘贴未通过、其他实际应用与正式发布链路未验收的结论。

0.50.5 调整原窗口粘贴顺序：请求切回目标时 Clipper 仍持有前台，随后隐藏自身并核对目标。源代码与包内程序均通过本机实际记事本和独立 WinForms 目标的自动粘贴回读；此前记事本失败已在当前机器复验通过。其他实际应用、管理员权限和不同桌面环境仍待验证，详见《验收-0.50.5》。

追加本机 Word 与 Excel 空白文档的纯文本回贴检查，源代码和 0.50.5 包内程序均通过；临时文档未保存。随后用隔离资料把同一条带粗体、颜色和 18pt 字号的 HTML/RTF 内容经最近记录粘贴到 Word，源码程序与 0.50.5 目录包的两种指定格式粘贴均保留样式。当前 Word 的“从其他程序粘贴”偏好为“匹配目标格式”，因此普通 Ctrl+V 使用文档默认颜色和字号；测试没有更改该偏好。图片回贴也在真实 Word 空白文档通过：保存后的 DOCX 内嵌图片为 160×96，解码像素与来源完全一致。本机资源管理器的 CF_HDROP 文件回贴也已通过：独立源文件经最近记录粘贴进独立空目录，字节完全一致且源文件未变；“文件 + 文件夹”组合也保留了嵌套文件和空目录。受控原生 OLE IStream 虚拟附件被捕获且来源进程退出后，仍能从最近记录落成资源管理器中的文件。Outlook 实际邮件样本、其他复杂来源及管理员目标仍未覆盖。

0.50.6 修正表情资料中的地区旗帜显示：Windows 原生字体会把部分双地区指示符显示成字母，现用本地彩色字体的私用区字形映射显示，条目文字和复制仍是原始 Unicode 序列。中国和英格兰旗帜的实机截图、六档肤色、分类导航及字体释放检查通过，包内程序已复验。

0.50.6 追加 Windows Terminal 实际回贴：独立启动的 UTF-8 PowerShell 接收最近记录粘贴的中文与 emoji，剪贴板和终端结果逐字一致；源码与包内程序均通过。PowerShell 5.1 默认输入编码在本机将 emoji 读成问号，因此旧代码页终端仍是兼容性边界。详见《验收-0.50.6》。

同版追加独立 Edge 实际回贴：普通输入框、可编辑区的中英混合文本，以及可编辑区 HTML 加粗/红色/18pt 均在源码和包内程序通过；包内连续三轮通过。首次扩展用例时曾有一次前台恢复失败，未将其视为稳定性已证明，保留手动 Ctrl+V 回退。其他浏览器及复杂网页编辑器待验收。
