# 搜索历史与快捷回复（v0.16）

## 需求与流程

功能参考 OneClip 的快捷回复独立快捷键及搜索历史规划；控件和快捷键录入方式参考本地 One 的 search-view.ts、shortcut.ts。两份参考只作设计资料。

搜索框旁提供“搜索历史”。记录默认关闭，用户开启后，在离开搜索框或使用搜索结果时记住完整词条；输入法组合期间及逐字输入不保存。最近 20 个词条按使用顺序排列，去除首尾空白并忽略大小写去重，最长 512 字。可以复用、单独删除、清空；历史窗口的操作立即保存，关闭记录即清空。复用保持当前页面与筛选，主窗口和快速面板共用。搜索历史只保存在本机数据库，随数据库加密和完整迁移，不进入历史备份或设备同步。

Ctrl+Shift+R 打开快捷回复页面，可改键或停用。在模板编辑中为文字、图片、文件和已保存附件配置独立热键；最多 100 个模板热键。无需填写的模板直接粘贴到触发时的外部窗口；带填写项的模板先打开填写/预览，确认后粘贴到原窗口。日期/时间变量使用实际执行时间。目标失效或注入失败明确提示，文件缺失不替换系统剪贴板。

## 一致性与生命周期

快捷键统一录入与校验，包含至少一个 Ctrl、Alt、Shift 或 Win 修饰键与字母、数字、F 键、空格或导航键；界面显示 Win，注册与存储使用 Super。所有入口和模板统一校验重复及系统占用；先注册新增组合，全部成功再撤下旧组合。失败保留既有设置与可用按键，启动时个别键被占用或升级产生重复不影响其他可用键，并显示错误；旧有入口优先于新增默认入口。录入时暂停本应用全局键，结束/失焦恢复。锁定时模板热键撤销，解锁后恢复；系统锁屏、休眠、迁移和退出使待填写操作失效。

模板热键和搜索设置是本机元数据，不改变 schema/备份格式。模板本身继续进入现有备份，导入不会自动启用外来热键。保存模板及热键事务提交，删除模板撤销绑定，迁移和重启重新读取绑定。待填写操作绑定模板内容、会话、原目标窗口及短期令牌；后续编辑/删除/锁定不能将旧预览粘贴出去。不用普通 Ctrl+V 接管系统粘贴。

## 验收计划

逻辑检查词条边界、顺序/去重/清除、快捷键规范化/冲突/原子回滚、数据库重启/迁移和备份排除。真实 Windows 热键测试从外部目标唤起与粘贴文字、变量、图片、文件；检查目标捕获、错误和取消不粘贴、重启恢复、删除释放、录入恢复、锁定恢复及被占用后的降级。检查浅深主题、键盘复用和输入法组合。发布包回归已有流程，记录证据及未验证环境。
