# 中英界面（0.21 开发方案）

2026-10-01。依据 [OneClip 官方功能说明](https://github.com/One-Clip/OneClip) 的中文、英文界面能力；沿用本地 One 的布局、系统字体和控件样式。One 仅作只读视觉参考。0.19 候选包及 0.20 独立开发成果保留，本阶段在 `work/next-0.21.0` 实施。

## 用户行为

设置中增加界面语言，提供「简体中文」「English」「跟随系统」。现有用户缺少配置时保留简体中文；跟随系统将中文系统映射到简体中文，其余系统使用英文。界面明确显示当前语言及已保存的下次启动语言。

保存后下次启动统一生效。切换本身不关闭窗口、不退出应用、不重载录制/编辑页面、不清理未保存媒体。用户正常退出并重新打开后，所有窗口、原生菜单和后台任务使用同一语言。外观字号与语言独立保存，界面语言不进入历史备份或设备同步。

应用自有按钮、标签、表单、菜单、对话框、状态、操作错误、无障碍名称、日期和大小格式属于翻译范围。主窗口、快速窗口、托盘、浮动容器、划词、截图、录制、长截图、图片编辑、解锁和恢复均需覆盖。网页访问者拥有独立语言选择，不依赖主机语言。

网页访客默认跟随浏览器语言，也可选择简体中文或 English；中文语言变体使用简体中文，其余使用英文。选择立即作用于当前页面，不重载或重新连接。名称、证书核对选项、已选内容、待发送文字、进行中的请求和重试编号保持不变。偏好只保存在当前来源的 localStorage；不同共享端口属于不同来源，不能承诺下次新共享会话沿用选择。存储被浏览器禁止时，当前页面仍可切换语言。

剪贴板正文、原始格式、HTML/RTF、文件和目录名、来源进程、标签、用户分类、用户模板、脚本内容、AI 输出、证书身份和外部服务原始错误保持原样。应用内置默认示例与用户数据需明确区分；切换语言不会迁移或改写旧历史。快捷键实际组合和数据协议字段保持不变。

## 实现约束

使用本地静态文案目录与明确的翻译调用。带变量的消息使用受校验的占位符，只替换应用文案，保留参数原值。禁止观察已渲染内容并全局替换文字，以免翻译用户剪贴板或路径。初始静态 HTML 只在产品脚本渲染用户数据之前处理产品文案和固定属性。

当前语言在启动时确定。主进程先初始化语言，再加载含显示文案的模块；工作线程继承本次语言。各窗口预加载获得只读的启动语言，渲染代码在初始化界面前设置相同语言。语言偏好读取有大小/版本/枚举校验，损坏时保留原文件并使用默认值；保存使用原子替换且失败不更新已保存状态。

上述启动规则用于桌面窗口。网页只在填入用户内容之前记录原始产品模板的文本节点与固定属性，切换时更新这些节点和明确的动态状态文案；不重新扫描用户内容。静态文本保留原有首尾空白。网页错误通过固定产品错误代码定位文案；接口仍保留原有中文 `error` 字段，新增 `code` 供访客独立翻译，未知代码或旧服务错误保持原文。浏览器语言不进入发送内容、授权或设备身份。

使用 `Intl` 统一日期和数字格式；机器协议、文件扩展名、格式版本、存储键及排序标识不翻译。记录时间仍表示相同时间点，大小仍采用既有二进制换算。需要按照数字数量变化的英文消息使用明确模板，不拼接中文语法。

静态目录检查必须发现缺失/多余占位符、未绑定的产品文案、重复键和空译文。未知外部错误保持原文；产品错误不能靠匹配任意用户内容进行翻译。原生辅助程序应返回稳定的错误代码或在已知消息边界转换，避免改变进程/格式判断逻辑。

## 开发与验收顺序

1. 盘点 TypeScript、静态 HTML、原生辅助程序和界面格式化调用，标记协议常量与用户默认内容。
2. 语言类型、静态目录、占位符和格式化工具，独立偏好与启动传递；先通过纯逻辑和权限检查。
3. 按主界面/设置 → 桌面与媒体窗口 → 数据/共享/文本工具 → 原生提示/后台错误顺序接入，中英目录同步维护。
4. 网页访客独立语言、文档与帮助文案；完成静态覆盖审计，不将部分中文回退视为英文完成。
5. 无界面验证中文用户内容在英文界面保持原样，覆盖大小窗口、150% 字号、键盘焦点、英文长标签和对话框；检查数字、时间及大小格式边界。
6. 在桌面独占确认后，实际验证保存重启、托盘、捕获、锁定/解锁及发布包完整回归。

本方案只定义开发行为，不代表功能已完成；进展以源码、文案覆盖报告和实际验收结果为准。

数据保护补充：历史诊断和外部错误按原值显示；新产生的自有提示使用本次启动语言。锁定异常类型、密码/密钥、文件格式和协议标识不随语言改变。Hello 自有提示可翻译，系统控件及真人交互仍需实机验收。恢复和解锁反馈需完整保留路径，并允许长词换行。

历史与桌面补充：新记录的自动标题按当前语言生成，已有记录、跨语言备份恢复和撤销删除保留保存的标题与预览。缺失或异常的备份标签按实际内容重新生成。模板内置变量名和持久化来源标识不翻译。主窗口及托盘的长诊断支持固定高度内换行与键盘滚动，阅读时暂停收起，避免触发底层历史操作。

捕获与媒体补充：元数据独立进程通过已有环境白名单接收启动语言。实际来源名称、文件名、格式扩展与元数据值不翻译。录制文件名使用独立整行，图片编辑长提示允许内容区滚动，坐标计算继续相对画布位置。

主入口与同步补充：保存的来源标识和设备名不随语言迁移；真实主机名保留原值。已知同步错误使用可选 code，并保留原有 error 字段，新接收端按自己的启动语言显示译文，旧端仍可读取原响应。原生附件自有错误使用固定代码，原有中文兼容字段保留；未知错误不按文本猜测译文。设备名省略时应能悬停查看完整名称。

格式与布局补充：只在显示边界格式化计数、字节大小和记录时间，不改写接口数值、ISO 协议、文件名或源文件元数据。英文侧栏空间应随字号调整，按完整单词换行，暂停恢复和导航提供完整提示；快速面板保持单列。文案绑定审计需区分整条条件键与模板中原文参数，不能仅凭上级存在翻译调用认定已绑定。
