# Clipper 设计与技术方案

## 界面结构

主窗口默认 1180×780，最小 860×600。左侧 208 px 导航：全部记录、收藏、堆栈、拖拽容器、快捷回复、自定义分类、设置。正文采用搜索与类型筛选、可滚动结果列表、选中内容预览。列表/网格可切换；预览显示来源、类型、时间、标签、操作。无数据时只显示实际空状态，不插入示例到用户资料库。

快速粘贴直接复用 TrayPanel 的最近记录 BrowserWindow、受限 preload、轻量查询和预览；不再创建第二个主界面紧凑窗口。关闭/失焦收起，边缘停靠显示时按停靠状态保持，闲置资源释放沿用最近记录策略。主窗口关闭后驻留托盘。原应用窗口句柄由主进程保存，renderer 不接触原生句柄。

## 视觉规范

沿用 One：浅色工作区 #ffffff / 侧栏 #f6f6f6；深色 #181818 / #141414。系统字体 Segoe UI Variable / Microsoft YaHei UI；正文 13 px、辅助 11–12 px、标题 22 px。内容留白 24–28 px，按钮 34 px，图标按钮 32 px，圆角 10 px。低对比度分隔线，普通内容不用重复卡片边框。黑白主操作，Lucide 线性图标，自有 Clipper 标志。保留 Windows 原生最小化、最大化、关闭按钮，标题栏拖动区与交互区分开。

选中项目使用浅灰背景与细边框；类型徽记只用少量低饱和色。图片在固定比例预览区 contain 显示。全文、文件列表单独滚动，长路径不撑开窗口。按钮包含可访问名称；所有交互具有键盘焦点；减少动态效果设置生效。

## 模块架构

```text
renderer  历史/预览/堆栈/模板/设置
    │ 固定类型接口；无 Node；禁止远程网络
preload   contextBridge / IPC
    │ 主窗口主框架校验 + 参数验证
main      窗口、热键、托盘、剪贴板、备份
    ├─ store      SQLite、事务、去重、保留策略
    ├─ native     Koffi / Win32 序列、所有者、文件格式、焦点、SendInput
    └─ shared     数据类型、分类、过滤、容量和校验
```

与 One 一致使用 Electron 44.5.1、TypeScript、原生 DOM/CSS、esbuild、Koffi。锁文件固定依赖。Electron 44 使用异步 ClipboardItem API；不能复用旧同步剪贴板调用。SQLite 使用运行时内置 node:sqlite，WAL、schema version，写入事务；当前数据量上限下保持查询简单，有持续卡顿证据时迁移 Worker。

## 数据模型

- clip：UUID、内容哈希、类型、文字/HTML/RTF/图片/路径、来源进程、创建/最近复制时间、收藏、置顶、标签。内容按 JSON 存储为单记录，索引字段独立保存。
- snippet：UUID、标题、类型、payload（文字/图片/文件）、缩略图、更新时间；兼容 v1 的 text 字段。
- queue：有序 clip ID 列表；删除 clip 时同步移除；排序与消费持久化。
- shelf：有序图片/文件 clip ID 列表；保护其不被自动保留策略或普通清除删除。
- categories：UUID、名称、颜色、类型/内容/来源/标签组合条件，仅作为动态视图。
- settings：主题、视图、数量/天数、暂停、排除应用、热键、开机启动。
- backup：format + version + exportedAt + clips + snippets + categories。导入只合并内容，避免导入备份意外改变本机热键、开机启动和隐私设置。

## 剪贴板捕获与回写

先检查序列和暂停/排除/隐私标记，再读取支持类型。读取前后序列变化则丢弃本次并重试最新状态，避免拼接两次复制的数据。主进程串行化捕获、回写和导入。优先文件引用；图片与文字的并行表示共同保留，富文本可独立存在。按内容哈希去重。自身回写更新已处理序列，避免循环。

CF_HDROP 通过 Win32 数字格式 15 读取/写入；不把文件路径当命令。内存分配交给 GlobalAlloc，SetClipboardData 成功后由系统持有，失败时释放。粘贴前逐项确认路径存在。

自动粘贴流程：捕获外部窗口 → 写入剪贴板 → 隐藏本窗口 → 恢复目标窗口 → 等待修饰键释放 → 再次确认焦点 → SendInput Ctrl+V。无目标、目标销毁、焦点变化或输入失败均不消耗队列。避免注册普通 Ctrl+V。

## 持久化与安全

持久化只写本应用用户目录。核心不调用网络。renderer sandbox/contextIsolation 开启，nodeIntegration 关闭；固定 preload 接口、CSP、自定义 app 协议、禁止导航/新窗口/权限申请。HTML 只展示为文字；图片仅接受 PNG 数据 URI；导入字段逐项检查、限制数量/长度/总体积，事务提交。

数据库和导出文件包含明文历史，界面明确说明。后续加密必须先设计恢复、迁移与备份密钥策略，不把单一磁盘加密开关描述成完整隐私保护。备份导出由用户选择位置，取消不产生文件。

## 进阶模块的接入点

OCR 从选中 PNG 或截图生成文字，通过正常新增记录入口入库。AI 操作显式选择记录与服务，在线发送前展示发送内容和服务，密钥通过系统安全存储。脚本独立进程且默认无文件/网络能力，设超时与输出大小限制。同步只接收版本化内容消息，经配对授权与校验后走同一导入入口，使用来源设备与逻辑时间解决冲突。

## v0.2 系统服务

OCR 通过静态 PowerShell 脚本调用 Windows.Media.Ocr，独立进程执行，30 秒超时，输出上限 4 MiB，可取消。图片写入本应用临时目录，完成/失败后清理；脚本在发布包中解包，带 UTF-8 BOM，兼容 Windows PowerShell 5.1。语言标识经过白名单格式与已安装列表校验，不拼接 shell 命令。

CaptureService 使用 Electron desktopCapturer 按 display_id 选择屏幕。先隐藏主/快速窗口，再捕获 PNG；区域截图使用独立全屏覆盖窗口和只有 data/complete 的 preload。基于实际 PNG 尺寸与覆盖窗口内容区域换算裁剪坐标，拒绝越界与非有限值。截图取消/异常均恢复原本可见的应用窗口，取消不写历史。

外部拖入只由 preload 的 webUtils.getPathForFile 将真实 File 转为路径；主进程验证存在性、文件数量和图片头尺寸，再解码。原生拖出只接受已存储项目 ID；文件传原路径，图片生成受配额控制的临时 PNG。退出时清理本次生成图片，启动时清理符合专用命名规则的遗留图片，绝不递归删除用户目录。

批量修改在 SQLite 事务内执行，超过标签/堆栈/容器限制时整体回滚；变量只做字符串替换，不执行表达式；自定义分类按文字字面值匹配，不执行正则或脚本。

## v0.3 文本服务

AIService 管理配置、密钥与并发请求；独立 ai-transport 处理非流式 JSON 协议，限制响应长度和重定向。发送与取消不占用剪贴板串行队列；配置及结果应用仍串行提交。revision 与实际请求地址绑定预览，expectedHash 防止结果覆盖期间的新编辑。工具界面左右展示输入/结果，主动应用结果才修改剪贴板或历史。

ScriptService 为每次任务启动 utilityProcess，内部 QuickJS WebAssembly 不注册宿主接口。引擎限制时间、堆和栈，父进程超时终止，输出二次校验。导入脚本先完整校验再写元数据，脚本备份与历史备份分离。

IntegrationService 将外部 URL 解析为有限动作；renderer 展示确认后主进程执行，关闭确认等待取消完成再检查下一条请求，避免取消与状态刷新竞争。密钥、脚本、协议边界详见《文本处理设计》。本版沿用 schema 2，通过元数据保存新配置，不改写原历史结构。

## v0.5 局域网同步

独立同步页面沿用 One 的侧栏、区块和浅深主题。SyncService 管理设备、网络与配对，SyncLedger 管理共享发布和删除标记，传输层负责证书固定、请求限额与超时。网络等待不进入剪贴板串行写队列，实际应用记录使用队列与 SQLite 保存点。SQLite schema 升级为 3，阻止不了解共享记录保留规则的旧版直接打开；同步目录与加密设备配置保存到 meta，历史备份不导出身份或信任关系。

共享记录获得自动清理保护，手工删除传播到已知发布。编辑产生新发布，避免覆盖另一设备的并发编辑。恢复资料副本会清除同步身份、信任和目录，去除共享标记，之后需要重新配对；避免克隆旧设备身份或自动连接旧网络。详见《局域网同步设计》。

## v0.4 数据管理

StorageManager 在固定用户目录保存位置配置，数据库可迁移到本机空目录。使用 SQLite 一致快照、完整性与内容哈希校验，先写目标再提交位置；所有引用 Store 的服务随后切换。原数据库保留，配置或目标不可用时不新建空历史。

BackupManager 管理计划、保留、加密导出与恢复预览。备份 v3 增加脚本，导入时所有内容和脚本在同一事务提交。加密使用 scrypt + AES-GCM，自动密码使用 DPAPI。写入采用同目录临时文件及原子替换；成功恢复演练后再清理本资料的自动备份。取消/过期会清理预览，确认仅使用已验证快照。完整格式和故障边界见《数据保护设计》。

## v0.6 网页共享

WebShareService 独立于长期设备同步；会话、证书和凭证不写数据库。浏览器页面单独构建到 dist/web，仅由限时 HTTPS 服务发布固定资源，不暴露 Electron preload。带 Bearer 令牌的流式通知只携带版本号，按需请求纯文字/PNG，刷新或断开后清除内容。

共享池缓存有限的安全元数据，以本机 ID、内容哈希和随机网页 ID 绑定。数据库观察者在事务后检查撤回；列表协调只查询 ID/哈希，避免持续复制完整图片。网络等待不占用剪贴板队列，接收在队列中再次检查会话后通过保存点写入；重复内容保留原记录权限，新记录标为仅本机。详细协议与边界见《网页共享设计》。

## v0.7 历史保护

HistoryVault 管理密码/恢复密钥/Hello 包装；StorageManager 以先创建和校验副本、后原子切换的方式启用加密，原明文副本由用户确认后清理。Store 通过统一数据库接口连接 Node SQLite 或 Multiple Ciphers。

独立解锁窗口仅暴露受限接口。锁定先隔离 IPC 与窗口、停止网络和后台任务，再关闭数据库并清理密钥；会话代次拒绝已排队的旧请求。系统空闲按 Windows 全局输入空闲计算，不以剪贴板写入延迟锁定。加密仍使用 schema 3，旧版不能解码加密页。详见《历史加密设计》。

## v0.8 桌面交互

新增 DesktopController 负责快速面板几何、悬停计时、显示器变化与浮窗生命周期。使用 Electron 的工作区/DIP，Win32 查询鼠标键及前台窗口；默认关闭自动呼出，以 120 ms 检查触发区，避免全局鼠标钩子。专用 shelf preload 只公开容器操作；主进程校验窗口、frame、URL、成员及锁定状态。独立元数据保存本机桌面偏好和位置，卡片排列供主窗口与快速面板共用。详见《桌面交互设计》。

## v0.9 选区处理（历史方案，0.50.0 已移除）

用户在 0.50.0 要求全面删除划词菜单。下述历史实现及对应源文件、原生程序、窗口、接口、快捷键、构建资产和测试均已退役，文本工具中的 AI、翻译、脚本仍保留。

SelectionService 管理鼠标释放、快捷键、选区代次、受限操作条及文本工具交接；SelectionReader 通过有界 JSON 标准输入输出调用独立 .NET Framework UI Automation 进程，2.2 秒超时后终止。辅助程序仅查询当前窗口选区与 IsPassword，不使用剪贴板或整篇文档回退。动作重读选区，实际入库/回写前再次核对代次，避免排队过程中已取消的动作执行。菜单不持久化选区；锁定销毁窗口、取消读取并清除等待文本。可见区域使用 DIP 与物理像素转换，配置存于本机元数据。详见《划词菜单设计》。

## v0.10 录制模块

独立非持久 session、受限 preload 与媒体权限；主进程重取并校验来源，renderer 只取得显式选择的屏幕/窗口与声音。Chromium MediaRecorder 编码 H.264/AAC MP4 或 AAC M4A，Web Audio 混合系统声音与麦克风。

RecordingService 管理会话代次、来源、心跳、生命周期与保存，RecordingFile 对每段 AES-GCM 加密并维护范围索引；预览只在专属 session 通过令牌读取，支持 Range。临时密钥不持久化；导出逐段解密，同目录临时文件写完后用 Windows 不替换目标的移动操作提交，保护已有文件。复制文件操作在真正写剪贴板前重验会话。

窗口沿用 One 的 Segoe UI、Lucide、浅深主题和原生标题栏；准备页、紧凑录制控制及深底媒体预览分为三个状态。区域录制和长截图独立规划，详见《录制设计》。

## v0.11 区域与拼接

CaptureService 共用冻结选区覆盖层与实际屏幕快照，输出屏幕签名和归一化区域；取消代次阻止迟到捕获和窗口重显。录制通过独立视频/Canvas 流裁剪后编码，释放时统一停止绘制与媒体轨道。

ScrollCaptureService 使用独立非持久 session、受限 preload 和图片预览令牌。原始 BGRA 帧、拼接图、一次撤销与待对齐画面只在内存；重叠分析与 PNG 编码在有超时的工作线程执行。像素抽样寻找垂直重叠，二次密集校验和重复图案判断降低错误拼接；不确定结果需手动确认。文件提交使用不替换目标的原子移动，历史提交在主队列中复验会话。

## v0.12 窗口截图与编辑

CaptureService 通过短期选择令牌、Win32 窗口身份和实际窗口快照完成独立窗口截图。缩略图候选与提交分别校验，取消代次阻止迟到写入。ImageEditorService 使用独立非持久 session 和专属 IPC，原图仅通过临时 URL 在该会话内提供。Renderer 保留有界操作序列，通过 Canvas 重新渲染实现原尺寸裁剪、变换与标注，撤销不存储整幅图像副本。保存输出经过主进程 PNG、容量、像素与原记录身份校验，主队列完成历史或剪贴板提交；导出使用同目录暂存和不覆盖移动。详见《图片工作台设计》。

## v0.13 格式与信息

白名单格式由 Win32 有界读取，Electron 负责兼容内容解码；原始表示纳入统一 Payload 校验、去重与容量预算。复制预分配 HGLOBAL，在单次剪贴板锁内提交原数据及 CF_DIBV5 兼容图。ContentInfo 按需读取格式/文件信息，原始导出使用同目录暂存与新文件提交，会话或记录失效即取消。数据库/备份升级为 4；同步按能力过滤和延后扩展条目，网页仅提供重新编码的 PNG。详见《格式保真设计》。

## v0.14 附件管线

独立 STA AttachmentHost 通过 OLE IDataObject 读取文件组描述与按索引提供的内容；主进程给辅助进程分配 Windows Job，限制内存、时间、输出和生命周期。HGLOBAL 按声明内容长度读取以避开分配填充；IStream 分块累计；IStorage CopyTo 进入有界 ILockBytes。读取前后与各附件之间复验序列/隐私，主进程提交前再验会话。

结构化 attachments 与其他 Payload 表示互斥，经统一校验进入 Store。AttachmentFiles 只创建专用缓存的直接 UUID 子目录，清理验证真实根目录且不跟随子链接；总量与空文件组数受限，取消代次阻止迟到物化。被占用文件计入预算并重试清理，不阻止启动。另存使用独占暂存、记录身份复验和不覆盖移动。详见《虚拟附件设计》。

## v0.15 内部信息读取

ContentInfo 将来源/原格式与按需内部信息分为两个页签。MetadataService 从已校验历史选择原字节或本机引用，每次启动独立 utilityProcess；开始和返回前校验记录哈希与会话代次。父进程施加 15 秒期限、192 MiB JS 堆与 512 MiB Windows Job 内存上限，读取不进入剪贴板串行提交队列。

本机文件逐级持有禁止重命名的目录句柄，拒绝重解析点、网络盘及离线文件；源文件仅允许读取共享。图片/PDF/Office 最多 64 MiB，媒体最多 2 GiB，媒体由流式库读取并对无音轨 MP4 补充有界箱头解析。Office 仅解析限定的 ZIP 属性 XML，不解压至磁盘。结果经过字段白名单、文本大小和会话复验后显示为纯文本，不持久化。详见《内部信息设计》。

## v0.16 效率与快捷键

EfficiencyService 将最近搜索和本机快捷键存于现有 meta 表。搜索在 blur 或使用结果时提交，组合输入期间跳过；主窗口与紧凑面板共用数据库。Renderer 的快捷键录入控件使用物理键位并暂时暂停本应用的全局键，失焦、Esc 或关闭后恢复。

HotkeyRegistry 统一管理入口及模板热键：规范化组合、检查重复、预先占用新增键，全部成功才更新已有回调与释放旧键。模板及绑定在 SAVEPOINT 中保存，注册失败回滚数据库；启动采用逐项报告和保留可用键的模式。

模板热键触发时捕获 HWND/PID；待填写操作持有短期令牌、模板内容指纹及原目标身份。确认在串行队列中复验模板，写入剪贴板及 SendInput 前复验会话和窗口进程。锁定、迁移、休眠或退出取消待填写操作，锁定时注销模板热键。细节见《效率功能设计》。

录制回归修复：renderer 为来源枚举维护请求代次，选择区域时使已有请求失效并暂停新的枚举；只在空闲且代次匹配时应用结果，防止捕获期间返回的空列表清空已选来源。

## 堆栈规则服务（0.17）

StackService 管理本次收集代次、AND 筛选、批量快照与确认期限。主采集流程先遵守暂停/应用排除/隐私标记/序列一致性，再将成功历史交给当前代次的收集会话。停止可立即撤销迟到的读取；规则转换与队列追加在同一 SQLite savepoint 内完成，失败同时恢复数据库与内存队列。批量确认绑定来源哈希、私密状态、规则和队列，2 分钟释放预览。仅本机文本派生不解除隐私，冲突共享内容整批拒绝。详见《堆栈规则设计》。

## v0.18 层级附件

Attachment 以相对路径和显式 directory 标识保留文件树，统一校验原始描述与隐式父目录，不改变旧平面附件的字段顺序与哈希。原生辅助进程先检查整个描述树，再按原 lindex 读取文件内容，跳过目录。schema/备份 6 区分新语义；旧版备份只允许平面附件。

writeAttachmentTree 统一生成完整目录，检查根与父目录身份和真实路径，独占创建文件，内容完成后设置目录时间。缓存只发布根路径；导出在目标同级随机目录完成后，以不替换目标的移动操作提交，失败仅清理本次暂存。系统锁定/休眠推进会话代次，恢复不会重新授权旧导出或复制。详见《虚拟文件夹设计》。


## v0.19 托盘面板

TrayPanel 独立窗口与专用预加载仅开放查询、预览、使用、拖出、关闭和回主窗口。TrayHistory 查询去除 payload/thumbnail，只为最新 80 条匹配项签发短时令牌；操作绑定记录内容哈希、查询代次与窗口会话。原窗口记录 HWND/PID 并在粘贴前复查。Windows 前台窗口轮询补充 Electron blur，连续失焦约 450ms 收起；已确认的粘贴/拖放期间由会话有效性控制。schema/备份仍为 6、同步仍为 4。
