# 托盘快捷面板（v0.19）

## 需求与交互

参考 OneClip 公开说明中的菜单栏最近项目、分类搜索、悬停预览及复制/粘贴/拖出；Windows 使用任务栏通知区入口。样式沿用本地 One 的 Segoe UI、Lucide 图标、浅深中性色、细分隔线和圆角。

左键托盘图标打开或收起独立面板，右键保留暂停、主窗口、锁定和退出等控制菜单。面板按最近使用时间显示记录；搜索正文、来源、标签及文件相对路径，支持类型、收藏和已有自定义分类。最多显示 80 条匹配结果，并明确提示可搜索缩小范围或打开主窗口。

左侧列表，右侧悬停/键盘选择的预览。文字只作为纯文本显示，最多预览 32,768 字；图片在框内适应显示；文件/虚拟目录只展示名称、层级和保存状态，不读取磁盘内容或生成临时文件。复制、粘贴和拖出仍使用完整原内容。预览不执行 HTML、脚本或外部链接。

左键记录复制，右键记录粘贴；预览区同时提供有文字的复制/粘贴按钮。方向键移动选择，Enter 复制，Ctrl+Enter 粘贴，Esc 关闭，Ctrl+F 搜索；输入法组合期间不触发这些操作。图片和文件允许原生拖出。完成复制/粘贴或拖出后收起。首次打开不自动复制任何记录。

面板定位在托盘图标附近，并限制在对应显示器工作区内，兼容上/下/左/右任务栏和负坐标显示器；小工作区使用可滚动的紧凑布局。不会因鼠标经过托盘图标自动暴露历史。

## 数据、目标窗口和生命周期

使用专用受限 preload，主进程逐项校验窗口、主 frame 和页面 URL。仅面板可调用预览/操作接口；隐藏、关闭、锁定、休眠、资料切换、退出后撤销会话。每次查询为显示结果签发短期行令牌，绑定记录 ID 和内容哈希；查询改变、删除/编辑原记录或旧窗口重开后不能使用旧令牌。预览返回有限的展示模型，不返回附件原始字节、HTML/RTF 或内部服务配置。

搜索从数据库投影正文和路径，不把全部图片/附件的 Base64 读入 JavaScript。只发送当前最多 80 条摘要。正文、搜索及预览仅在面板存活期间保留，不另建历史或持久缓存；历史本身仍遵守已有本机加密、保留及隐私标记规则。

打开前保存外部目标 HWND/PID，过滤任务栏、托盘溢出菜单和桌面等 Shell 窗口。粘贴前及写入期间重新确认目标进程与会话；没有有效目标时仍可复制，粘贴明确提示。操作一旦点击可以完成必要的异步文件生成；Esc、锁定、休眠、切换资料和退出撤销操作。失焦只收起未开始操作的面板，防止自动粘贴自己触发的窗口切换取消已确认操作。

截图或其他捕获流程隐藏面板并撤销未开始的请求；主动录制/选区捕获、快捷键录入或资料切换时拒绝打开。锁定销毁窗口，解锁不会自动恢复预览。原生拖放和复制仍受来源存在、容量及取消检查约束。

## 验收与交付

先验证排序、筛选、Unicode 搜索、上限、布局边界、纯文本/有限预览、行令牌失效与记录替换。再使用隔离资料验证真实托盘入口、悬停、键盘、复制/原窗口粘贴、拖出、删除或查询变化后的旧操作拒绝、锁定/休眠/资料切换/截图清理、浅深主题和多种窗口尺寸。

最终在同一发布二进制上运行全部回归并核对哈希，交付源码、可运行目录包、截图、说明及实际限制。受控事件不替代物理热插拔/休眠和所有任务栏配置；未验证场景明确记录。当前 schema/备份 6、同步 4 保持不变。
