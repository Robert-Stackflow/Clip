# 功能交付

日常在当前仓库根目录使用 Electron 开发模式，让界面变更即时可见；不为每次修改生成程序、源码或依赖副本。入口、流程与资料隔离见 [代码与构建管理](代码与构建管理.md)。

每次完成功能项并通过必要验证后，提供完整、已解压的 Windows x64 Electron 程序目录，并链接其中的 Clip.exe。移动程序时保留 resources、locales 和运行库；安装器按安装和更新需求提供。

`release` 只保留最新两个可运行版本。新包校验成功后再清理更旧版本，正在运行的旧程序必须正常退出。源码和版本记录由 Git 保存，报告使用固定目录，不再保存逐版本的 work/dist 快照。

交付前核对程序版本、构建内容及原生组件加载，说明尚未完成的验证，不将未完成的功能计为已交付。
