# 当前状态与待办（0.50.14）

更新于 2026-10-05。当前源码使用一个托盘最近记录窗口；独立“快速粘贴”功能和快捷键已移除。拖放窗口提供简洁与展开两种布局，支持手动打开，以及分别可选的拖动自动显示和顶部中央呼出。托盘菜单、侧边栏、设置和记录刷新已随之调整。具体操作见 [使用说明](../user-guide/使用.md)，改动与验证边界见 [0.50.14 验收记录](../history/验收-0.50.14.md)。
