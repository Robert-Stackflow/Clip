# 当前状态与待办（0.50.16）

更新于 2026-10-07。托盘左键默认打开 Clipper，可在基本设置中选择最近记录、快捷面板、快捷回复或拖拽容器。快捷面板支持分类筛选、快捷回复、原生悬停预览和移动；点击面板外部关闭。拖放窗口支持手动打开、拖动自动显示和顶部中央呼出，置顶与锁定分别设置；锁定后不自动隐藏。容器、堆栈、分类与全部记录共用记录和详情样式，快捷回复提供列表和卡片布局。分类图标、数量、多选栏及设置页面已统一整理，OCR 已移除。本轮范围见 [0.50.16 验收记录](../history/验收-0.50.16.md)，安装器方案见 [0.50.15 安装器记录](../history/验收-0.50.15.md)，日常操作见 [使用说明](../user-guide/使用.md)。
