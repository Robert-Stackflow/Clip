## 维护基线

保持 Clip 剪贴板工作台的现有范围，截图、录制、图片编辑和贴图由 Frame 负责。先复用当前模块和测试入口，行为或架构变化时同步需求、专项规格和使用说明。开发、构建、安装与发布分别核验，流程见 [代码与构建管理](代码与构建管理.md)。

## 后续工作与依赖

| 工作 | 前提与验收条件 |
| --- | --- |
| 真实设备局域网验收 | 两台设备及不同路由/防火墙；核对发现、配对、内容/附件传输、断线和恢复，单机双实例仅作为前置检查 |
| 日常应用兼容性 | 在真实目标应用测试 Outlook 附件、Excel Ctrl+C、Word 富格式、管理员目标和旧代码页终端；记录已验证与未覆盖的边界 |
| 硬件与桌面恢复 | Windows Hello、锁屏/休眠、混合 DPI 多屏热插拔、自动隐藏任务栏及拖动呼出；需要真实硬件和交互 |
| 安装与发布链路 | 干净 Windows 10/11 的安装、升级和回退；补齐签名及公开 Release 链路，发布动作按实际授权执行 |
| 长期运行与故障恢复 | 有限容量及独立测试资料下验证长期驻留、满盘、损坏恢复与高负载内存，不以短时测试替代 |

以上顺序按依赖整理，不代表已获授权实施或已有完成日期。每项以可复现的用例、环境、结果与限制验收，不复制历史未勾选清单。
