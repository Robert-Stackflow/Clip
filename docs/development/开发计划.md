## 阶段 4：v0.4 起，同步与数据保护

先实现自定义存储迁移、定时备份、恢复演练，再实现局域网设备配对、TLS 传输、撤销信任、冲突合并、设备身份和数据删除传播规则。局域网共享必须由用户显式启用；新设备需配对；私密项目默认不发送。同步不能变成任意文件传输或命令执行入口。Windows Hello/数据库加密需配套密钥恢复和升级迁移。

## 持续工程要求

v0.18 后续按以下顺序细化需求与实现（差距明细见《功能对齐审计》）：

1. 内容信息兼容：扩展真实来源照片、媒体和文档样本，补充其他私有标签/格式；保留明确的只读、容量和生命周期边界。
2. 使用效率与格式：继续审计真实来源目录与私有格式、托盘最近项目/预览及字体设置，逐项给出 Windows 等价流程及验收。
3. 中英界面：统一可翻译文案、日期/大小格式、语言切换和跨窗口一致性，再检查两种语言的布局与快捷键提示。
4. 分发与兼容：安装/卸载、更新与回退、签名、干净 Windows 10/11、实际 Office/邮件应用和物理设备测试。需要实际设备或发布凭据的项目保留为明确待验收项。

变更保持 main/preload/renderer 边界。核心行为写自动化测试；样式微调用截图核验。测试使用隔离资料目录，真实剪贴板测试结束恢复原内容，避免写入正常用户历史。发布附实际测试结果、已知限制和依赖许可；只更新已验证的完成状态。
