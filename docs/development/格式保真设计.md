# Windows 格式保真与内容信息

## 范围

OneClip 的公开说明包含图片、音视频、文档及元数据保留。Windows 文件复制沿用原文件路径，不重写文件；剪贴板中的并行表示另外处理。此次补齐 HTML 上下文/SourceURL、RTF 原始字节及常见图片原始编码。未知应用私有格式、OLE 虚拟文件和流式大附件仍在完整参考范围内，不能用此次白名单实现宣称全格式完成。

## 内容模型

保留 text/html/rtf/png/files 的既有字段，新增 formats 数组，每项仅有受支持的 Windows 格式名称与 Base64 原始数据。允许 HTML Format、Rich Text Format、PNG、JFIF、GIF、TIFF 及 image/jpeg、image/gif、image/webp、image/tiff、image/bmp 注册格式。禁止任意注册名、文件描述符、Shell 移动标记、私密标记或执行指令。数组规范排序，原始字节参与去重；相同可见文字但不同来源/格式的记录分别保留。

图片预览按解码后的 PNG 展示，但原始编码独立保存。能解码的格式支持现有图片编辑；无法解码时保留原格式、复制和导出，明确显示缺少预览。编辑或变量替换会生成新内容，不携带与新内容不一致的旧原始表示。

## Windows 读写

读取白名单 HGLOBAL 数据，限制单条及总容量，并通过剪贴板序列检查避免合并不同时刻的内容。复制完整内容使用一次 OpenClipboard/EmptyClipboard 提交已准备的全套数据：Unicode 纯文本、原始或生成的 CF_HTML、RTF、原始图片格式、PNG 及兼容位图。复制纯文本只写 Unicode 文本。不会恢复源应用的文件剪切/移动状态。

原始图片和富文本数据只存储或交给用户选择的目标应用，Clip 不执行 HTML、脚本、RTF 对象或外部链接。信息面板显示实际格式、编码字节量、图片尺寸及 CF_HTML 来源。文件信息按需读取本机路径的当前状态；网络/设备路径不自动访问，不读取文档正文，不假定文件仍与复制时一致。

## 兼容性

数据库标记及备份版本升级为 4，能读取 1–3 版，旧版程序拒绝新资料，避免静默丢失格式。同步增加格式能力协商，旧端仍可同步既有文字/PNG，新格式须升级双方。请求头 X-Clip-Payload-Version 与清单 payloadVersion 识别 v4，旧端看不到扩展条目的清单，直接请求也被拒绝；新端跳过向旧端推送扩展条目并提示升级，兼容条目继续传输。网页共享继续仅提供纯文字/重新编码 PNG，不发送原始格式、PNG 注释和来源元数据。记录、快捷回复、加密备份及恢复需验证字节一致。

原格式另存只允许新文件名，延迟对话框返回时重新确认记录和解锁会话；普通 PNG 编辑结果不冒充原始编码。资料容量仍是单条序列化 16 MiB、总 256 MiB，原始表示与预览均计入预算。

## 实现边界

Windows 位图回放为兼容目标生成 CF_DIBV5，透明度已用真实系统读回检查；不保证源 DIB 头、ICC/HDR 或所有应用私有色彩数据。TIFF 等格式能否预览由当前系统解码能力决定。原始格式名称采用白名单，内容视为不可信的有界数据，不宣称文件签名或嵌入对象安全性校验；不自动打开另存文件。

文件信息仅在用户点击后读取本机盘路径，拒绝直接 UNC、设备、映射网络盘及文件本身的符号链接；父目录重解析点不保证被识别。大小、类型与修改时间来自当时文件系统；尚未解析音视频时长/编码、文档作者或 Office 内部元数据。文件模式不复制文件本体进入数据库。

PNG 原图不重复存入 formats；其他图片保留原始字节和可生成的 PNG 预览。透明图、动画及元数据均以原始字节作为保真依据，预览和编辑结果可能静态化或重新编码。多格式复制在一次剪贴板锁内完成；极少数 SetClipboardData 失败会报错，不保证回滚到操作前的系统剪贴板。
