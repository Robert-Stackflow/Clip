# 桌面交互设计（0.50.14）

主工作台和托盘最近记录各有一个窗口。独立“快速粘贴”功能及其快捷键已移除；最近记录由托盘打开，继续使用轻量查询、预览和原目标粘贴。主窗口关闭后驻留托盘。

## 拖放窗口

拖放窗口读取同一份容器资料，提供简洁小窗和完整窗口两种布局。小窗仅保留拖入提示、条目摘要和展开/关闭操作；展开后可管理条目、拖出、复制和粘贴。切换时窗口尺寸连续变化，过渡期间用遮罩覆盖尚未稳定的组件布局。两种布局共用同一窗口和控件样式。

用户可以通过拖拽容器、托盘或快捷键打开窗口。设置中的两个自动呼出开关互相独立，默认关闭：一项在拖动文件或文字时显示小窗，另一项在按住左键拖至屏幕顶部中央时显示小窗。窗口可保持置顶；手动打开后由用户关闭。自动呼出时保留原应用的拖动上下文。

文件、图片和纯文本可拖入；已保存的文件和图片可拖出。移出容器不删除历史或源文件。窗口使用受限 preload；主进程校验调用窗口、会话和容器成员关系。锁定时销毁窗口并停止自动触发；解锁后不会自行恢复此前的浮窗。

自动呼出目前依据鼠标按键和位移判断拖动手势，不能直接从全局指针事件识别 OLE 载荷；在更多目标应用、混合 DPI、多显示器热插拔和自动隐藏任务栏下仍需实机复核。截图、录屏与录音的进一步优化按用户要求暂缓。
