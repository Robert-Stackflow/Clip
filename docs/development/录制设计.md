# 录屏与录音（v0.10 实施基线）

## 范围与交互

OneClip 路线图包含录屏/录音。Windows 版采用独立录制窗口，沿用 One 的 Segoe UI、Lucide、浅深主题与原生标题栏。先选择屏幕或窗口及声音来源，明确点击开始；纯音频模式可选系统声音、麦克风或混音。暂停、继续、停止、放弃都可见，录制中显示计时、音量与大小。停止后本地播放预览，再选择保存位置；不自动写剪贴板、历史或网络。保存后可主动“复制文件”，将文件引用加入历史并写入 Windows 文件剪贴板。

本批目标是屏幕/窗口录制与纯音频，以及系统声音/麦克风混音、权限与资源边界、预览和文件导出。区域录制、其他导出格式、长截图后续独立实现，不能把本批当作全部进阶能力完成。

## 捕获与编码

专用、非持久 Electron session；固定录制页面和 preload。desktopCapturer 提供真实屏幕/窗口列表，不把任意 renderer 提供的源 ID 当作授权。只有用户选择并开始的一次性会话可请求 getDisplayMedia；权限回调校验主 frame、窗口、URL、状态、声音开关及次数，禁止摄像头与其他权限。系统声音使用 Windows loopback。纯音频系统采集的占位视频来自录制页面自身，丢弃视频轨道，不录屏幕。

麦克风仅在主动勾选并开始后调用 getUserMedia；录制范围内的音频用 Web Audio 混合。音频不回送扬声器，避免回声。缺少请求的轨道必须报错，不能悄悄生成无声录像。停止、来源消失、失败、窗口崩溃和取消均释放所有媒体轨道与 AudioContext。

使用 Chromium MediaRecorder，实际探测 H.264/AAC MP4，音频为 AAC M4A；只在编码器可用时开始。已取得真正的 Windows 窗口画面及 loopback 音频轨道，并验证 MP4 文件可解码。15/30/60 fps，最长边限制 1920 或 2560，码率和时间有上限。分段传入主进程落盘，有序编号与单段/待写队列限制，避免整段内容常驻内存。不把 MP4 容器默认的 VP9/Opus 当作 H.264/AAC；主动指定并验证实际 MIME 编码。

## 文件与生命周期

未保存片段以独立 AES-256-GCM 加密写本应用临时目录，随机密钥只存本会话内存；主进程提供受会话令牌保护的流式 Range 预览。临时目录不进入内容备份。默认单段上限 8 MiB，总上限 1 GiB、最长 60 分钟；接近时间或大小上限时正常停止并预览；磁盘不足、编码或写入失败则明确报错并清理不完整暂存。错误不能生成看似完整的成功文件。

主动另存时才流式解密到用户选择的媒体文件。导出文件为明文，界面明确提示不受历史加密保护。禁止覆盖历史数据库、密钥、配置及暂存目录；写入新文件并同步落盘，完成后才报告成功。取消保存对话框保留预览。仅保存为新文件。使用同目录暂存与 Windows 不替换目标的移动操作提交；即使目标在选择后出现，也不会覆盖。可处理的保存错误和取消只清理本次临时文件；保存中强制结束进程或断电可能在用户选择的目标目录留下 .Clip-export-*.part 明文片段，不能承诺故障时已删除。

有未保存录制时阻止数据目录迁移或历史加密转换，提示先保存或放弃。锁定、休眠及退出停止采集并销毁预览、清除密钥和暂存；不恢复旧录制。关闭有未保存内容的窗口给出保留/放弃选择。应用主动退出有未保存内容时提示。主进程监测心跳与来源结束，避免 renderer 停滞后无限捕获。启动只清理本模块专用命名的遗留加密片段，不扫描或删除用户媒体目录。

## 验收

实际屏幕/窗口录像必须可播放、包含预期画面变化，暂停期间不增加录制时长，音频轨道/系统音测试要检查非静音信号。麦克风测试夹具与真人硬件测试分别标注。覆盖来源断开、权限拒绝、磁盘/容量、乱序片段、超时、保存取消/冲突、锁定、迟到结果、窗口崩溃与退出。发布包重跑原有剪贴板、加密、备份和同步回归，检查新模块不放宽原有窗口权限。
