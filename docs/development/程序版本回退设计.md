# 完整程序版本回退

0.26 开发阶段。继续沿用 One 的分类设置、列表、行内操作及确认预览。应用更新页增加旧版本列表，显示实际版本、时间和容量，不使用装饰性说明。

更新辅助程序在应用正常退出后，保留旧程序完整文件、自己的两组 HKCU 安装登记、开始菜单项，并将归档与安装前数据恢复点配对。先验证并发布归档，再启动安装引擎；失败时仍由安装器恢复原程序，只有旧程序完整树仍一致时才删除该次失败归档。归档逐文件记录 SHA-256，拒绝链接、未知文件和改变的内容。自动保留三个不同版本的有效归档；其关联数据恢复点在归档删除前保留。此前版本没有保存的旧程序不能补出；从支持归档的版本完成应用内更新后才会有可回退记录。

回退先校验程序及关联恢复点，要求解锁旧加密资料；当前资料要求加密而旧点为明文时，必须设置新密码并保存新恢复密钥。准备独立资料目录，保留旧数据库格式，暂停记录、自动备份和同步。预览不切换当前资料。提交前额外保留当前数据和程序，便于后续恢复。

应用正常退出后，独立辅助程序再次检查归档、资料、当前程序和资料指针。旧程序先复制到安装盘上的暂存目录；原程序目录保留后再切换程序文件、安装登记及最后的数据指针。每一步写入持久化事务记录；失败恢复原程序、登记及指针。进程中断后可由归档内的辅助程序恢复，Windows 下次登录时的独立恢复入口负责未完成事务。完整提交后才打开旧程序。

测试使用独立安装身份、临时程序及合成数据库，不操作日常安装、剪贴板、物理键鼠或用户历史。生产构建不允许测试安装位置或登记参数。真实 GitHub 正式发布、完整系统断电与干净 Windows 验收另行记录，不以模拟更新替代。
