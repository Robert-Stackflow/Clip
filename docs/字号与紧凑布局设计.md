# 字号与紧凑布局（0.20 开发方案）

功能依据 OneClip 可配置阅读体验，视觉参考本地 One 的 Segoe UI、浅深主题、细边框和舒适/紧凑密度。0.19 候选包正在等待剩余桌面验收；本阶段在独立开发目录实施，不替换候选包。

## 需求与交互

设置的外观区域增加「字体与密度」入口，使用现有弹窗样式。提供默认、无衬线、等宽三种字体，100%、110%、125%、150% 四档字号，舒适/紧凑两种间距。默认保持现有大小和风格；预览样例同时包含中文、英文、数字和路径。选择项只改变样例，保存后同步到所有当前窗口；取消不改变已保存外观。提供恢复默认选项。

字号只缩放文字，字体采用本机固定白名单，不接受 CSS 或字体文件路径。代码、脚本、密钥等有语义的等宽文本继续使用等宽字体；图片、录制分辨率、截图坐标、DPI 和窗口缩放不改变。字号设置应用到应用自有窗口，包括历史、快速面板、托盘、浮窗、选区、录制、图像编辑、解锁与恢复。网页共享的访问者保留浏览器自己的设置。

紧凑密度缩小列表和表单留白，保留清晰的按钮点击区域与键盘焦点。860×600 主窗口内优先保留正文，复制和粘贴始终可达；其他操作可在独立滚动区域访问，记录信息可展开查看。详情整体不与结果列表共用滚动条。

## 实现

外观属于本机偏好，独立保存到应用配置目录的 appearance.json（版本 1），不放入剪贴板历史、历史备份或同步内容，确保历史加锁和启动解锁页面仍可按用户选择显示。读取有大小限制，损坏配置回退默认并在设置界面提示；写入采用临时文件和原子替换，失败时内存设置不改变。

纯模块校验固定枚举和值。只读外观 IPC 限于应用自有、白名单协议页面的主框架；普通剪贴板历史接口权限不扩大。更改接口仅开放给主界面。预加载只提供读取及变化订阅，渲染端用固定映射设置 CSS 变量和密度属性。所有自有样式的文字大小使用缩放变量，媒体像素和坐标使用原来的数值。

详情布局需同时覆盖文字、图片、文件夹、堆栈、模板以及搜索/批量工具栏。尽量保留已有操作编号，避免使既有功能不可达。必要时用可展开记录信息和有界滚动操作区释放预览高度。

## 开发与验证顺序

1. 外观参数、兼容默认、独立保存与损坏/写失败处理。
2. 独立只读外观桥接、所有自有窗口订阅与主界面设置弹窗。
3. 字体缩放和紧凑布局，重点修复小窗口详情正文高度。
4. 不占用系统键鼠或剪贴板的逻辑与无界面浏览器验证：字号/字体/密度组合、浅深主题、主要视图、860×600 和常见面板尺寸、按钮可达和横向溢出。
5. 用户确认桌面可独占后，验证真实多窗口同步、保存重启、加密锁定/解锁、托盘与拖放、媒体坐标不变，并完成最终包回归。

无界面测试不替代原生窗口/DPI、实体输入法或系统剪贴板验证。本方案不将任何历史未验证项标为完成。
