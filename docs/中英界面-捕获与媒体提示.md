# 0.21 捕获、媒体与内容信息双语

2026-10-01。独立开发记录，完整中英双语和实际 Windows 发布验收尚未完成。

## 功能行为

截图、窗口选择、图像编辑、OCR、录屏录音、录制文件导出、长截图拼接及照片/媒体/PDF/Office 内容信息的自有提示使用本次启动语言。14 个后台文件接入显式翻译，新增 OCR 错误代码表，补充 168 条英文文案。

内容信息解析进程通过原有环境变量白名单接收 CLIPPER_UI_LANGUAGE；没有继承主进程其他环境变量。解析线程使用启动语言处理自有错误，结果字段、原始作者/标题、字节内容及文件名保持原值。剪贴板图片没有实际文件名时，显示用的“原图.png”或“原图.扩展名”按语言生成；扩展名和解析器选择保持一致。

OCR 辅助程序的图片不存在、语言未安装两类自有错误附带固定代码，由主程序选择译文。旧中文 error 字段保留以兼容旧调用方；未知代码和 Windows 原始错误保持原文。识别文字、OCR 语言标签及系统提供的语言名称不翻译。没有通过任意外部错误文本匹配译文。

实际窗口标题和捕获对象名称保持原值，来源令牌、进程身份及权限检查不变。MP4/M4A/PNG 格式、文件扩展名、字节、录制加密和不覆盖已有文件的提交方式不随语言改变。取消、超时和锁定清理仍使用原有流程。

## 界面修复

截图复核发现 OCR 的长错误提示被两侧按钮挤成窄列，录制文件名也被挤在按钮旁；图片编辑反馈元素被压缩，文字超出窗口底部。首轮仅检查控件可达性和横向溢出未发现全部问题，补充文字可读宽度及完整高度检查后确认缺陷。

OCR 提示现位于按钮下方并使用整行宽度，录制文件名位于操作按钮上方；图片编辑保留提示的自然高度，内容区域可纵向滚动。完整消息和文件名不截断。修复前截图及检查结果保存在 work/language-media/before-readability-fix。

## 验证范围

- 239 项逻辑检查通过，包含新增 12 项捕获/媒体检查：图片、音频、PDF 和 Office 原始值与字节；录制加密、取消和不覆盖已有文件；实际元数据/拼接工作线程语言；OCR 固定代码与未知错误；窗口身份、权限、原始名称、PNG/M4A 导出及缓冲清理。
- PowerShell 只执行从实际辅助程序提取的错误处理函数，不启动真实 OCR 引擎。Electron 窗口、截图、麦克风及 Win32 捕获接口使用模拟对象；文件导出只操作本批隔离的测试文件。
- 48 组实际构建页面检查通过：中英文、6 个提示场景、浅深主题、100%/150% 等宽字体。检查文字完整性、控件可达性、HTML 字样保持文字，以及图片编辑滚动后的裁剪、撤销/重做和 PNG 导出尺寸。
- 因主窗口 OCR 和媒体窗口样式有调整，重新执行既有 192 组英文窗口布局，以及中英文对话框交互回归，均通过。其余无变化的历史、共享等布局矩阵未重复执行。
- 类型检查、构建、文案范围检查及源码审阅通过。源码审阅比较 14 个既有 TS 文件和 OCR PowerShell，仅允许显式翻译、三处变量模板、语言白名单传递及 OCR 错误代码识别；新增共享错误表另由边界检查覆盖。

文案目录共 1455 条，112 个已审阅 TS/HTML 文件及两份标签表、1704 处引用无缺失；仍有 106 条不同候选文本需要审阅，包含应保留的标识和示例，全应用完成标记为 false。

检查命令：npm test；npm run check:language；npm run test:language:media。本批证据位于 work/language-media 和 work/*-media-language-0.21.log。无界面检查不替代真实 Windows OCR、媒体编码、麦克风、混合 DPI 或发布包验收。
