# Clipper 0.30.0

本轮在 0.29 的全部页面重构上继续统一 One 组件和动画，并优化列表、容量统计、全文搜索。

| 项目 | 实现 | 验证 |
| --- | --- | --- |
| 分段切换 | One 0.15.2 滑动指示器与委托控制器；字号、尺寸、键盘变化共用 | 双语、减少动态效果、动态挂载、隐藏和禁用按钮 |
| 应用确认 | One dialog 标题、正文和操作栏；120 ms 退出、背景模糊；失败保留操作 | 隐藏 Electron 真实沙箱 IPC；重复关闭、错误 token、Escape、撤销和保存 |
| 表单对话框 | 统一进出场与 Escape 退出；异步保存只关闭原表单 | 保存尚未完成时取消并打开新表单，旧回调不会关闭新表单 |
| 列表与容量 | 可重建的轻量摘要缓存；正文和附件不进入列表解析 | 旧 v7 数据、编辑、重复内容、撤销、事务失败、旧版写入、只读检查 |
| 全文搜索 | 后台 worker 逐条投影搜索字段，返回 ID；窗口独立、替换和锁定取消 | 实际 Electron/SQLite 加密与明文；正文末尾、Unicode、标签、路径、附件名、分类，超时和异常 |
| 搜索交互 | 输入时立即失效旧请求，刷新保留最新资料 | A→B→A 和刷新交错，旧结果不会覆盖当前查询 |
| 构建 | 冷构建显式设置 Rust 静态 CRT 库搜索路径 | 本机完整冷构建和独立打包构建 |

私有生成资料约 114 MB，共 100 条，包含 96 条接近 1 MiB 的长文本及四份 5 MiB 附件。相同 Electron 44.5.1 环境，每项测七次：列表查询中位值从约 119 ms 降至 0.27 ms，容量查询从约 74 ms 降至 0.04 ms。搜索中位值从约 707 ms 降至 510 ms；七次样本的最大值没有稳定改善。搜索完成后该测试进程 RSS 从约 570 MB 降至 59 MB；主线程 JS 堆从约 541 MB 降至 5 MB。此为测试进程完成后的数值，不是全应用驻留或峰值内存。

首次建立摘要缓存约 257 ms，后续打开约 12 ms。搜索进行时每 10 ms 安排主线程列表和容量查询，最大查询用时约 1.47 ms；定时器最大间隔约 16.22 ms。结果只代表此私有工作负载，不能推断所有机器及全部操作。

310 项逻辑、348 项布局、120 项页面、16 项 One 控件比对、16 项搜索外观、48 项媒体反馈、144 项通知检查通过；新增四组双语/动态效果交互与九组原生搜索验证通过。语言检查覆盖 137 个文件，未绑定项为零。打包验证报告另含加密恢复、既有文件同步、Rust 文档解析、重复堆栈和实际字体服务。

One 与已运行 Clipper 仅作只读进程快照，未控制窗口状态或工作负载，不能直接比较驻留内存。真实系统剪贴板、物理键鼠、双设备、硬件录制和干净系统没有在本轮重新测试。构建后的程序没有签名或公开发布。

运行完整目录中的 Clipper.exe。移动程序时保留整个目录；先从旧版托盘退出以释放单实例与快捷键。原始项目及旧版交付未覆盖。
