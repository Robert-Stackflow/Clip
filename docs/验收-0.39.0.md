# Clipper 0.39.0

直接运行 `Clipper-0.39.0-win-x64/Clipper.exe`，保留整个程序目录。先从旧版托盘退出，再打开这一版。

本轮继续按 One 0.16.9 的真实组件实现整理界面。十个桌面入口现在共用一个公共样式文件。全部记录、最近记录和网页共享直接生成同一个搜索组件，取消运行时套框。分类、OCR、录制和内容信息的分段选择直接带有 One 的组件结构。

逐项比对后修正了旧样式造成的输入行高、聚焦边框、设置导航字号和内边距、设置行间距偏差。复用搜索历史时，清空按钮也会正确显示。设置切换保留未保存输入，原有截图、录制、复制、图片编辑和确认流程继续工作。

调整清单与来源见 `界面组件核对-0.39.md` 和 `ONE-UI-REVIEW-0.39.json`。

验证包括 370 项逻辑测试、151 个文件的语言绑定检查、18 类组件在明暗主题和四种状态下与实际 One 对照的 144 项检查、348 项页面布局、120 项窗口和组件操作、24 项跨页面搜索、16 项搜索布局、20 项表单与确认、4 项动画和 12 项异步操作检查。

独立冻结源码构建安装目录后，进一步检查实际打包的样式、十个 HTML 入口、沙箱预加载、字体、全文和图片预览、图片保存、加密数据库及既有核心功能。交付程序目录逐文件校验，源码压缩包解压后再次核对。

本轮使用无头页面和隐藏的私有 Electron 宿主，没有使用用户键鼠、系统剪贴板或日常资料。真实桌面的 DWM 像素、完整应用驻留内存和两台设备的实际交互未在本轮测量。程序尚未签名或发布到 GitHub。
