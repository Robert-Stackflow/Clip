# 运行与常用操作

完整目录包中双击 Clipper.exe。移动程序时保留整个目录。关闭窗口后驻留托盘；从托盘菜单选择“退出”才会结束程序。

开发源码可从根目录 Start-Clipper-Dev.cmd 启动；开发资料独立保存，自动记录默认开启，此后保留手动暂停状态。

## 常用操作

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+V | 打开主窗口 |
| Ctrl+Alt+N | 粘贴堆栈下一项 |
| Ctrl+Shift+R | 打开快捷回复 |
| Ctrl+Shift+D | 浮动拖放窗口 |
| Ctrl+Alt+V | 打开快捷面板 |
| Ctrl+F | 搜索 |
| ↑ / ↓ | 选择记录 |
| Enter / 双击 | 粘贴回原应用 |
| Ctrl+Enter | 只复制 |
| Esc | 收起窗口 |
| Delete / Ctrl+Z | 删除记录 / 撤销最近一次删除 |

全局快捷键可在设置中修改，点击输入框后直接按组合键，松开按键即保存。支持 Ctrl、Alt、Shift、Win 修饰键（可用 Win＋单键），以及字母、数字、空格、方向键和 F 键。录入期间使用原生按键捕获，Alt+Space 不会弹出 Windows 窗口菜单；录入结束或失焦后立即恢复正常按键。注册时被系统或其他应用占用会提示并保留原快捷键。左键单击托盘图标默认打开 Clipper，可在「设置 → 基本设置 → 应用」中改为最近记录、快捷面板、快捷回复或拖拽容器。最近记录窗口使用“复制”和“粘贴到原窗口”按钮。主窗口 Enter 用于粘贴，Ctrl+Enter 用于复制。独立的快速粘贴入口和划词菜单已移除，其旧快捷键不再注册。

## 功能入口

快捷面板顶部依次为剪贴板、快捷回复、Emoji、颜文字和符号，支持搜索、分类和最近使用。快捷回复复用主窗口中保存的内容，支持日期、时间及自定义模板变量。点击快捷面板以外的区域会自动关闭面板和预览；面板内的筛选菜单、对话框及预览可继续正常操作。单击内容粘贴到原窗口，右键复制；剪贴板记录也可置顶、收藏或删除，筛选栏提供“置顶”页签。全部记录页与快捷面板均可“清空历史”，会保留置顶、收藏、堆栈、拖拽容器、共享及永久分类记录；可在主窗口撤销最近一次删除或清空。记录列表滚动到底部会自动加载更多内容。在「设置 → 快捷键」开启「拦截 Win+V 系统剪贴板」后，Win+V 会打开快捷面板，自定义快捷键仍然保留。该开关默认关闭并记忆选择；关闭开关或退出 Clipper 即恢复 Windows 的 Win+V 行为。

历史记录支持文字、链接、代码、图片、文件与已保存附件，以及搜索、收藏、分类、标签和删除撤销。堆栈支持逐条粘贴和重复副本，拖拽容器支持图片和文件拖出。

工具分组的「截图与录制」使用截图、录制两个分段标签：截图支持区域、独立窗口与整个显示器；录制页直接选择来源、声音和格式，并操作开始、暂停、停止、预览与保存。截图、录制与图片编辑保存结果到历史。全部记录顶部保留选择、撤销与更多操作；快捷面板和清空历史位于更多操作中。工具分组的「AI与脚本」以 AI 服务、指令、文本脚本三个分段标签管理服务和文字处理工具，操作按钮与标签同一行。连接与分享下的 URI 管理 clipper-win:// 外部请求。设置的数据分组包含当前存储、自动备份、备份记录、恢复与回退；支持导入、导出、加密和目录迁移。局域网同步包含设备配对与文件、附件同步；网页共享按授权开放内容。

指令内置翻译、总结和改写，可复制后修改，也可新建并选择图标、标题和提示词。提示词支持 `{{text}}` 正文、`{{language}}` 目标语言、`{{title}}` 记录标题、`{{source}}` 来源应用、`{{date}}` 当前日期、`{{time}}` 当前时间；`{{tone}}` 等自定义变量会在运行前显示填写项。变量只替换一次，正文中的变量样式不会再次展开。未写 `{{text}}` 时自动附上正文。自定义指令保存在本机，并随备份导出、导入。

「AI与脚本」页面的「AI 对话」按钮打开独立聊天窗口；默认可用 Alt+Space 唤起或收起，在「设置 → 快捷键」中修改快捷键。开发模式也支持全局快捷键。窗口默认置顶并在失去焦点时保持显示，可通过标题栏按钮分别关闭；关闭“保持窗口”后，切换到其他应用会收起聊天窗口。置顶、保持窗口状态及窗口大小和位置会保留；左上角的侧边栏按钮向左展开历史列表。输入区的模型菜单分为两栏，左侧选择 AI 服务、右侧选择该服务的模型；菜单自动读取可用模型列表，服务编辑窗口可修改模型显示名称、模型 ID 和默认模型。Codex 提供独立的推理强度选择，根据模型返回的能力显示可用分级；模型和强度按对话保留。首次打开窗口会显示加载状态；支持粘贴、拖入图片和引用剪贴板记录。Enter 发送，Shift+Enter 换行。回复生成时同步显示 Markdown、公式、表格与代码高亮，生成按钮可随时停止；发送的文字、回复和代码块都可复制。回复还可粘贴回原窗口或保存为剪贴板记录。

对话和草稿保存在当前本机资料库，收起窗口不会停止生成。历史对话支持搜索、重命名和删除，最多保留 50 个对话、每个 100 轮；每条消息最多 4 张图片，图片总大小不超过 16 MiB。对话存储随资料库加密、锁定及数据库恢复点保护；当前 JSON 备份不包含聊天历史，保存为剪贴板记录的回复按普通记录备份。

添加 AI 服务时可选择「Codex（本机）」。运行时随 Clipper 提供，无需填写接口地址或 API 密钥。在账户区登录 Codex，打开授权页面并输入验证码；登录资料保存在 Clipper 的独立目录，不会覆盖日常 Codex 的登录。可检查登录、重新登录或退出账户，默认模型可选择 Codex 默认模型，也可从读取到的模型列表中选择，并设置默认推理强度。文字指令和图片 AI 处理都可使用 Codex，开始处理前确认发送内容；支持取消和超时。Codex 在本机启动，模型处理使用账户对应的服务和额度。Codex 自动使用系统代理；已设置代理环境变量时优先保留该配置。

文字记录的更多操作可运行指令。图片记录的更多操作中提供「AI 处理」，预览图片并填写要求后，可使用所选模型分析图片，或选择已有指令。Ollama、LM Studio 和 OpenAI 兼容接口支持图片请求，所选模型须具备视觉能力；远程请求确认的是图片和提示词一起发送。结果可修改、复制或另存为文字，原图片保留。开始发送前会检查图片及指令是否已改变。

设置中可调整外观、语言、记录规则、交互、快捷键与应用更新。修改后自动生效，语言切换会立即更新主窗口。

## 设置与应用筛选

大多数设置修改后自动生效；界面语言位于基本设置，切换后立即更新主窗口。设置侧栏分为常规、交互、维护、数据。在基本设置点击“管理侧边栏”，可隐藏入口、拖拽调整同组顺序；此弹窗需点击“保存”。自定义分类可在侧边栏标题处新建或管理，在管理弹窗中拖拽排序。桌面交互可分别开启“拖动内容到小窗位置时显示”和“拖动到屏幕顶部时打开”；两项默认关闭。前者只有拖动进入所选角落并停留后才显示小窗，其他位置的拖动不会触发。拖放小窗可展开为完整窗口，也可用快捷键直接打开完整窗口。拖放窗口默认失焦 6 秒后隐藏，锁定后保持显示；开关和阈值可在桌面交互中调整。桌面交互还包含托盘、搜索历史和快捷回复设置。

全部记录、收藏、堆栈和拖拽容器支持组合类型与来源应用筛选。高级筛选弹层支持类型、日期、状态、来源、标签、文件类型与大小组合。应用分段位于类型筛选右侧；空间不足时，点击末尾下拉按钮查看其余应用。可获取的程序使用 Windows 原生图标，找不到原程序时保留统一图标。

选中记录用背景色区分。预览顶部的信息按钮显示来源、时间、大小与标签，更多按钮打开完整操作菜单；底部保留粘贴与复制。

恢复与回退统一收纳升级恢复点和旧程序版本：恢复点恢复升级前的资料，旧程序版本回退应用本体，并按该版本关联的恢复点处理资料。二者保护对象不同，功能保留在同一入口。应用更新负责检查、下载和安装新版本。当前存储显示用量和清理操作，历史页面不再常驻容量提示条。

在设置的“基本设置”中点击“重启 Clipper”，或从托盘右键菜单选择退出上方的“重启 Clipper”，可重新启动应用并保留数据与设置。未保存的录制或图片编辑会先询问是否放弃。
