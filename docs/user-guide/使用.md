# 运行与常用操作

完整目录包中双击 Clipper.exe。移动程序时保留整个目录。关闭窗口后驻留托盘；从托盘菜单选择“退出”才会结束程序。

开发源码可从根目录 Start-Clipper-Dev.cmd 启动；开发资料独立保存，自动记录默认开启，此后保留手动暂停状态。

## 常用操作

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+V | 打开主窗口 |
| Ctrl+Alt+V | 最近记录窗口（快速粘贴） |
| Ctrl+Alt+N | 粘贴堆栈下一项 |
| Ctrl+Shift+R | 打开快捷回复 |
| Ctrl+Shift+D | 浮动拖放窗口 |
| Ctrl+F | 搜索 |
| ↑ / ↓ | 选择记录 |
| Enter / 双击 | 粘贴回原应用 |
| Ctrl+Enter | 只复制 |
| Esc | 收起窗口 |
| Delete / Ctrl+Z | 删除记录 / 撤销最近一次删除 |

全局快捷键可在设置中修改。快速粘贴和托盘最近记录使用同一个窗口：Enter 用于复制，Ctrl+Enter 用于粘贴；主窗口 Enter 用于粘贴，Ctrl+Enter 用于复制。划词菜单已经移除，其旧快捷键不再注册。

## 功能入口

历史记录支持文字、链接、代码、图片、文件与已保存附件，以及搜索、收藏、分类、标签和删除撤销。堆栈支持逐条粘贴和重复副本，拖拽容器支持图片和文件拖出。

截图、录制、长截图与图片编辑保存结果到历史。工具分组的首项是 AI 服务，其后是独立的文本脚本入口；连接与分享下的 URI 管理 clipper-win:// 外部请求。设置的数据分组包含当前存储、自动备份、备份记录、恢复与回退；支持导入、导出、加密和目录迁移。局域网同步包含设备配对与文件、附件同步；网页共享按授权开放内容。

设置中可调整外观、语言、记录规则、交互、快捷键与应用更新。修改后自动生效，语言切换会立即更新主窗口。

## 设置与应用筛选

设置修改后自动生效，无需保存；界面语言位于基本设置，切换后立即更新主窗口。设置侧栏分为常规、交互、维护、数据。桌面交互包含托盘、边缘呼出、浮动拖放，以及搜索历史和快捷回复。浮动拖放的顶部呼出仅在按住鼠标左键拖动并经过屏幕顶部中央触发区时显示，需要先启用该开关；也可以用快捷键直接打开。

全部记录、收藏、堆栈和拖拽容器支持组合类型与来源应用筛选。应用分段位于类型筛选右侧；空间不足时，点击末尾下拉按钮查看其余应用。可获取的程序使用 Windows 原生图标，找不到原程序时保留统一图标。

选中记录用背景色区分。预览顶部的信息按钮显示来源、时间、大小与标签，更多按钮打开完整操作菜单；底部保留粘贴与复制。

恢复与回退统一收纳升级恢复点和旧程序版本：恢复点恢复升级前的资料，旧程序版本回退应用本体，并按该版本关联的恢复点处理资料。二者保护对象不同，功能保留在同一入口。应用更新负责检查、下载和安装新版本。当前存储显示用量和清理操作，历史页面不再常驻容量提示条。
