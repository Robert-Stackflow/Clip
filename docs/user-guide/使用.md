# 运行与常用操作

完整目录包中双击 Clipper.exe。移动程序时保留整个目录。关闭窗口后驻留托盘；从托盘菜单选择“退出”才会结束程序。

开发源码可从根目录 Start-Clipper-Dev.cmd 启动；开发资料独立保存，自动记录默认暂停。

## 常用操作

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+V | 打开主窗口 |
| Ctrl+Alt+V | 快速粘贴面板 |
| Ctrl+Alt+N | 粘贴堆栈下一项 |
| Ctrl+Shift+R | 打开快捷回复 |
| Ctrl+Shift+D | 浮动拖放窗口 |
| Ctrl+Alt+X | 打开划词菜单 |
| Ctrl+F | 搜索 |
| ↑ / ↓ | 选择记录 |
| Enter / 双击 | 粘贴回原应用 |
| Ctrl+Enter | 只复制 |
| Esc | 收起窗口 |
| Delete / Ctrl+Z | 删除记录 / 撤销最近一次删除 |

全局快捷键可在设置中修改。托盘最近记录中的 Enter 用于复制，Ctrl+Enter 用于粘贴。

## 功能入口

历史记录支持文字、链接、代码、图片、文件与已保存附件，以及搜索、收藏、分类、标签和删除撤销。堆栈支持逐条粘贴和重复副本，拖拽容器支持图片和文件拖出。

截图、录制、长截图与图片编辑保存结果到历史。文本工具包含脚本和 AI 操作；数据与备份包含导入、导出、加密和数据目录迁移。局域网同步包含设备配对与文件、附件同步；网页共享按授权开放内容。

设置中可调整外观、语言、记录规则、交互、快捷键与应用更新。修改后自动生效，语言切换会立即更新主窗口。

## 设置与应用筛选

设置修改后自动生效，无需保存；界面语言位于基本设置，切换后立即更新主窗口。桌面交互按托盘、边缘呼出和浮动拖放分成独立卡片。

全部记录、收藏、堆栈和拖拽容器支持组合类型与来源应用筛选。应用分段位于类型筛选右侧；空间不足时，点击末尾下拉按钮查看其余应用。可获取的程序使用 Windows 原生图标，找不到原程序时保留统一图标。

选中记录用背景色区分。预览顶部的信息按钮显示来源、时间、大小与标签，更多按钮打开完整操作菜单；底部保留粘贴与复制。
