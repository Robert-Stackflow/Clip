# v0.12 窗口截图与图片编辑验收

2026-10-01，Windows 11 x64、Electron 44.5.1、150% 缩放。独立测试资料，真实桌面测试串行运行，结束恢复原剪贴板。

## 窗口截图

真实 680×460 逻辑像素窗口得到 1019×691 PNG（系统边框影响实际尺寸）。图像左右颜色与测试窗口对应；用绿色窗口遮挡后仍捕获原目标的蓝/红内容。检查排除 Clipper、过期/伪造选择、最小化和关闭窗口拒绝；等待实际窗口来源枚举时模拟休眠，迟到结果不进入历史。窗口选择界面截图只保留测试夹具候选，避免展示其他应用内容。

## 图片编辑

真实 PNG 含蓝/红色块和透明区域。验证旋转和翻转后的透明像素位置、缩小预览下的 300×180 裁剪、撤销/重做、矩形/箭头/画笔/文字输出像素和实色遮盖。保存真实 Windows image/png 剪贴板和 PNG 文件；保存副本保留原图、标签及仅本机状态，未自动共享。取消导出、冲突不覆盖、浅深主题及 760×620 小窗口通过检查。

主窗口不能调用编辑 IPC，普通 session 不能读取原图令牌。非法 PNG、非法动作、超大像素拒绝。未保存关闭确认、迁移阻止、删除原图后拒绝提交、导出等待中模拟休眠不写文件、加密锁定销毁窗口、旧令牌失效、解锁不恢复未保存编辑、退出保留/放弃确认均覆盖。

## 限制

窗口捕获不保证受系统保护、特殊 GPU 或管理员应用的兼容性，物理多屏、混合 DPI、Windows 10 和真实休眠仍待验收。捕获图最长边 2,560、最多约 400 万像素，可能缩小。编辑支持 PNG 栅格输出，不保留可编辑图层、矢量或色彩配置文件；最多 1,600 万像素/100 步，标注不支持事后选择移动，使用撤销重做。文件导出未加密，进程强制终止可能留下同目录暂存文件。源记录若被自动保留策略后续清理，同样需要重新打开仍存在的原图。

当前仍是未签名 x64 目录包。更多格式/元数据、中英界面、安装更新及 OneClip 剩余范围持续推进，不能把本里程碑视为完整项目完成。
