# 桌面交互（v0.8 开发基线）

## 范围

参考 OneClip 的边缘触发、三方向卡片与顶部拖放架，在 Windows 上实现快速面板四边停靠、三种卡片排列、独立浮动拖放窗口及顶部拖动呼出。使用 One 的系统字体、浅深主题、Lucide 图标和原生窗口控制。默认不启用屏幕边缘触发，不占用 Win+V。

本轮不把划词菜单、录制、长截图或签名更新标成已完成，仍按开发计划独立推进。

## 快速面板与卡片

主工作台保留正常窗口。快速粘贴面板可选择左、右、上、下停靠，以及目标显示器；屏幕拔除时回到可用显示器。位置使用 Electron 的设备无关像素和工作区，避让任务栏与四角，公共显示器边界不触发。

鼠标在目标边缘停留后展开，悬停呼出不抢走原应用焦点；点击或热键打开后可键盘搜索、选择和粘贴。可选离开面板后收起；正在拖动、按住鼠标、截图、锁定、录入快捷键或其他 Clipper 窗口获得焦点时不误触。前台全屏窗口阻止自动呼出。关闭或粘贴后必须离开触发区才能再次呼出。

卡片提供纵向单列、横向滚动、网格三种排列。横向支持滚轮与左右键，网格方向键遵循实际列数；搜索框中的左右键仍移动光标。内容更新保留当前位置，所有模式继续支持选择、复制、粘贴、搜索、图片预览及文件拖出。

## 独立拖放窗口

从拖拽容器页面、托盘或独立快捷键打开；可保持置顶，支持调整尺寸和移动，保存位置并在屏幕变化后约束到可见工作区。窗口展示同一份容器内容，不建立另一套文件仓库。

支持真实文件/图片拖入、纯文本拖入、拖出文件/图片、复制/粘贴与移出容器。路径型记录只引用源文件，移出容器不删除历史或源文件。现有条目上限 200、单项/总容量限制不变，外部 HTML 不执行。

可选顶部拖动呼出：按住左键拖至目标工作区顶部中央，停留后显示浮动容器，使用 showInactive 保留拖动上下文。它是 Windows 的顶部拖放入口，不依赖刘海屏或 macOS API。拖动结束并离开后可收起自动呼出的窗口；手工打开的窗口由用户关闭。

浮动窗口使用独立 preload，仅允许访问容器项目及其操作。主进程再次校验发送窗口、顶层 frame、URL、当前解锁会话和容器成员关系。锁定销毁窗口并停止触发定时器；截图隐藏所有内容窗口；解锁不自动展示之前的浮动内容。

## 设置与验收

桌面设置保存在当前资料数据库的独立元数据中；备份不携带本机屏幕位置。原资料缺少字段时使用兼容默认值。显示器坐标、停留时间、快捷键、卡片方向和开关在主进程校验，热键冲突不破坏已有注册。

验收包括负坐标/不同缩放/共享边界/任务栏的几何测试，真实 Electron 的四边位置、悬停不抢焦点、离开收起、全屏和锁定隔离、卡片滚动与键盘、浮动窗口文件拖入拖出、位置重启与旧数据兼容。真实物理混合 DPI、多显示器热插拔仍单独标注人工验收范围。
