# Clipper 0.23 界面重构

参考 D:/Repositories/One/src/renderer 的组件及设计规范，以白色工作区、浅灰侧栏、32 px 控件、24 px 标题、36 px 内容留白和低对比度分隔组织页面。深色、字体大小、密度、中英文继续使用同一套语义变量。

- 主窗口：全部记录、收藏、堆栈、拖拽容器、自定义分类与快捷回复统一为搜索/筛选、列表、预览三个区域。侧栏可收起并保留选择。预览中的复制、粘贴、收藏、置顶、编辑、删除保持可见，其余通过“更多操作”展开。
- 设置：基本设置、外观、桌面交互、记录与隐私、快捷键、本地数据使用分类导航。切换分类保留未保存的表单输入。
- 文本工具：AI 服务、脚本、外部链接分开管理。数据与备份：当前存储、自动备份、备份记录分开；原有加密、恢复与迁移流程保留。
- 局域网同步、网页共享：连接/设置与设备/内容分区；窄窗口自动改为纵向。网页访问端使用同样的排版和颜色。
- 录制：画面来源与音频/画质参数分区。图片编辑：工具侧栏与独立画布、底部保存操作。长截图、截图选区、托盘、浮动容器、划词菜单、解锁和恢复窗口统一控件及排版。
- 安装器：删除口号、装饰插画与无意义的示例内容，展示版本、系统、安装位置、实际阶段与结果。安装引擎和失败恢复机制保持。

## 性能

记录图标缓存；记录 ID 索引替代每行遍历全量历史；方向键只更新选择而不重建列表，纵向移动不测量全部行；短时间重复状态通知合并。共享页面复用当前历史状态，仅在内容发生变化时更新记录节点，并拒绝过期请求。

一万条合成记录、末尾 100 条收藏、连续 60 次选择的三次相同浏览器对比中，旧版平均重建 6000 个记录节点，新版为 0。耗时见 validation/performance-results.json。该结果仅衡量渲染事件处理，不代表剪贴板捕获、数据库或完整端到端响应。已有备份、脚本和媒体元数据任务继续运行在独立工作进程。此次已测量的瓶颈是 DOM 重建，无需额外引入 Rust。

## 验证

验证使用合成资料和隔离环境，不访问日常历史或系统剪贴板。覆盖中英文、深浅色、常用/窄窗口、放大字体、表单保留、常用操作；另使用未显示的 Electron 窗口运行实际构建的页面。安装器通过实际 WPF 离屏渲染验证四种状态、两种语言、三种缩放。物理键鼠、剪贴板、干净 Windows 系统验收不在本次验证范围内。
