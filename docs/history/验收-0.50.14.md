# 0.50.14 桌面交互与代码收尾

当前源码移除了独立“快速粘贴”入口，最近记录仍由托盘打开。托盘右键菜单改为自绘面板；拖放窗口保留完整布局，另增简洁小窗和尺寸过渡遮罩。桌面交互设置可分别控制拖动自动显示与顶部中央呼出。侧边栏折叠布局、记录刷新和部分页面间距一并调整。

此前开发过程中，核心检查曾通过 515 项；类型检查、构建、最近记录与拖放相关界面检查、双语设置检查以及原生文件拖入检查分别通过。用户随后亲自确认拖动文件和文字的效果，并明确要求停止继续测试。因此本次收尾不重跑完整功能测试；这些既有结果不能证明后续每次改动或所有真实桌面场景都通过。

现存 `release/0.50.14` 的构建一致性记录显示 265 项资源匹配，同时标注 `fullFeatureAcceptance: false`。这份记录生成于 2026-10-04，早于本次文档和清理收尾，不能替代当前源码的重新打包与运行验收。

本次清理仅处理本仓库内确认可删除的生成物：失败的发布暂存、过期依赖副本与旧调试映射，共释放 234,965,163 字节（约 224 MiB）。保留最新两个可运行版本、开发资料及未标记的旧工作目录。清理脚本已去掉仓库外目录目标。

剩余工作与暂缓项目见 [当前状态与待办](../development/当前状态与待办.md)。
