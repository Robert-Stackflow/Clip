# 0.21 格式显示与英文侧栏复核

2026-10-01。独立开发记录，完整运行范围、Windows 验收和发布仍未完成。

## 显示改进

英文侧栏宽度随字号增加，导航文字按完整单词换行；暂停后的 Resume capture 也可分行显示。主要导航及暂停按钮提供完整标题提示。快速面板继续使用原有单列布局，中文侧栏沿用既有宽度。

主窗口的导航、记录/回复总数、堆栈计数、批量确认和设置计数，以及托盘总数使用统一数字格式。1000 显示为 1,000，计数本身及传给操作接口的记录数组不改变。记录日期使用共用日期格式工具，保留原有时区及月/日显示；相对时间仍采用 min/hr 简短文案。

录制大小继续用 MB 和一位小数，现在通过共用数字格式显示；字节数、容量限制、录制秒数和编码过程不变。相对时间的译文原本是 min/hr 缩写，并不存在单复数错误；本批没有为此重写时间行为。

## 文案绑定审阅

检查只认可从 i18n 模块导入的翻译函数，并确认字面量作为完整文案参数或带标签模板传入。先选择完整条件文案再翻译是合法的；模板参数、回调中的字符串或动态拼接的键不能因为外层存在翻译调用而被误判为已翻译。

已审阅静态表和网页访客延迟翻译仍有单独边界。3 项检查覆盖条件键、直接模板、原文参数、嵌套回调、动态键及假同名函数/纯类型导入。当前 110 个 TS 文件及 15 处网页延迟翻译通过检查，没有未绑定的自有中文候选。检查不执行任意用户内容，也不替代语义及实际运行审阅。

## 格式审阅

盘点并分类 60 处显式日期、数字、ISO 和精度格式化调用：界面使用本次启动或网页访客的语言；备份协议、生成文件名及源文件元数据保持原表示。照片/PDF/Office 日期、媒体 s/kbps 精度和原始作者等内容不按界面语言改写。

该盘点覆盖指定调用类型，不能证明所有动态数值、技术尺寸或实际原生表面都已完整审阅；全应用完成标记继续为 false。

## 验证证据

- 250 项逻辑测试通过，包含新增 3 项翻译绑定检查。类型检查、构建及文案范围检查通过：1569 条目录、120 个 TS/HTML 文件及两份标签表、1853 处引用无缺失，已盘点候选为 0。
- 108 组针对性界面检查通过：96 组侧栏/日期/计数组合，覆盖中英文、860/1180 宽度、4/1000 条记录、三种字体、100%/150% 字号和两种密度；另有 4 组托盘大数计数与 8 组录制大小检查。英文单词逐个检查完整矩形，千条计数、原始标题、日期显示及暂停动作保持正确。
- 样式调整后，既有 304 组英文工作区、424 组中文布局检查通过；随后追加的大数计数变化由针对性检查覆盖，未重复不变的小计数矩阵。中英文工作区行为回归在最终计数变化后通过，覆盖原文/路径、复制粘贴参数、编辑搜索、设置、撤销、分类和托盘等操作。
- 侧栏宽度影响其他主窗口页面，最终构建又通过 420 组数据/同步/网页共享页面与对话框、448 组文本工具页面与对话框布局检查，没有横向溢出或不可达控件。
- 截图复核确认 Favorites、Capturing 及 Resume capture 在 150% 等宽字体下可读，主窗口正文与操作区保留可用空间。
- 3 个渲染文件和主样式经过限定源码审阅，仅允许已列出的格式显示、标题提示及英文侧栏规则变化；IPC、数据、媒体和时间计算没有修改。

检查使用实际构建页面、合成内容和模拟接口，没有操作系统键鼠、剪贴板或真实录制。首轮提示预期写成 Resume capturing，实际既有译文为 Resume capture；已修正测试预期，生产译文和检查阈值未更改。绑定审阅对条件键的分类与源码审阅工具对托盘的文件分类也已修正。

证据位于 work/language-format；检查入口为 npm run check:language:bindings、npm run test:language:format 和 npm test。本批没有生成新运行包或源码归档，旧交付与预览快照保持原样。
