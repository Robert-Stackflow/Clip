# 0.49.8 长正文搜索减少拼接

普通搜索词不包含空白，不能跨标题、正文、文件名之间的换行分隔。此前每次正文搜索先复制标题与长正文等字段拼成大字符串，再转换成小写。本轮按字段转换和匹配，减少一次长文本拼接；支持包含换行的内容分类仍使用原有完整字符串，保留跨字段匹配。

505 项核心回归、类型和 2,246 条自有语言字符串检查通过。新增明文/加密与有缓存/旧数据库四种组合，使用独立完整记录结果验证 Greek Sigma、组合字符、混合查询、文件名和附件名、换行分类、精确总数与记录身份；工作线程结果相同，主记录字节保持不变。边界测试使用实际合法的绝对文件路径，附件与其他内容分开构造，没有放宽生产数据校验。单独的最近记录套件 17 项也通过。

较大文本后台查询的全应用工作集采样峰值增量中位数，明文为 63.3→53.2 MiB，加密为 78.7→65.5 MiB。采样范围分别为旧版 59.8–66.9 / 76.1–80.4 MiB、新版 27.8–72.5 / 41.0–68.2 MiB；新版明文也有更高一轮，不能声称稳定降低峰值。250 ms 采样可能漏掉短时峰值，元数据查询的零采样增量不表示零内存占用。

新版全部后台样本中，主进程版本探针最大等待为普通资料 45.9 ms、较大资料 38.5 ms，5 ms 计时器最大间隔为 20.5 / 22.4 ms。报告为 work/current/recent-search-packaged-worker-0498/result.json 与 recent-search-packaged-worker-0498-large/result.json。
