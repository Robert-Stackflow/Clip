# 0.50.4 最近记录粘贴失败回退验收

2026-10-04。最近记录从原目标窗口粘贴时，如果 Windows 拒绝恢复该窗口，面板隐藏后主窗口会显示“无法恢复目标窗口，已复制，请手动 Ctrl+V”。这样用户仍能找到已复制的内容，并明确知道下一步操作。此前为列表/纵向导航更新了桌面界面回归，移除了等待旧网格切换控件的断言。

`npm run test:desktop`、`node tests/tray-boundaries.cjs`、`node tests/tray-ui.cjs`、`npm run typecheck` 和 `npm run build` 已通过。0.50.4 Windows x64 目录包位于 `release/0.50.4/win-unpacked`；打包检查确认 260 项构建资源与源码一致。`node tests/packaged-smoke.cjs 0.50.4` 使用独立、暂停自动记录的资料启动实际 `Clipper.exe`，确认版本、主界面、样式及原生组件，截图已目视核对。dev 继续运行。

系统记事本的真实试用中，内容写入剪贴板成功，但 Windows 拒绝恢复记事本前台，**自动粘贴未通过**。隔离 Electron 目标窗口的正常粘贴及最近记录边界回归通过，但不能替代记事本和其他实际应用验收。[微软的窗口前台权限说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)指出系统可能拒绝切换，即使通常条件已满足。因此保留清晰的复制与手动 Ctrl+V 回退，不将强行抢占前台作为默认行为。

目录包未签名；双物理设备、真实 Office 等应用、多屏和正式发布链路仍未验收，整体目标继续进行。性能与录音录屏性能调查按此前用户要求保持收尾状态。
