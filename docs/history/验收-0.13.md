## 原始数据与交互

真实 Windows 剪贴板同时提供 Unicode 文字、含 tEXt 注释的 PNG、含 SourceURL 与中文字节偏移的 CF_HTML、非 UTF-8 RTF。捕获和回写的原始数据逐字节一致；纯文本复制后原格式不再存在。透明像素保持透明，半透明输入约 [80,160,240,128]，兼容位图回读 [80,159,239,128]，在转换误差内。

JPEG 的 EXIF ImageDescription 经捕获、复制、另存、模板和备份后保留完整字节。GIF、TIFF、WebP、BMP 与 JPEG 的注册格式及 MIME 别名逐个验证真实捕获和复制，尺寸信息可读取。单张 JPEG 文件拖入保留元数据，再通过真实 Windows OLE 拖到独立接收窗口，收到 .jpg 文件，字节与源文件一致；源文件未改动。

真实网页共享服务将带注释 PNG 重新编码后输出，HTTP 下载中不再包含该注释，本机原图保持不变。服务级测试同时检查其他原始格式未泄露到 PNG 响应。格式信息的浅深界面已截图核验，富文本无预览时有明确说明。

文件引用默认不读取磁盘信息，主动请求后显示当前大小、文档类型和修改时间；删除夹具文件后显示不存在。此功能不解析媒体编码/时长、文档作者或全部元数据。

## 数据与边界

原始表示参与去重。原数据在快捷回复、普通备份、密码加密备份及独立资料恢复后保持一致。仅修改纯富文本标签不丢弃原格式；改变可编辑文字或填写变量后输出纯文本。校验拒绝任意 Windows 格式名、Shell 移动标记、虚拟文件描述符、重复名、非规范 Base64 和超限数据。

原格式导出取消不写文件，已有目标不覆盖；等待保存对话框时删除源记录或锁定历史，迟到选择不产生文件或残留暂存。加密备份在新的空资料目录恢复后，原始 RTF 和模板字节一致。

同步使用真实隔离 TLS 服务验证新端原字节、旧端能力清单过滤、旧端请求原格式拒绝，以及兼容文字仍继续发送；未支持的原格式留待升级。schema 2 升级后保留历史，schema 4 被实际 0.4.1 和 0.12 程序拒绝打开，数据库哈希不变。

## 限制与后续

原格式采用明确白名单，不代表全剪贴板格式：OLE 虚拟附件、应用私有格式、原始 DIB 色彩上下文和内部媒体/文档元数据仍待扩展。图片预览和编辑是静态 PNG，原始 GIF 字节可保留动画；TIFF 解码能力取决于运行环境。文件大小和修改时间为读取时状态，父目录重解析点不保证被识别。

实际来源应用（如 Word、Outlook、Adobe 软件）及目标粘贴选择仍需单独兼容性测试，本次字节验收主要使用受控 Windows 剪贴板夹具。混合 DPI、多屏、Windows 10、真实休眠和长期满容量测试沿用未完成项。当前仍是未签名 x64 目录包，中英界面、安装更新、签名与剩余 OneClip 范围继续推进。
