# 窗口截图与图片编辑

> 历史归档（2026-10-10）：截图、录制、图片编辑和贴图已由 Frame 负责，Clip 迁出清理已完成。本文保留迁移前的需求与设计，不代表 Frame 当前实现；边界与验证见 [Frame 迁出清理](../验收-Frame迁出清理.md)，当前任务见 [当前状态与待办](../../development/当前状态与待办.md)。

## 目标

补齐 OneClip 的独立窗口截图及图片编辑，沿用 One 的 Segoe UI、Lucide、浅深色、原生窗口按钮和简洁工具栏。主入口仍是历史顶部的截图和图片详情，不引入独立图库。

## 窗口截图

截图对话框增加窗口模式，展示名称和缩略图，支持刷新。候选仅来自 Windows 可捕获窗口，排除 Clip 自身和最小化窗口。选择仅在短期内有效；拍摄前后检查窗口身份、最小化状态及候选匹配，关闭或失效时要求刷新。实际图像来自窗口捕获，不裁切桌面坐标。输出最长边 2,560 像素、最多约 400 万像素；较大的窗口缩小。受系统内容保护或特殊 GPU 渲染影响的窗口可能无法捕获，不能保证所有应用。

## 图片编辑

图片详情新增“编辑图片”。独立窗口提供裁剪、向右旋转、水平翻转、画笔、矩形、箭头、文字和实色遮盖。坐标以原图像素保存，显示缩放不影响输出。可撤销/重做，最多 100 步；画笔点数有界，图片最多 1,600 万像素、单边 16,384 像素。编辑全过程保留 PNG 透明度。

“保存副本”写入图片历史，保留原记录；相同图片遵循历史去重。副本不自动加入共享或网页发布；继承原图标签，仅本机标记随副本保留。也可显式复制当前结果或另存为新的 PNG 文件。复制不会自动保存编辑工程。PNG 文件是普通未加密文件。原图在编辑期间被删除或内容改变时，禁止继续提交，需重新打开记录。

## 大图渲染（0.46.4）

主画布保留原始像素。新增操作和重做只应用本次操作；撤销从原图重放操作列表，共用相同绘图函数，不为每一步保存整张位图。操作签名仅在操作列表改变时更新，拖动预览和界面状态检查复用签名。

透明选区图层按显示大小和设备像素比创建，上限为原图分辨率。预览坐标通过画布变换映射，所有记录和输出仍使用原图坐标；改变缩放后重新绘制选区。旋转/翻转的临时位图按动画前后较大的显示比例与设备像素比创建，最多 400 万像素。该上限只用于短暂动画，最终图像不缩小。动画仍裁切在画布区域，并在结束或窗口改变后释放预览位图。

验证包含透明源图、混合编辑的逐像素比较、原尺寸 PNG、撤销/重做和保存状态；测量使用独立浏览器进程、固定图片与相同操作列表。区分位图尺寸估算、进程私有内存、动画帧回调和实际屏幕绘制，不用其中一种替代另一种验收。

## 数据与生命周期

原图及操作仅驻留内存；专用非持久会话通过临时令牌提供原图，不能访问主窗口 API、外部网络或本地文件。主进程验证输出类型、大小、像素和记录身份，所有提交受同一会话有效性检查。锁定、休眠、退出清除窗口和令牌；关闭未保存修改需确认，迁移存储前需保存或放弃。导出使用同目录暂存文件并原子提交至新文件名，避免覆盖现有文件。强制终止可能遗留未加密暂存文件。

## 验证

使用真实 Windows 窗口内容检查捕获结果、遮挡、最小化和关闭；验证实际 PNG 的尺寸、颜色及透明度。编辑操作验证坐标、撤销/重做、裁剪旋转翻转、绘图输出和真实剪贴板，另外测试跨窗口访问、过期令牌、锁定及延迟保存取消。未经真实硬件测试的多屏、混合 DPI 和受保护窗口明确列为后续兼容性验证。
