# 划词菜单（v0.9 实施基线）

> 历史归档（2026-10-10）：划词菜单已在 0.50.0 移除，本文保留旧设计；当前范围见 [需求](../../development/需求.md)。

## 目标与入口

参考 OneClip 的选中菜单和划词翻译，在 Windows 外部应用选中文字后显示轻量操作条，复用现有复制、历史保存、翻译、总结与脚本。视觉沿用 One 的系统字体、浅深主题、Lucide 图标及低对比度边框。

自动菜单默认关闭，可在设置中启用；提供独立、可修改的主动读取快捷键。鼠标选中和快捷键都只读取目标应用通过 Windows UI Automation 暴露的选区，不发送 Ctrl+C，不临时覆盖或恢复系统剪贴板。没有 TextPattern 支持时明确反馈，不假装读取成功。

## 读取与生命周期

本机 .NET Framework 辅助进程通过 UI Automation TextPattern.GetSelection/GetText 获取选区，最多 32,768 个 UTF-16 字符和 128 KiB。只访问当前目标窗口与对应控件；识别 IsPassword、进程排除与无选区。读取有超时、输出限额和会话编号；辅助进程卡住可终止，主界面继续响应。

自动触发来自鼠标释放，延迟短暂稳定后读取；在输入、重新点击、切换应用、截图、迁移、录入快捷键、锁定或关闭功能时失效。自动菜单不抢焦点，快捷键入口支持键盘操作。窗口在当前显示器工作区内摆放，不遮挡选区终点，支持负坐标与缩放换算。

选中文字暂存内存，不自动写历史或发送网络。每次操作需要有效快照编号并确认目标选区仍一致；菜单消失、超时或锁定后旧请求不能使用。密码控件和排除进程不显示菜单，不读取 ValuePattern 或整篇文档作为替代。

## 操作与边界

- 复制：用户点击后才写系统剪贴板。
- 保存：用户点击后保存为一条历史记录，来源标记为选中文字的应用。
- 翻译/总结：将选区送入现有输入与结果对照窗口，由用户确认和点击开始后才请求模型。
- 脚本：显示脚本代码及权限，用户确认后运行；输出可复制或另存，不直接改写外部应用。
- 锁定：销毁操作条、终止读取进程、清除快照和待处理文字；解锁不恢复这些文字。

操作条使用独立 preload，主进程再次校验窗口、顶层 frame、URL、会话和参数。选择内容按纯文字显示，不执行 HTML 或外部命令。本机设置不进入内容备份。当前不做鼠标选区自动联网、自动替换外部文字或跨权限提升。

## 验收

先验证真实 UI Automation 能读取 Chromium 普通文字、输入框及 Windows 原生文本控件，再完成鼠标自动显示和快捷键入口。覆盖无选区、密码、进程排除、超长选区、窗口切换、超时/迟到响应、锁定/迁移、热键冲突、剪贴板保持、复制/保存、AI/脚本预览及浅深/边缘布局。真实 Word、PDF、终端、管理员应用和不同浏览器版本单独记录，不用模拟结果替代兼容性结论。
