# 0.50.16 开发整理

2026-10-07。本轮提交包含当前工作区积累的桌面交互、AI 与脚本、分类、快捷回复、设置和 Electron 图形安装器改动。

- 分类支持列出和搜索 Lucide 图标，侧边栏显示分类数量，统一分类入口与排序样式。
- 容器、堆栈和分类复用记录与详情呈现；全部记录排除容器内容；批量选择支持未选、半选、全选状态。
- 快捷回复支持列表与卡片布局、多选和快捷面板内新建；标题与内容使用不会推动布局的字段校验。
- 快捷面板优化筛选、日期选择、移动、粘贴、拖放与原生悬停预览。点击外部关闭面板，同时保留面板内弹出菜单和进行中的粘贴。
- 托盘左键默认打开 Clipper，可切换为最近记录、快捷面板、快捷回复或拖拽容器。
- 设置页面统一卡片、标题、说明和控件排版；快捷键集中管理；移除 OCR 入口、服务、任务、接口和发布资源。
- 图片拖放支持浏览器图片来源；随程序提供按当前页面启用的浏览器扩展，用于登录图片和 Blob 图片。

提交前已通过 613 项核心测试、12 项开发与发布流程测试、类型检查、完整构建、语言覆盖与绑定检查、模型编辑、中英文文本工具、设置布局、快捷面板外部点击关闭及原生预览检查。收尾补齐新增文案翻译，更新模型编辑测试，并让未变更的快捷键原生组件在 dev 运行时可复用。图形安装器的程序版本与应用版本同步。安装器构建会校验版本与全部编译资源，并在发布目录保留构建一致性报告；构建一致性不代表全部功能已在所有 Windows 环境完成验收。

交付版本为 0.50.16，图形安装器文件名为 `Clipper-0.50.16-Setup-x64.exe`。个人开发资料及构建产物不提交 Git。
