# Clipper 0.20 字体与紧凑布局：开发检查

日期：2026-10-01。状态：独立目录中的开发版本，尚未生成 Windows 发布包。

## 已实现

- 设置 → 字体与密度：系统默认、无衬线、等宽字体；100%、110%、125%、150% 文字大小；舒适和紧凑间距。
- 选择项先在样例中预览；取消不保存，保存后通知当前应用窗口，下次启动读取本机设置。可恢复默认选项。
- 本机偏好单独保存，不包含剪贴板内容，不参与历史备份或设备同步。解锁和资料恢复窗口也可读取外观。
- 小窗口侧栏滚动，设置入口固定可达；详情中的记录信息可展开，辅助操作区独立滚动，为正文保留空间。
- 修复大字号下划词浮条来源行裁切、文件容器及批量选择状态的正文高度不足。托盘和浮动容器支持紧凑间距。
- 文字缩放不改变图像画布像素、截图坐标或媒体分辨率。
