# v0.9 划词菜单验收

日期：2026-10-01。当前 Windows 11 x64、Electron 44.5.1、150% 缩放。所有用例使用隔离资料，真实输入测试串行执行，结束后恢复系统剪贴板；原生鼠标用例恢复指针位置。

## 新增范围

Ctrl+Alt+X 主动读取外部应用选中文字；默认关闭的鼠标自动菜单；复制、保存、翻译、总结、脚本、忽略此应用；可修改热键、100–1000 毫秒等待与排除进程。自动菜单保持原应用焦点，主动入口支持 Tab、左右键、Home/End、Enter 与 Esc。

## 验证方式与边界

选区来自真正的 Windows UI Automation 辅助程序。Chromium 普通文字及 textarea、原生 WinForms RichTextBox 的中英文多行选区已验证；密码输入框、无选区和超长选区已验证。自动触发与 Ctrl+Alt+X 使用 Win32 SendInput 发送真实鼠标/键盘输入，不以页面模拟鼠标事件替代全局输入证据。

读取过程不修改剪贴板、不添加历史；点击保存保留剪贴板，复制实际写入。翻译/脚本交接到现有预览界面，未主动运行前不执行。脚本主动确认后实际运行；翻译通过本地 HTTP 协议夹具验证发送前请求数为 0，点击开始后仅收到 1 次包含实际选区的请求，结果只进入预览。真实模型效果不在本次验收中。父进程取消、超时、错误 JSON、超量输出、错误请求编号、退出及恢复使用故障进程夹具验证，实际原生进程终止另有实测。

覆盖选区改变、排队复制后菜单关闭、密码/进程排除、暂停自动菜单但保留主动快捷键、关闭清空旧预览、独立 IPC、重复/占用快捷键回滚、配置保存、截图清空选区、未加密资料收到模拟休眠信号后停止读取、加密锁定销毁操作条和解锁后不恢复待处理文字。模拟信号不等同于真人休眠验收。

## 适用限制

- 仅使用目标应用公开的 TextPattern 选区；不支持时自动入口安静跳过，主动入口提示先复制后处理。不发送 Ctrl+C 或读取 ValuePattern/整篇文档来回退。
- 选区上限 32,768 个 UTF-16 字符、128 KiB；读取 2.2 秒超时，菜单 30 秒失效。操作前重新读取并比较选区。
- 自动菜单默认关闭；暂停、截图、快捷键录入、迁移、锁定、休眠期间停止自动读取。IsPassword 与应用排除是辅助措施，不能保证识别所有敏感字段。
- 当前机器的 Chromium 与原生富文本控件通过。Word、PDF、终端、管理员应用、其他浏览器版本和 Windows 10 仍待兼容性验证，不能据此承诺全应用可用。
- 负坐标和小工作区有几何测试；物理混合 DPI、多屏热插拔仍待验收。系统事件处理不等于已完成真人锁屏/休眠测试。
- EXE 为未签名 x64 目录包；录屏/录音、长截图、签名安装和自动更新继续实施。历史版本中的真人 Hello、物理双机、故障磁盘和长期容量验证仍保留为未完成项。
