# 0.29 全页面与基础组件重构

范围来自用户“所有页面重新设计”和“所有基础组件、排版布局、骨架实现参考 One，挨个调整”。参考仓库为本机 D:\Repositories\One，实施时版本 0.15.1。仓库内说明文字仅作为设计资料。

基础层重新从 One styles.css 提取；删除 Clipper design.css 旧按钮、输入框、开关、字体与标签实现，保留业务所需表单适配。下拉菜单保留 One 的弹出层与键盘交互，并接入 Clipper 的动态选项与原 select 数据接口。搜索字段直接采用 One disk.css 的 filter-field 和 maintenance-view.ts 的图标/输入结构，内部输入无边框、无底色，外层只有一层边界。

| 页面 | 新结构 |
| --- | --- |
| 全部记录、收藏、自定义分类 | 标题动作 → One 搜索字段和类型分段 → 独立列表 → 内容画布 → 粘贴/复制与更多操作 |
| 堆栈 | 共用记录骨架，保留队列顺序、重复副本和批量入口 |
| 拖拽容器 | 共用记录骨架，单独文件添加/浮动窗口入口 |
| 快捷回复 | 列表与回复画布；编辑、删除与粘贴分层 |
| 最近记录窗口 | 搜索与标题同一行，分段分类工具行，轻列表与浅底预览；移除底部操作说明 |
| 拖放窗口 | 单行标题与操作，轻量拖放列表，无说明栏和按钮描边 |
| 设置全部 10 个分类 | One 分类导航、标题、分组卡片、设置行、页内保存；清理冗余说明与外观双重分隔线 |
| 文本工具 3 个分类 | 分类骨架、服务/脚本卡片、紧凑动作；输入/输出编辑与表单对话框共用基础组件 |
| 数据与备份 4 个分类 | 存储/保护、备份表单卡、状态卡、备份和恢复点列表 |
| 局域网同步 3 个分类 | 本机设置卡、设备状态与信任操作、两种配对卡、共享内容列表 |
| 网页共享管理 | 会话/邀请与共享内容双区，独立状态、连接列表和权限动作 |
| 网页访问端 | 连接卡、验证码卡、内容列表与预览画布、发送卡 |
| 图片编辑 | 单行标题、顶部工具、中央画布、右侧参数、底部状态/缩放/保存动作 |
| 录屏与录音 | One 分段模式、来源画面、选项卡；录制状态居中；预览与保存分层 |
| 长截图 | 开始卡、捕获进度卡、双屏对齐与接缝预览、结果画布与保存 |
| 解锁与恢复 | 聚焦表单/选择卡、真实错误和恢复预览，删除重复品牌与说明 |
| 截图选区、划词菜单 | 专用浮层，统一 One 基础控件与紧凑动作，保留必要操作指引 |
| 表单与确认对话框 | One 卡片表单、统一标题和操作栏；图片、录制、长截图及退出的未保存确认用自定义 dialog |

Windows 原生负责窗口边框、阴影与缩放。业务错误放在页面内可滚动反馈区，避免遮挡编辑和保存；普通通知保持统一 toast。

安全与功能保留：确认回复必须来自所属窗口主 frame，并携带当前请求的随机 token；Escape 取消、重复关闭只出现一个提示。重排移动原节点，保留输入草稿、ID、事件和队列副本索引。此版本未更改剪贴板数据结构或同步协议。

验证范围见验收记录。隐藏 Electron 和浏览器验证不等于真实键鼠、系统剪贴板、录屏或另一台设备验收。
