# 0.50.15 安装器

2026-10-05。Windows 安装器按本地 One 的单窗口流程重做：选择位置、安装进度、完成与失败使用统一界面；保留现有 NSIS 安装引擎、当前用户安装登记与卸载行为。旧 WPF 图形壳已移除。交付文件为 `Clipper-0.50.15-Setup-x64.exe`，同目录的 `Setup-Engine` 仅供构建和诊断。

失败页把可操作的简短说明放在主视图，原始错误收进可展开详情。长错误只在详情卡片内滚动，轨道、滑块与 Clipper 主界面一致；普通页面不出现外层滚动条。首次安装与迁移前校验版本、运行进程、路径、剩余空间和包摘要；升级失败尝试恢复旧程序、注册表项和快捷方式，个人资料保留。

本机验证：应用构建通过；隔离产品身份的 NSIS 首次安装、重装、卸载及跨盘路径验证通过；Electron 安装器首次安装、换目录、模拟失败后的旧版恢复、静默安装与卸载通过。源码界面和最终打包界面均检查安装位置、失败详情与溢出情况；打包目录中的 265 项应用资源摘要一致。未使用日常 Clipper 安装身份或资料目录。

待验收：正式签名、干净 Windows 10/11、公开 Release 更新链路及真实用户环境中的跨版本升级。此前截图、长截图、录屏与录音的进一步优化仍按用户要求暂缓。
