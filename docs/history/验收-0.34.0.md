# Clipper 0.34.0

## 本轮改动

统一异步按钮的重复提交保护和原位反馈，接入主窗口、普通保存对话框、备份、文本工具、最近记录、拖放容器和图片编辑。采用 One 的按钮基础、RotateCw 图标以及 1.4 秒旋转节奏；原仓库没有通用忙碌按钮，Clipper 的等待门控与 150 毫秒延迟是适配扩展。操作过程中保留按钮尺寸、名称和原有边框规则，快速完成时不显示旋转动画，减少动态文字和额外提示。减少动态效果时显示静止图标。

同一操作在页面重新绘制后仍只执行一次。新按钮继承正在进行的禁用状态，只在原操作位置显示旋转图标；移除的按钮及时释放。恢复原有禁用状态，键盘焦点仅在仍适合恢复的原按钮上恢复，用户已经移到其他控件时保留其焦点。取消 AI/脚本任务、关闭非锁定对话框仍使用已有流程。

图片编辑改用 Canvas.toBlob 异步编码，再按 192 KiB 原始字节分块转换为 base64；运行时支持原生转换则使用原生方法，其余使用可让出事件循环的兼容路径。历史副本、复制和另存为继续使用原有 IPC 与后端校验、原子写入。浏览器两种 PNG 编码的压缩字节可能不同，检查的是尺寸和解码后的完整像素一致。编码仍会持有完整 Blob、ArrayBuffer 和最终字符串，不代表全应用峰值内存已降低。

修复以下异步交互：复制前等待搜索历史保存时切换记录，不再改为复制后选中的记录；旧文件夹选择不回填新页面；设置保存、导入和清理完成后不强制改写其他页面；旧 AI 服务保存不清空新对话框的密钥；旧文本替换结果不关闭新对话框。数据迁移/导出等锁定操作期间的 Esc 同样受到锁定保护。

## 验证范围

- 339 项逻辑检查、类型检查通过。
- 35 项异步组件和主页面专项检查，加 12 项图片编辑/最近记录/拖放容器组合检查；覆盖中英、明暗主题、减少动态效果、重复点击/快捷键、页面重绘、异常恢复、取消、焦点及旧任务完成。
- 真实 One 0.16.4 的样式与组件做 16 项计算样式比对；另核对 RotateCw 路径与扫描动画节奏。16 项搜索输入检查、120 项页面和基础控件检查、48 项媒体反馈检查通过。
- 文本工具与数据交互在两种语言下复验；143 个有语言绑定的文件没有未绑定项，静态目录没有缺失译文。
- 程序实际 Electron 44.5.1 / Chromium 152 在私有隐藏沙箱里运行生产图片编辑页面，确认异步编码、像素、重复提交与失败重试；打包后使用 ASAR 内的实际页面和样式再次检查。图片 IPC 为模拟接口，没有使用系统剪贴板。
- 打包后检查实际加密恢复、文件同步工作进程、Rust 文档助手、重复堆栈、加密搜索、字体助手、图片保存/缓存与原始格式内存准备的依赖；核对完整程序文件、源码归档和版本。

900×900 随机透明像素样本的单次观测中，原同步编码约 26–34 ms；异步编码与分块转换约 82–146 ms，其中事件循环可以继续运行。结果说明界面可响应，不说明保存总耗时变短。计时会受并行检查和系统负载影响，不作为性能门槛。

完整 348 项布局基线、全套历史动效检查沿用 0.32/0.31；本轮只将实际重跑的检查计入当前验收。不宣称所有页面和性能项目已经完成。

## 运行与限制

先从旧版托盘退出，再运行完整目录中的 Clipper.exe。移动程序时保留整个目录。原始开发仓库、日常资料、One 参考仓库和以前交付版本保持不变。

本轮没有使用物理键鼠、系统剪贴板或日常用户资料，没有验证真实桌面拖放、两台物理设备互传、DWM 像素、完整应用的常驻/峰值内存或干净系统安装。软件未签名，也未公开发布。
