# Frame 迁出后的 Clip 清理

日期：2026-10-09。仓库：`D:\Repositories\Clip`，版本：0.51.0。

## 范围

按用户要求，移除 Clip 中已迁往 Frame 的内置截图、录屏、录音、图片编辑及贴图实现。图片编辑功能完整移除，不保留按钮、占位提示、预加载接口或 IPC。

- 删除对应的主进程服务、独立窗口、渲染页面、预加载脚本、专用样式和共享类型。
- 清理工具导航、托盘入口、资源白名单、窗口生命周期、构建入口及旧构建产物。原生 SourceHost 只保留应用图标和光标定位。
- 删除迁出功能的专用测试；混合测试继续覆盖剩余行为。删除不再使用的语言条目，保留音视频文件元数据相关条目。
- 将仍供附件、图片和格式导出使用的文件提交工具整理为 `file-commit.ts`，保留已有文件保护和异步图片保存。

剪贴板采集、图片预览、复制、粘贴、导出、图床上传、文件元数据读取、AI 图片处理、快捷面板和拖拽容器继续保留。快捷键录入的捕获机制属于应用交互，不属于截图功能。
