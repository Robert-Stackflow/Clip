# Clipper 0.29.0 验收

交付形态：完整 Windows x64 解包目录，直接运行 Clipper.exe；移动时保留整个目录。另附源码与校验报告。旧版需要先从托盘正常退出。本次不改变历史数据结构和同步协议。

## 界面与操作

- 全页面重构清单见《界面重构-0.29》，基础组件来源见《ONE-UI-MIGRATION》与 ONE-UI-SOURCES.json。
- 308 项逻辑检查通过；348 项布局组合和 120 项设置/辅助窗口检查通过。
- 16 项基础控件与 One 实际样式比对、16 项搜索框样式和搜索/清空检查通过。
- 48 项媒体、OCR、内部信息反馈检查通过，包括裁剪、撤销、重做和导出图像尺寸；双语、明暗主题、100%/150% 字号均覆盖。
- 144 项通知位置和阅读检查通过；40 项真实隐藏 Electron 滚动条检查通过。
- 实际 ImageEditorService、AppearanceService、沙箱 preload 与 IPC 验证中英文自定义关闭提示，涵盖继续编辑、Escape、重复关闭、无效 token、保存、放弃关闭；未调用系统确认框。
- 文本工具、表单、备份/保护、同步和网页共享操作通过模拟接口回归。取消“设为仅本机”后按钮永久禁用的问题已修复，并验证取消后可再次设置。
- 类型与语言绑定检查通过，检查范围中未发现未绑定提示。

## 响应与内存

同一隔离浏览器、万条合成记录、三轮连续选取测量：0.29 的事件处理 P95 平均约 0.80 ms，0.28 基线约 1.23 ms；两版均保持列表节点复用。这个数字不包含绘制、数据库、系统捕获或网络延迟。运行中的 One/Clipper 工作集仅作瞬时只读观测，窗口状态和负载未控制，不能当作后台或峰值内存比较。详见《性能测量-0.29》。

## 打包

最终交付报告核验冻结源码、构建内容、ASAR、完整目录与源码 ZIP，并对实际包内依赖、加密恢复、文件同步副本、Rust 文档解析、重复堆栈和原生字体服务回归。每项结果以交付校验 JSON 为准；检查失败不交付。

## 验证边界

使用隔离资料、隐藏 Electron 与无头浏览器；未使用物理键鼠、系统剪贴板或日常历史。没有重做物理双机同步、真人录音、第三方应用粘贴、多屏 DPI、干净 Windows 或 DWM 阴影像素验证。实际公开 Release 升级与签名仍待完成，整体持续优化目标未结束。
