# v0.11 区域录制与长截图验收

日期：2026-10-01。Windows 11 x64、Electron 44.5.1、150% 缩放；独立测试资料，串行运行真实桌面/剪贴板测试，结束后恢复原剪贴板。

## 区域录制

真实全屏测试窗口内外颜色不同，拖动选择 400×200 逻辑像素区域。实际媒体源 2561×1601，输出 600×300 偶数像素视频；逐帧取样确认区域内蓝/绿变化、四周没有区域外红色。暂停不计时，系统声音 AAC 轨道与裁剪视频共存。原有音频用例单独检查真实 loopback 测试音。

取消选区不增加历史，伪造/过期选区令牌拒绝，显示器配置改变前拒绝开始、开始后停止并保留预览。配置变化使用故障注入；不声称完成物理显示器旋转/热插拔验收。共用选区仍通过原有屏幕和区域截图像素检查。

## 长截图

真实全屏窗口中的滚动内容逐屏移动，原生屏幕快照进入拼接；初始 721×541，连续向下滚动后得到 721×991。解码 PNG，采样 36 行与源画布颜色逐行对照。覆盖重复帧不追加、自动重叠、撤销后重做、跳页触发手动对齐、调整重叠行数与实时接缝预览。

实际保存 PNG、新文件提交、取消保存、冲突不覆盖、图片历史及真实 Windows image/png 剪贴板尺寸均验收。独立 session 的预览在普通窗口不可读，取消后旧 URL 为 404。浅深主题、紧凑控制和完整长图预览通过截图检查。

边界包含取消选区、延迟真实快照后取消、显示器配置变化保留既有图像、未保存内容阻止迁移、保存对话框等待中模拟休眠且迟到返回不写文件、加密历史锁定、解锁不恢复旧图、退出保留/放弃确认。几何与纯拼接测试覆盖非整数缩放、负坐标屏幕签名、偶数编码尺寸、重复图案、反向滚动、无效重叠及超出尺寸限制。

发布前复查发现极窄选区缩略图被放大，新用例在首个候选包实际得到 420×3901 并失败。已改为不放大且限定 420×500 范围，并缓存当前帧缩略图，避免反复复制大图；修复后的候选包重新进行完整回归。保留故障证据：work/candidate-0.11-before-thumbnail-fix.json、work/candidate-0.11-narrow-thumbnail.log。

第二轮文件剪贴板回读遇到 Windows 短暂占用。测试改为仅对此占用错误进行最多 3 秒的有限等待，仍必须读到完全匹配的真实文件路径；不忽略内容差异或其他错误。保留原始记录 work/candidate-0.11-clipboard-contention.log，应用二进制未因该测试时机调整而改变。

## 适用限制

- 区域录制采用整屏捕获后在内存裁剪，选区是保存/编码范围，不是操作系统媒体授权范围。物理混合 DPI、多屏、Windows 10/N、真人麦克风及长时录制仍待实测。
- 长截图由用户在目标应用滚动后主动追加；自动的是重叠识别和拼接，不发送鼠标滚轮。固定标题、动态内容、重复图案及滚动过快可能要求手动对齐；用户需检查接缝与最终预览。
- 最多 30 屏、总 2,400 万像素、最长边 16,384、单屏 1,200 万像素、15 分钟；撤销仅最近一次追加。真实满容量和故障存储未完成。历史另有约 16 MiB 单项限制，超限图片可另存文件。
- 原始长图只在内存，清理不保证抹除系统交换/休眠或崩溃转储。导出 PNG 未加密；导出中强制结束进程/断电可能留下 .Clipper-image-*.part 明文片段。系统信号模拟不等于真人锁屏/休眠实测。
- 未签名 Windows x64 目录包。图片编辑、窗口截图、多语言、更多格式和元数据、签名安装/自动更新与其他物理兼容性项目继续推进。
