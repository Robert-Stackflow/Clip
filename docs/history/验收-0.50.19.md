# 0.50.19 Codex 入口与模型刷新

2026-10-07。本轮修复本机 Codex 的程序选择与升级后的模型列表刷新，包含 0.50.18 的快捷键和 AI 服务交互改进。

- 手动选择程序支持 npm 的 `codex.ps1`、`codex.cmd`、`codex.bat`、`codex.js` 及无扩展名入口，支持常见 npm 和 pnpm 安装布局。入口解析到所属安装目录内的原生程序，取消或选择无效文件保留原有设置。
- 界面显示手动选择的入口路径，悬停可查看实际程序；可以恢复自动检测。安装包继续不携带 Codex 运行时。
- 每次读取模型启动当前安装的程序，结束后关闭临时连接，保留账户连接；取消读取或关闭服务也会释放临时进程。模型分页、名称和推理强度处理保持一致。

本机实测 npm Codex 0.160.1 与桌面 Codex 0.160.0 均返回 7 个可见模型。原 Clipper 缓存标记旧版 0.146.0，当时只有 3 个可见模型；现象与复用升级前进程相符。诊断只读取账户和模型信息，没有改动日常账户或发送 AI 生成请求。

变更通过 626 项核心测试、类型检查、构建和语言绑定检查。中文与英文账户界面检查通过。隔离 Electron 实例验证实际 npm ps1/cmd 选择、程序启动、模型读取、选择器文件类型、无效选择与取消保留设置，以及恢复自动检测；测试资料暂停记录并清空快捷键。

交付文件名为 `Clipper-0.50.19-Setup-x64.exe`。发布构建会校验版本与全部编译资源的一致性，并检查安装器界面及隔离资料目录启动；这些检查不代表所有 Windows 环境的完整功能验收。
