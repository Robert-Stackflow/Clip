# 0.46.2 工具页面与媒体交互

开发目录为 `D:\Repositories\Clipper`，继续使用 One 的基础控件、分段滑块、对话框与按钮反馈。

## 页面布局

- 应用更新分为当前版本与更新选项、旧程序版本两张卡片。恢复点内容加入卡片，空状态保持一致。
- 外部链接按动作和 URL 示例分行，保留注册入口及调用确认。
- 局域网同步按设备名称、同步选项、配对设备、附近设备分组；状态和立即同步按钮移到居中的页面标题行。
- 网页共享按邀请与浏览器、可共享内容排列，搜索框与内容列表紧凑布局；共享范围说明移到邀请卡片，开启会话页移除该说明。
- 邀请链接随内容与宽度自动调整高度，通过当前会话的主进程接口直接复制。过期、已使用或会话变更时不能复制旧邀请。
- 展开说明增加高度与箭头动画，左栏固定保留滚动条空间，展开和收起不改变卡片宽度。侧边栏显示同步、共享状态，记录开关改为带图标的紧凑状态控件。

## 截图、录制与图片编辑

- 截图模式和录制模式使用实际分段按钮，支持方向键切换。截图模式与刷新窗口同排，移除底部提示及多余表单边框。
- 显示器按图标、名称、分辨率紧凑排列。显示器、独立窗口、录制来源都使用单层细边框和轻背景表达选中，边框位于卡片内。
- 录屏与录音将来源和设置放入两张卡片，区域操作与屏幕/窗口分段同排；开始操作移到顶部，仅录音使用独立说明区。
- 区域选择浮动工具条统一按钮高度与悬停反馈。
- 图片编辑工具、撤销和重做同排且同高。适应窗口按画布可用空间和内边距计算，四边保留空间，缩放仍可滚动，隐藏滚动条。
- 自定义选色面板包含色彩平面、色调、预设色和 HEX；贴着色块按钮定位，缩放窗口时更新位置，支持键盘、Esc 和点击外部关闭。
- 文字直接在图片上输入，Enter 完成、Shift+Enter 换行、Esc 取消；撤销和导出均使用完成后的标注。
- 旋转和翻转通过预览动画连接实际编辑结果。动画限制在画布可视区域，不能覆盖工具栏或设置；窗口缩放会结束预览并显示当前结果，减少动态效果时立即完成。
- 图片编辑、录制与长截图窗口不再设置屏幕内容保护标记。此调整针对远程桌面黑屏反馈；截图和图片导出仍使用原有 PNG 路径。
- 拖放窗口标题栏为 44 px，四周留白收紧，空白区域可拖动。按钮依次为添加、打开主窗口、置顶、关闭；隐藏且禁用最小化与最大化。
