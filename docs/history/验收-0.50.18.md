# 0.50.18 快捷键与 AI 服务

2026-10-07。本轮完善设置与 AI 服务交互，保留 0.50.17 的本机 Codex 检测方案。

- 主窗口、快捷面板、快捷回复、AI 对话、拖放窗口及堆栈粘贴快捷键均支持清空。保存后立即注销，重启后保持为空；清空快捷面板快捷键时同时关闭 Win+V 拦截。
- Codex 登录检查显示结果反馈，授权码使用主进程系统剪贴板复制。新增 Codex 服务可在账户连接后、保存配置前读取模型，读取本身不写入服务配置。
- 默认 AI 服务固定在首位，其他服务支持拖拽或 Alt+方向键排序并保存；编辑服务保留原有位置，取消拖拽或保存失败恢复顺序。排序与默认服务切换提供移动动画，并遵循减少动态效果偏好。
- AI 对话模型菜单采用细纵向滚动条，长名称和模型 ID 自动换行，无横向滚动。
- 图床连接与认证卡片的最后一个可见设置项不再因隐藏字段绘制额外分割线。

变更通过 622 项核心测试、类型检查、构建及语言绑定检查。设置、Codex 账户与草稿模型读取、服务排序、模型菜单及模型编辑界面检查通过。隔离 Electron 实例验证了快捷键实际注销及重启保持、系统剪贴板授权码复制、未保存服务模型读取与排序持久化；授权后端使用测试替身，未修改日常账户或发送 AI 生成请求。

交付文件名为 `Clipper-0.50.18-Setup-x64.exe`。发布构建会校验版本与全部编译资源的一致性，并检查安装器界面及隔离资料目录启动；这些检查不代表所有 Windows 环境的完整功能验收。
