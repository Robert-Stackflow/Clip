# 0.47.0 离线资料与侧边栏分组

侧边栏新增「表情符号」与「CheetSheet」，按剪贴板、自定义分类、工具、连接与分享、管理分组。宽度、导航行、左边框和折叠过渡按本地 One 的实现调整；折叠状态仍持久保存，减少动画设置仍生效。

表情符号包含 Unicode 官方清单的 3,963 个完整 Emoji、2,339 个符号、手工整理的颜文字、WHATWG 的 2,125 个带分号命名实体、149 个 CSS 命名颜色、IANA 的 2,349 个 MIME 类型和完整 128 项 ASCII。CheetSheet 包含 Git、LaTeX、Bash、Linux 与 JavaScript Regex 五个主题。资料快照可离线使用，进入页面时才加载约 0.6 MB 的独立模块；主页面脚本不包含大型目录数据。

验证：TypeScript 类型检查、语言目录与绑定检查、455 项核心测试、浏览器资料页与 208/56 px 侧边栏布局测试、原生 Electron 自定义协议加载和复制测试通过。0.47.0 完整目录包的 200 个构建文件与源码构建一致，包内程序再次通过资料页加载、导航、复制及外部链接白名单检查。原有外观布局测试的主界面测量未发现失败，但其部分辅助窗口在无头浏览器中报告零尺寸（192 项），与本次新增的主窗口资料和侧边栏无关；旧设置按钮的测试路径已更新为当前内联设置。

数据来源及许可记录见 [资料目录说明](../../src/renderer/reference-data/README.md)。旧的未标记 `.building` 暂存目录仍保留；本次使用独立的带标记版本暂存目录成功打包，未改动它。备份预览工作保存在独立 Git stash，未混入本版。
