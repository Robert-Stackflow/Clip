# 0.46.13 备份导入容量计算

## 改动

备份恢复原来每写入一条记录都会重新汇总整库容量，批量导入时重复扫描已有数据。本版在导入事务开始时读取一次容量，随后按实际写入的 UTF-8 字节数增量更新；替换已有记录和新增快捷回复也计入差额。事务结束或失败后清除临时计数，普通读写仍使用数据库计算。内部版本号与包版本统一为 0.46.13。

## 检查

核心测试 454 项、TypeScript 类型检查和语言绑定检查通过。新增回归在混合新旧记录与快捷回复的两次导入中，对照数据库直接汇总验证容量和最终记录数；缩略图回调中途失败后，事务回滚且容量恢复。独立运行目录的 199 个构建文件与源码构建结果一致。

使用同一批 1,800 条合成文本记录，在独立 Node/内存 SQLite 进程中交替比较三轮：修改前 609、634、633 毫秒，修改后 239、228、205 毫秒。各轮均为 1,800 条，容量 1,084,290 字节。这个对照只测导入路径，不代表完整恢复窗口响应或内存峰值。

## 限制

备份预览、解码和最终恢复仍在主进程，较大备份可能让窗口短暂停顿。真实大型加密备份、磁盘数据库和长时间使用的内存表现仍需单独验证。独立运行目录尚未经过完整功能验收。按用户要求，本版不继续调查录音录屏性能。
