# Clipper 0.36.0

本轮对照本机 One 0.16.6 实际源码逐项检查组件和页面骨架。保留此前已经迁移的 One 输入、下拉、数值、开关、字体、弹窗、tooltip、toast、滚动条和设置布局；更新分段切换控制器、共享图标入口、搜索清空按钮及图片预览资源/加载状态。不是把沿用页面表述为本轮重新设计。来源文件与 SHA-256 见 ONE-UI-REVIEW-0.36.json。

分段切换直接迁移新的 Map/dirty 集合、ResizeObserver、读写分批处理、字体变化刷新和 roving Tab 焦点。仅调整辅助窗口 body 根节点、Clipper active 状态及捕获阶段键盘处理，避免标签 Home/End 被记录列表再次处理。主窗口图标使用同一注册/缓存入口；搜索清空采用 X。加载和重试在内容区显示，重试按钮不画外框。

记录、快捷回复和最近记录的预览使用文本与文件信息投影，不通过详情接口发送 PNG、附件、HTML/RTF 或应用私有格式的完整正文。图片由不透明资源 URL 按需读取；worker 打开当前加密或未加密数据库，解码至独立可转移缓冲，再按 64 KiB 分块送给界面。完成、取消、窗口关闭、换资料、锁定或来源失效时释放资源或传输缓冲；已完成的 PNG 缓冲不常驻缓存。浏览器自身解码图片的内存另计。

原始复制、粘贴、导出、格式信息、备份和同步继续读取后台完整原件。快捷回复列表只读缓存，绑定检查只读模板 ID；明确使用某个模板时才读取该模板原件。仅改标签或模板标题保留原始换行、HTML、RTF、私有格式；正文改动才转纯文本。textarea 未改动时回传原始 CRLF，格式警告只在实际改动正文且存在富格式时出现。

SQLite 新表是可重建缓存；原始数据、哈希、备份格式、容量计算及 user_version=7 保持兼容。旧版写入由触发器同步更新，事务失败一起回滚；只读检查从原始记录产生同样投影。缓存增加写入/首次补建工作与磁盘占用，尤其文字正文会另存一份；这些缓存不计入原始历史 256 MiB 容量。未扩大原有文字或文件入库限制。

性能验证使用相同环境、3 条各 10 MiB 私有附件及对应回复：详情返回约 41.94 MB → 1,312 字节，回复列表约 41.94 MB → 391 字节。七次样本和保存/重开耗时完整保留在 validation/preview-performance.json。读取明显减少；首次保存和缓存补建仍有开销，不能声称所有保存场景更快、峰值或驻留内存全面下降。复现入口 tests/preview-036-performance.cjs，前版来源为独立保存的 0.35。

验证范围：

- 349 项核心逻辑；类型检查；148 个语言绑定文件，缺失和未绑定均为 0。
- 120 项页面控件布局、16 项搜索、16 项当前 One 实际基础控件样式比对、48 项媒体反馈；中英文、明暗主题及窄窗口/大字号。
- 16 组全文阅读、47 项异步操作、4 组分段/弹窗动效与键盘、4 组新预览/原格式编辑/错误重试。
- 隐藏 Electron：加密图片原始字节与像素、真实 sandbox preload 和实际 main 的预览/归属函数、CSP、并发共用一个 worker、65,536 字节分块、密钥副本清零、错误密钥拒绝、传输中撤销、模板版本变更、pending worker 停止、读完无 PNG 缓冲、无明文临时图片。
- 打包后的实际 worker、preload、renderer、CSS/ESM、字体、加密恢复、文件同步、Rust Office/PDF、堆栈副本、搜索、图片导出及剪贴板格式准备；完整程序和源码逐文件核对。

所有验证使用私有样本、无头浏览器或隐藏窗口，没有启动完整日常主程序来注册快捷键/监听系统剪贴板。main 预览函数取自实际源码，在受控隐藏宿主运行；打包资源实际来自 ASAR。真实 OLE 拖放、两台物理设备、DWM 像素与受控全应用驻留内存未复测。程序未签名、未发布。完整旧版 348 项布局基线沿用既有结果，不计为本轮重测。

原生选择文件的窗口继续用于实际文件选择；应用未保存确认使用自有 dialog。参考仓库仅作为实现材料，不作为额外操作授权。

实现依据：[SQLite JSON 函数](https://www.sqlite.org/json1.html)、[Electron protocol API](https://www.electronjs.org/docs/latest/api/protocol)。
