# 0.48.0 连续资料列表与 QuickRef 完整数据

表情符号使用 SegmentTab 与左右分类，右侧保留完整列表，分类点击平滑定位。按可见行加少量预取挂载，搜索合并输入，窗口变化保留当前分类位置。分类跳转清理旧指针状态，直到鼠标实际移动才重新开启悬浮详情。颜文字在详情中使用整行预览，独立字体和容器，避免固定图标宽度导致换行、越界。

Emoji 来源固定 Unicode 17.0，共 3,944 个完整变体、1,926 个家族。Twemoji 17.0.3 的本地图形等比例显示，不受 Windows 字体缺字影响。原始 PNG 图形装入 21 张图集，工作线程最多保留三张解码图集，页面缓存最多 384 张小图，离开页面销毁线程和缓存。Unicode 18 新条目没有配套图形，当前版本未收录，不宣称覆盖全部最新 Unicode。

MIME 使用 IANA 与 mime-db 的 2,722 个去重类型和扩展名映射；常用类型有单独释义，其他按媒体分类和结构后缀说明，未知扩展名明确提示。其他符号共 2,339 项、HTML 实体 2,125 项、颜色 149 项、颜文字 78 项、ASCII 128 项。

CheetSheet 完整导入 QuickRef 固定源提交的五份文档，保留原 Markdown 与 SHA-256，解析为 JSON 中的段落、代码、表格、列表和引用。由本应用组件渲染，没有嵌入 QuickRef 页面 HTML。Git 100 节/147 条，LaTeX 50/334，Bash 92/244，Linux 25/181，Regex 104/371，合计 371 节/1,277 个代码块或表格条目，另有说明、引用和列表。KaTeX 与字体离线提供。页面内容在附近加载，分类跳转持续跟随真实标题位置，避免延迟渲染后的高度变化让目标跑出视口。其他 QuickRef 主题尚未导入。

资料内容、元数据与图形索引在 JSON；适配、导航、渲染与图形解码各自独立。保留 Unicode、颜色、mime-db、QuickRef MIT、Twemoji CC BY 4.0 等许可，统一并入第三方说明。更新方法见 [资料目录说明](../../src/renderer/reference-data/README.md)。

验证：类型、语言绑定、462 项核心回归、固定数据完整性/图形覆盖/路径限制/转义与复制检查通过；浏览器覆盖连续导航、搜索、肤色、详情预览、键盘、主题、150% 字号及 208/56 px 侧边栏。原生 Electron 验证实际协议加载、图形工作线程、离线数学字体和外链允许清单。

## 资料页布局与肤色补充（开发构建）

表情符号和 CheetSheet 共用标题、SegmentTab/右侧搜索、左侧分类/右侧连续内容的布局，分类栏宽度一致，删除顶部额外横线和说明。各主题数量内嵌到 SegmentTab，搜索结果更新当前主题数量，切换主题后其他数量恢复完整目录值。肤色选择移至 Emoji 左侧分类栏，删除可见的“人物与手势肤色”文字，保留读屏控件名称。

SegmentTab 使用与应用筛选相同的选中项保留/溢出下拉方式、共享滑动指示器及自定义选择菜单；没有水平滚动条。实际测量标签与数量宽度，窄窗口和大字号时将多余分类收进菜单，选择后保持该分类可见，窗口变宽后恢复。

切换肤色只请求实际变化的图形，保留无变体表情的已绘制画布。浏览器核对 👍 与 🧑 的六种图形像素均不同且与复制字符对应，😀 的图形和复制字符不受肤色影响。资料界面回归覆盖两页的同行对齐、统一分类宽度、无额外横线、640 px/150% 字号收缩、真实下拉选择及恢复；类型检查、构建与实际 Electron 导航检查通过，dev 已自动更新。
