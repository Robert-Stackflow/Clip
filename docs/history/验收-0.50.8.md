# 0.50.8 共用粘贴目标校验

2026-10-04。历史记录、快捷回复、拖放容器和堆栈的自动粘贴共用同一目标窗口校验：先确认目标仍存在且属于原进程，再修改剪贴板。目标已关闭时，直接提示切换目标应用，当前剪贴板和堆栈队列保持不变。仅复制操作仍正常写入剪贴板。

源码验证：类型检查、`tests/stack-multi-app.cjs`、`tests/stack-ui.cjs`、`tests/paste-edge.cjs` 通过。跨应用测试用独立 Electron 输入框和 Edge 表单验证堆栈顺序、普通 Ctrl+V、主界面按钮及普通历史记录自动粘贴；关闭 Edge 后，堆栈和历史粘贴均拒绝失效目标且不修改剪贴板。Edge 文本和 HTML 样式回贴回归通过。测试使用隔离资料并恢复原剪贴板；尚未覆盖管理员应用和复杂网页编辑器。

Windows x64 目录包位于 `release/0.50.8/win-unpacked`，260 项资源与构建一致，保留 0.50.8/0.50.7。`node tests/packaged-smoke.cjs 0.50.8` 验证隔离资料启动、界面样式及原生组件；包内 `tests/stack-multi-app.cjs` 再次通过正常历史粘贴和目标关闭后的拒绝路径。未执行正式公开发布、签名信任链和干净 Windows 系统验收。
