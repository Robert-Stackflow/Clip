# 0.24 更新功能验收

本版延续 0.23 的 One 风格界面，增加 GitHub Releases 更新。最新工作源码在 `work/next-0.24.0`，没有覆盖根目录的日常版本。测试均使用隔离资料、进程或浏览器，没有操作用户键鼠或剪贴板。

## 已实现与验证

- 设置 → 应用更新：当前版本、手动检查、每日自动检查、版本说明、下载进度、取消、错误与安装入口。更新选项立即保存，其他设置的未保存值在切换分类时保留。
- 固定 `Robert-Stackflow/Clipper` 的正式 Release；严格版本、资产名称、大小、SHA-256 与 HTTPS/跳转来源限制。流式下载并有总时限、空间与取消保护。
- 安装版确认当前用户安装位置和登记，辅助进程握手成功后正常退出。辅助程序等待原进程结束，重新校验文件，运行已有安装器，核对安装后版本，再重新打开应用。失败只在旧版登记及文件摘要仍一致时重开旧版。
- 草稿、预发布、旧版本、缺失摘要、不完整文件、摘要不一致、非法来源、未保存内容与改变的会话不会进入安装。
- 267 项逻辑测试通过，其中包括更新协议/真实本地 HTTP 下载，以及生产主入口的 IPC 权限和未保存内容保护。
- 更新页 72 个中英、深浅色、窄窗口与 150% 字号场景通过；版本说明中的 HTML 仅作为文字显示。已有页面 276 个场景及真实离屏 Electron 渲染通过。
- .NET 辅助程序用同一生产源文件、隔离安装身份编译验证：带版本号的安装名称识别、生产程序拒绝测试身份、退出等待、成功、失败、校验与超时。真实进程检查证明等待中的辅助程序仍存活。
- 真实自定义前端和 NSIS 引擎在独立身份与路径中完成首次安装、重复安装、卸载、运行中拒绝、拒绝降级和失败恢复；测试资料摘要保持不变。没有启动被安装的 Clipper。
- 最终包的 54 个构建文件、三个原生辅助程序、SQLite 和原生桥加载核对通过。最终自定义安装器另做实际隐藏 WPF 渲染及嵌入内容提取/摘要/取消检查。

机器证据在源码交付的 `validation/`；完整测试脚本在 `tests/`。安装器编译日志记录实际安装包、嵌入载荷与 app.asar 摘要。

## 验证边界与剩余工作

公开最新 Release 接口本次返回 HTTP 404，表示当前调用没有取得可用正式发布。未把本地 HTTP 服务或测试安装器结果当作真实 GitHub 跨版本升级。需要仓库及正式资产公开可访问后继续验证该链路。

更新辅助程序进程测试使用模拟安装器，真实 NSIS 生命周期另用独立身份验证；当前没有从日常 Clipper 进行真实联网升级。安装程序文件失败恢复已经验证，历史数据格式降级仍未实现。本次安装包未签名。干净 Windows 10/11、物理多屏及完整跨应用回归仍按开发计划保留待验收。
