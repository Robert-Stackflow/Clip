# 0.49.11 性能与响应优化收尾

按用户要求，本轮完成后停止扩展性能与响应调查。既有最近记录后台搜索、元数据先匹配、闲置窗口释放、图片后台转换、文件与大内容后台保存均保留。已处理的肤色选择器留白不再修改，录音录屏性能不纳入本轮。整体功能目标仍有独立工作，不将此次收尾等同于全应用验收完成。

## 最后实现

保存本应用的普通记录时，将原有完整 UTF-16 JSON 字符串改为直接生成 UTF-8 缓冲区。较长的 PNG 与格式数据保留原字符串引用，按有界片段写入精确长度的缓冲区；其他内容使用原有 JSON 字符串转义。写入 SQLite 时显式转为 TEXT，保存成功或异常后清零临时缓冲区。记录主数据、字段顺序、原格式与摘要没有改变。

预览与快捷回复索引在一次字段投影中复用解析后的 JSONB 文档，并减少二进制长度计算的临时副本。JSONB 只用于投影，主记录仍保存相同的 JSON TEXT。旧 v7 数据库仅替换本应用自己的六个索引触发器，不重建原记录或缓存。再次打开不重复迁移，快捷回复修订号保持。

新增校验涵盖大内容片段边界、中文与 Emoji、控制字符及孤立代理项、旧格式特殊字符串、原始 JSON 字节一致、SQLite TEXT 类型、成功及观察回调失败后的缓冲区清零与回滚；明文和加密数据库的旧触发器迁移、原记录、预览、快捷回复缓存及重复打开保持。

首次打包遇到正在使用的原生 SelectionHost 文件，未强制关闭 dev 或修改原生程序；原生子进程自然结束后重试构建成功。目录包 263 项构建文件一致，保留 0.49.11/0.49.10。没有修改已测试目录包内的程序或原生二进制。

## 保存副本原型

实际 Electron 的 CaptureWriter、Store 和容器事务，使用自建 1,600×1,600 噪点图，各三轮交替比较原实现、JSONB 投影、UTF-8 序列化，共九个有效样本。基线源码固定为 e772d05（0.49.10）。原始内容、预览、容器与缓存数量以及数据库原 JSON 字节均核对。

| 中位数 | 原实现 | JSONB 投影 | UTF-8 序列化 |
| --- | --- | --- | --- |
| 保存完成 | 346.4 ms | 364.6 ms | 351.0 ms |
| Electron 主进程最大工作集 | 349.6 MiB | 290.9 MiB | 335.1 MiB |

两个原型独立减少副本，但保存等待没有稳定加快。工作集最大值包含后续内容核对，属于自建单应用原型，不代表完整应用峰值。没有强制 GC 或调整工作集，所有有效慢样本与高峰值均保留。

初次原型误取 Playwright 启动器 PID 的工作集，约 7.2 MiB 与实际进程阶段数据矛盾。这组峰值无效，单独保存并标记，不参与内存改善结论；修正为 Electron 实际主进程 PID 后再做交替比较。

## 最终目录包复测

0.49.10 与 0.49.11 各三轮交替启动真实目录包，每个程序依次导入自建 8,000×4,800 纯色 JPEG 和 1,600×1,600 噪点 JPEG，共 12 个样本。隐藏测试自己创建的可信主窗口，将文件选择结果替换为自建路径，后续走正式 addFiles IPC、转换、缩略图、保存、索引、容器变更及通知；实际渲染器并行执行 updateState 测量等待。两版的原文件 SHA-256、原始 JFIF 格式、预览和容器数量全部保持。

| 中位数 | 大图 0.49.10→0.49.11 | 噪点 0.49.10→0.49.11 |
| --- | --- | --- |
| 完整导入等待 | 689.4→695.5 ms | 842.1→798.0 ms |
| 最长界面 IPC 等待 | 7.1→28.6 ms | 77.4→83.9 ms |
| 主进程最大计时器间隔 | 20.1→20.5 ms | 61.7→62.8 ms |
| 采样进程树绝对峰值 | 437.5→435.8 MiB | 622.5→509.4 MiB |
| 采样阶段峰值增量 | 26.9→28.0 MiB | 194.8→84.4 MiB |

噪点绝对峰值旧版 550.9–645.1 MiB、新版 507.9–611.3 MiB，保留新版首轮 611.3 MiB 高样本。大图峰值基本相同，噪点采样中位数改善不能推断全应用或长期驻留目标已解决。100 ms 进程树采样可能遗漏短峰值；先大图后噪点、两项之间读取原内容验证会影响二次导入起点，故同时报告绝对峰值与增量。

噪点完成等待略降，但 IPC 等待没有进一步改善；大图旧版 4.9 ms 和 7.1 ms 低样本均保留，最新版大图中位数更慢。不能声称全面提速。另一次保存锁定验证的两个准备导入耗时为 806.0 和 892.8 ms，也完整归档，未用重跑覆盖。

候选版原生转换活动期间锁定通过。另一个实际目录包在后台保存线程活动期间，通过正式 IPC 锁定已加密的自建历史；导入拒绝且仅有解锁窗口，关闭后解锁并用只读数据库核对主记录、列表索引仍各两项，无迟到第三项。没有关闭提交、有效性或取消守卫。
