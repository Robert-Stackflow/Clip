# 0.49.1 资料页字体加载与间距

表情列表仍直接显示 Unicode 字符。通过既有字体入口按需加载本机安装的 Segoe UI Emoji 文件，不附带字体文件、离线图片或图集；修复原字体协议缺少跨来源配置的问题。字体文件请求仅允许 clipper://app 来源，地址仍使用受限随机令牌；源文件只由受信任的应用窗口申请。没有可用文件或加载失败时，继续使用系统字体。

Windows 系统字体路径与字体文件路径采用不同的 OpenType 排版度量。新路径依据本机字体测得的上升与下降度量保留原基线。五类原生截图核对覆盖笑脸、手势、人物、ZWJ 职业和旗帜；字形外接边界至多相差 1 个截图像素，整幅截图的平均通道差异不超过 1%；边缘抗锯齿不能声称逐像素完全一致。六种手势肤色的截图各不相同，复制保留完整 Unicode 序列。连续离开及重进六轮，页面只注册一个专用字体，离开时从 FontFaceSet 删除；异步来源或加载迟到不会修改已经离开的页面。

减少上方工具栏至分类栏的留白：工具栏下方 8 px、分类栏顶部 8 px；肤色选择不再额外添加底部间距，分类栏内间距统一为 8 px。CheetSheet 与表情页共用布局。代码阅读样式覆盖 Git、LaTeX、Bash、Linux、Regex，代码块 14 px、行内代码 13 px，明确继承等宽字体与行高；语言高亮与亮暗配色、原文复制、LaTeX 公式与字体均再次验证。

TypeScript、476 项核心回归、源数据及安全渲染、资料页界面和实际 Electron 检查通过。目录定位、右侧 14 px 留白、自适应标签和窄窗口文字换行保持原行为。字体检查同时验证外来页面不能请求字体文件，以及所选 Arial 文件字体能实际加载。正式发布包复测也通过，包含 150% 文字缩放和专用字体的实际加载。

字体资源从页面移除不等于浏览器立即释放全部字体缓存。滚动响应改善不能代表总内存峰值或长期驻留已经改善，仍须独立测量。按用户要求不继续调查录音录屏性能。


发布包 0.49.0 与 0.49.1 在本机各 5 轮交替启动独立 Electron 进程，使用相同的空资料和暂停采集设置。每轮记录首次打开、140 帧连续快速滚动、70 帧再次滚动、12 次受控滚轮输入、搜索及返回记录页后 10 秒自然驻留。没有强制 GC。工作集每 250 ms 采样指定应用进程树，含渲染器和辅助进程；不是全机内存、私有字节或长期驻留。下表为五轮中位数。

| 指标 | 0.49.0 | 0.49.1 |
| --- | ---: | ---: |
| 首轮滚动 p95 帧间隔 | 104.1 ms | 20.8 ms |
| 首轮最大帧间隔 | 229.2 ms | 34.7 ms |
| 首轮超过 50 ms 的长任务数 | 41 | 0 |
| 再次滚动 p95 帧间隔 | 111.1 ms | 20.9 ms |
| 每轮最慢滚轮输入至两帧确认 | 475 ms | 131 ms |
| 输入搜索至目标条目出现 | 198 ms | 148 ms |
| 首次打开至条目出现 | 290 ms | 541 ms |
| 首次打开至文件字体就绪 | 系统字体路径，无此阶段 | 624 ms |
| 相对打开前的进程树峰值工作集增量 | 154.6 MiB | 218.1 MiB |
| 返回记录页 10 秒后的工作集增量 | 131.8 MiB | 202.8 MiB |

两版首轮和再次滚动的 DOM 均最多 187 项。新版五轮冷滚动没有长任务；再次滚动有一轮出现 1 次长任务，其余为 0，不能声称任何情况下都没有长任务。滚轮数字包含自动化传输和两帧确认，不能当作真实硬件输入延迟；首次打开较慢，后台字体初始化与首次布局仍须改进。字体文件和字体缓存使峰值增量约多 63.5 MiB，离开后 10 秒增量约多 71.0 MiB，当前响应改善伴随实际内存代价。删除注册字体尚未消除浏览器字体缓存，不将这项交付计作内存优化。

固定报告：work/current/emoji-performance/result.json、work/current/emoji-font-native/result.json 和 work/current/reference-native/result.json；发布目录 release/0.49.1/win-unpacked 的 262 项构建文件校验一致，保留 0.49.1 和 0.49.0。实际发布包覆盖五个主题的字号、高亮、原文复制、Git 目录定位、数学字体、右侧留白、人物/手势肤色、专用字体清理和来源限制。开发窗口已自动刷新。持续目标仍有全应用内存、其他日常场景及功能对齐事项未完成。
