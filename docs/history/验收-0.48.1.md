# 0.48.1 原生 Emoji、目录定位与代码阅读

按用户要求移除离线 Twemoji 图形，列表、全局肤色选择、详情肤色变体及更多混合肤色组合均直接显示 Unicode 字符，由系统 Emoji 字体绘制。保留 Unicode 17 的 3,944 个完整序列、1,926 个表情家族，以及原有搜索、连续虚拟列表和分类平滑导航。

人物和手势使用原数据中真实存在的肤色变体；笑脸没有肤色变体。复制始终保留完整 Unicode 序列，详情中的单独肤色选择不更改全局设置。系统字体没有覆盖的较新字符可能显示缺字，本轮按请求不提供图片替代。

包含上一轮已完成的资料页布局：搜索和自适应 SegmentTab 同行、数量放在标签内、肤色按钮放在左侧分类栏、两个资料页布局统一。两个页面右侧统一保留 14 px 内容留白，滚动条不再贴紧内容。

修复 CheetSheet 长目录点击后左侧分类异常滚动：定位期间及完成后保留显式目标分类，右侧经过的章节不覆盖它；用户滚轮、触摸、滚动条操作或滚动按键释放定位状态。分类可见性以实际视窗坐标计算，消除重复扣除 offsetTop 的错误。

CheetSheet 五个主题统一提高阅读字号：代码块 14 px、行内代码 13 px、说明 13 px、表格 12 px，均响应文字缩放。优先使用 Cascadia Code/Cascadia Mono 等宽字体，明确让 code 继承字号、字体与行高。代码块和行内片段通过语言解析器生成静态高亮，包含 shell、LaTeX、正则片段及示例中的 Python、JavaScript、PHP、Java、SQL、INI；亮暗主题分别设置颜色，公式预览保留。解析限于附近章节，无逐项编辑器实例；大于 64 KiB 或不支持的语言安全显示原文，复制按钮仍使用原始数据。

已通过 TypeScript、离线数据/安全渲染、资料页 UI、实际 Electron 与 462 项回归验证。UI 验证覆盖 Git 第 65、30、95、12 项的跨目录跳转，定位过程中连续检查选中状态、可见性与左栏位置，五个主题的末尾分类均保持可见；手动滚动后正确恢复章节跟随。五个主题的高亮与字体大小逐一检查，语法样式不改变复制内容；完整 JSON 文档安全渲染、嵌套行内片段及大代码回退检查通过。实际 Electron 已验证 👍 和 🧑 六种肤色均产生不同的原生字体截图，显示、复制与完整 Unicode 序列一致。中英文字绑定检查没有未绑定项，既有静态候选仍有 33 条，不能据此声称全应用语言验收完成。

原生 Unicode 绘制的代价仍在：140 帧连续快速滚动实测，Emoji 的 p95 帧间隔 104.2 ms、最大 194.5 ms，仍有字体相关长任务；DOM 最多 187 项。MIME/符号/实体同轮 p95 均约 7.1 ms。按用户请求使用原生字符，本轮不以图片替代字体，也不宣称 Emoji 快速滚动响应已经优化完成。记录位于 work/current/reference-performance/result.json。本轮不包含仍在开发的备份正式恢复工作线程，不宣称总内存峰值或所有性能任务已完成。

完整 Windows x64 目录包位于 release/0.48.1/win-unpacked，261 项构建文件与打包内容一致。已从该目录的 Clipper.exe 启动隔离资料进行实际验证：五个主题字号、高亮与原文复制、Git 长目录定位、14 px 右侧留白、LaTeX 字体和人物/手势六种肤色均通过，亮暗代码配色的实测文字对比度均不低于 4.5，页面无异常。这里只记录本次资料页验收，不代表全功能验收完成。开发窗口保持运行并已自动更新。
