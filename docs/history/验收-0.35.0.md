# Clipper 0.35.0

本轮逐项迁移 One 0.16.4 的全文阅读组件：code-view.ts 的只读 CodeMirror 状态、全文查找与选择、行号和语法高亮、preview-redesign.css 的搜索行与语法配色，以及 code-worker.ts 的按行准备方式。来源文件摘要见 ONE-UI-REVIEW-0.35.json。基础按钮、输入、下拉、开关、分段标签和页面骨架继续使用此前迁移的共用实现；本轮不是重新复制所有页面。

Clipper 的适配包括中英文、外观字号与普通文字字体、自动换行按钮、独立 worker、按需加载 ESM 和语法包，以及页面生命周期管理。短普通文字保留轻量预览；代码和超过 32768 字符的普通文字使用全文阅读器。只绘制可见区域，文档内容保持完整；这遵循 [CodeMirror 文档视口机制](https://codemirror.net/docs/guide/)。历史记录和快捷回复均接入。

后台刷新未改变当前记录时，保留阅读器、滚动和选择，不重复调用详情接口。内容、标签、收藏、队列位置或搜索条件改变时重新加载；切换页面销毁阅读器和 worker，并阻止旧请求写回新页面。移除曾在切页后保留完整详情的无用途全局变量。自动换行独立保存代码和普通文字的选择。

全文查找支持 Ctrl F、Enter、Shift Enter；Escape 先关闭查找，阅读器保留原有选择快捷键语义。主操作“复制”和“粘贴”继续读取后台原始记录。阅读器按 One 的实现将 CRLF/CR 转成 LF，选择部分文字复制使用阅读器的 LF 文档；主操作不会把阅读器中的归一化文本回写到原记录。未扩大现有文字入库上限：仍为 UTF-8 1 MiB。

验证：

- 339 项逻辑测试、类型检查、145 个语言绑定文件检查通过。语言覆盖已加入阅读器及 worker。
- 16 组阅读器场景：两种语言、明暗主题、普通多行、单行、代码，全文内容、末尾查找、全选复制、只读、代码语法、换行、大字号及窄窗口、未变刷新、元数据变化、切页旧请求；另覆盖快捷回复的完整内容、复制、刷新和正文变化。
- 真实 Electron 隐藏沙箱和打包后 ASAR 验证完整文档、全文查找、生命周期、按需加载、模块与 worker、样式和 CSP。测试 IPC 是私有适配器，不操作系统剪贴板。
- 基础组件与 One 实际样式 16 项比对、120 项页面控件、16 项搜索输入、48 项媒体反馈，以及原有 47 项异步操作专项复验。
- 打包后核对全部构建文件、实际可执行程序版本、既有加密备份/恢复、同步附件、Rust 文档解析、重复堆栈、字体、搜索、图片传输和剪贴板格式逻辑。源码包解压后逐文件核对。

性能与范围：

一致的无头 Chromium 私有小样本，80500 字符单行文本：首次切换从 424 ms 到 136 ms，五次后台刷新期间最大定时器间隔从约 570 ms 到约 9 ms，重复详情请求从 5 次到 0 次。另两种多行和代码样本首次打开增加了按需模块开销，不能声称每种文本首次打开都更快。接近入库上限的三种文本（966000–1015000 UTF-8 字节）在本次运行中首次切换为 152–179 ms，DOM 文本约 2000–7900 字符；文档状态和末尾内容仍完整。测试环境与采样结果详见 preview 性能 JSON，以上为一次测量，不是延迟保证。

CodeMirror 增加约 1.5–1.9 MiB 的小样本 JavaScript 堆开销；相应 DOM/浏览器侧堆减小。未查看代码/长文字时不加载阅读器模块、CSS 或 worker。切页释放文档和 worker，已加载的共用模块继续缓存。不能由这组数据宣称全应用驻留或峰值内存统一下降。初期超过 1 MiB 的前端压力样本不代表实际入库能力，不纳入对外功能范围。

只读快照中日常 One 是 0.15.2，日常 Clipper 是 0.28，另有未知版本临时 Clipper；页面状态、后台任务和工作集回收不一致，不能作优化前后的对照。保留快照原始值，不终止这些进程。整机受控驻留内存、真实桌面拖放和系统剪贴板仍待专门验证。
