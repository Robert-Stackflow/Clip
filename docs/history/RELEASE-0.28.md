# Clipper 0.28.0

- 迁移 One 的实际控件、设置导航、外观页面、字体选择器和提示组件。
- 自定义窗口按钮，保留原生 Windows 边框、阴影、缩放和贴靠体验。
- 外观、语言、桌面交互、划词、搜索直接在设置页配置。
- 统一设置、数据备份、文本工具与同步页面布局；同步分为设备、配对、共享内容三个区域。
- 正在记录/暂停开关移至侧边栏。
- 最近记录重排为单行标题搜索、轻量筛选、无描边列表和浅底预览区；操作按钮去除显式边框。
- 拖放窗口合并标题和操作栏，去掉操作按钮描边与空状态栏。
- 系统字体枚举在原生辅助进程执行，字体缓存有上限；页面卸载清理菜单和监听器。
- 保留 0.27 的文件附件同步、原始剪贴板格式、加密文件信息与录制导出、堆栈重复副本功能。

运行方式：打开整个解压目录中的 Clipper.exe，保留 resources 和旁边所有文件。退出其他版本的托盘进程后再运行新版。

验证采用隔离数据和隐藏/无头窗口，没有操作日常剪贴板、真实键鼠或日常资料。双机真实局域网和各应用原生粘贴仍需实机反馈。
