# 0.49.0 正式备份恢复的后台保存与索引

已校验的备份快照一次转交工作线程；后台完成 JSON 解析、校验、PNG 缩略图、合并保存及列表/搜索索引更新。准备阶段允许其他写入继续，仅正式事务进入串行写队列；正式恢复及旧 JSON 导入使用同一路径。前一次预览验证仍保留，不用磁盘上随后改变的文件代替已检查内容。

主窗口状态读取通过 WAL 读取快照完成，恢复期间返回一致的旧资料或已提交的新资料。工作线程内部事务同时维护同步账本；成功退出后返回少量记录标识与分类，主窗口更新分类缓存和网页共享状态。不会把所有恢复正文再送回主进程。本机较新的重复记录、收藏/标签、私密与共享标记、队列/容器、删除撤销、模板/分类/脚本均保留原合并语义。导入脚本不自动运行。

恢复对话框处理中显示状态并允许取消。取消、令牌过期、锁定、退出及超时会结束准备或回滚尚未提交的完整事务；原生解码取消等待子进程退出，数据库打开后合作取消，关闭连接后才完成工作线程退出。提交决定已经生效时等待提交确认，防止向用户返回取消却留下已提交数据。加密历史密钥只在写队列实际开始时复制至线程，随即清除主进程临时副本，线程打开数据库后清除副本。锁定和退出等待事务与工作线程收尾，未保存捕获内容的既有确认保持。

新增 9 项核心检查，覆盖明文和加密历史、图像/附件/富格式原始内容、检查后的文件变动、本机较新记录、私密及共享状态、同步账本、队列/容器、删除撤销、模板/分类/脚本、失败整体回滚、取消后的数据库可用性、等待队列期间取消、缺失文件/错误密钥、超时、原生解码子进程结束、提交决定边界和 WAL 读取一致性。完整核心 471 项通过。类型、语言绑定检查通过：无未绑定项，既有静态候选仍有 33 条；不代表全应用语言验收完成。

中英界面验证恢复进行中可取消、Esc 取消及迟到结果不影响新对话框；迁移和导出仍保护不可中断的操作。实际 Electron 数据回归覆盖迁移全部资料及服务密钥、DPAPI 自动密码、明文和加密备份、错误密码拒绝、恢复前预览、合并保留新本机资料、重启后的存储位置与到期备份。旧测试入口已调整为当前分类页面和即时保存的设置流程。

正式恢复性能在相同约 41.2 MiB、48 条文字备份上，与固定基线 e04c853 分别对照明文/加密目标历史；每类 5 轮交替运行独立 Node 22 进程。只计算已预览完成后的正式合并，包含解析、校验、保存、索引、同步通知及线程退出，不包含选文件、预览、界面、图片或导出。下表为五轮中位数。

工作线程和备份快照在结束后释放，主进程暂存显著减少；总时长约增加 15% / 20%，峰值基本不变。峰值采样包含进程启动和此前预览；500 ms 及另测的强制 GC 结果不能证明长期驻留或全应用内存已优化。固定报告为 work/current/backup-restore-performance/result.json。

实际开发构建恢复约 41 MiB 加密备份时，40 次状态读取均在恢复未完成时返回，最多 1.8 ms；记录数量保持完整。正式合并窗口的明文/加密取消、旧 JSON 入口、PNG 原件/缩略图、加密目标历史恢复和实际锁定重新解锁回滚均通过。恢复中正常退出 1,025 ms、锁定到解锁窗口 229 ms。具体数字仅适用于本机隔离测试；记录为 work/current/backup-restore-native/result.json。

完整 Windows x64 目录包位于 release/0.49.0/win-unpacked，262 项构建文件与打包内容一致。已从其中的 Clipper.exe 运行同一实际恢复验收：40 次恢复期间状态读取最多 1.7 ms，明文/加密取消、旧 JSON 入口、PNG 原件/缩略图、加密历史恢复和锁定重新解锁回滚均通过；正常退出 329 ms、锁定到解锁窗口 206 ms，页面无异常。上述固定原生报告当前保存此发布包结果。release 按规则保留 0.49.0 与 0.48.1；开发入口已正常重启并加载 0.49.0 的完整构建配置。此次不包含启动故障恢复流程、整体峰值与长期驻留、原生 Emoji 冷字体快速滚动、实体双设备兼容性或所有日常操作的完整验收。按用户要求不继续调查录音录屏性能，持续目标仍未全面完成。
