# 0.50.0 设置与窗口整合验收

2026-10-04。范围来自本轮用户的八项调整，以及最近记录边距、关闭按钮、历史容量提示条和三个工具入口拆分的反馈。

## 交付行为

1. 默认自动记录开启；旧开发资料迁移只执行一次，此后手动暂停保持。
2. 划词菜单及其原生读取进程、窗口、接口、快捷键、构建资源、专用测试全面移除，旧配置删除；AI、脚本及外部请求能力保留。
3. 快速粘贴与托盘最近记录使用同一个 TrayPanel 窗口、查询和预览，移除第二套主界面紧凑渲染及样式。
4. 顶部拖放呼出说明明确按住鼠标左键并经过顶部中央触发区，支持关闭及快捷键。
5. 设置分为常规、交互、维护、数据，共十项；原数据与备份四入口嵌入，保留加密、备份、迁移及恢复操作。
6. 搜索历史与快捷回复并入桌面交互，旧程序版本与升级恢复点统一收纳于恢复与回退；应用更新保持更新职责。
7. 基本设置开机自启动使用普通字重，退出从托盘执行。
8. 所有历史页面移除容量常驻条，容量限制保持；用量在当前存储查看。最近记录预览右边距 12 CSS 像素，关闭按钮右侧与拖放窗口一致为 10 CSS 像素。

9. AI 服务为工具分组首项，文本脚本独立；外部链接改名 URI 放在连接与分享。三页只请求自己的数据并复用操作逻辑，旧引导跳转同步更新。AI/脚本卡片右边缘与标题栏按钮对齐，局域网同步改用网络图标。

## 验证及开发恢复

`tests/window-settings-050.cjs` 使用私有资料及隐藏 Electron，真实数据库、生产主进程、preload、IPC、资源协议加载，十一项通过：侧栏分组/网络图标、AI/脚本/URI 独立内容及右边缘对齐、主界面资源、十项设置、窗口实际复用、两窗按钮边距一致、拖放窗口资源、快捷键自动保存和英语设置。页面异常和失败请求均为零。禁用物理显示/焦点及前台检测，不写系统剪贴板；不将隐藏测试当作真实桌面粘贴验收。

本轮用户发现主界面、最近记录及浮窗异常后，完整重构建并正常启动 dev 恢复了加载；当前资源请求成功，主界面及浮窗可见。未捕获旧进程的确切运行时错误，不能归因于一个未证实的源码故障。构建配置或原生资产改变时应完整重新运行 dev，界面变更继续即时刷新。

隔离窗口测试开发过程中发现隐藏模式的显示保护和刷新条件需要由测试宿主管理，以及分数像素导致精确整数断言不成立；改用实际窗口比较和小于 1 CSS 像素容差。初次夹具选择器和断言失败属于测试设置问题，未作为生产功能证据。

类型检查通过；语言扫描覆盖 2,214 条源码消息，缺失和未绑定均为零。此前的 510 项核心测试及 13 项集合/设置界面检查通过。本轮独立页面和合并表单在中英文、不同窗口与字号条件下分别检查 504 和 420 个布局场景，最终无溢出或运行错误；AI 弹窗中长服务名撑宽表单的问题已修正。两套双语行为检查分别覆盖 AI/脚本/URI 的 10 项和数据/备份等的 11 项。这些行为与布局检查使用模拟接口，未代替外部服务或物理设备验收。

0.50.0 Windows x64 目录包已生成于 `release/0.50.0/win-unpacked`。打包校验确认 258 项构建资源一致；包内 Electron 可加载 SQLite 和原生桥接。隔离隐藏窗口再次从打包资源通过同样的十一项检查，页面异常和失败请求均为零。发布目录保留 0.50.0/0.49.11。dev 在当前代码重新启动并正常加载主界面。开发进程可能另写仅供调试的源码映射文件；目录包校验按发布资源清单核对。
