# v0.10 录屏与录音验收

日期：2026-10-01。当前 Windows 11 x64、Electron 44.5.1、150% 缩放。隔离测试资料；真实剪贴板测试串行执行并恢复原内容。

## 功能与实测

屏幕/窗口 MP4 录像、AAC M4A 录音、系统声音和可选麦克风、暂停/继续、有限时长和容量、停止后本地预览、新文件导出和主动复制文件。录制默认不启用声音，也不自动写历史或共享。浅深主题、紧凑控制和视频预览已检查截图。

真实外部窗口先蓝后红，暂停间隔不计入时长；逐帧解码检查两种画面。实际屏幕捕获得到有效视频尺寸，MP4 有有限时长并可拖动播放。视频和纯音频都检测到由 Windows 实际播放并经 loopback 采集的 437 Hz 测试音，AAC 可解码且非静音。

麦克风采集流程用 659 Hz WAV 虚拟测试设备验证。混合测试使用实际系统 loopback 和受控的 Web Audio 麦克风替身，解码后能检测两种频率；不声称完成真人麦克风硬件验收。测试不会启用真实麦克风或修改系统音量。

权限覆盖未开始的屏幕请求、麦克风、摄像头和跨窗口 IPC 拒绝。默认 session 不能读取录制预览。加密暂存不含原始片段；Range 返回正确区间；保存取消保留预览，已有目标不被覆盖。主动复制文件验证 Windows 文件剪贴板与历史记录，之前不改剪贴板。

生命周期覆盖实际来源窗口关闭后保留可播放预览、取消中的迟到媒体请求清理、会话令牌失效、乱序片段、停止心跳后关闭捕获、未保存预览阻止数据迁移、历史锁定销毁录制、退出保留/放弃确认与暂存清理。心跳丢失使用故障注入，实际等待超时；不是渲染器崩溃或真人休眠实测。低磁盘与小容量上限、密文篡改、创建/导出取消和只清理自有遗留文件由单元测试覆盖。

## 限制与后续

- 录像最长 60 分钟、约 1 GiB；暂停累计导致整个会话超过 2 小时也停止。单段 8 MiB，录制前检查磁盘至少 128 MiB，写入期间检查余量。真实长时间满容量、磁盘故障及低性能硬件未完成验收。
- 默认 30 fps、最长边 1920 像素，可选择 15/60 fps 和 2560；实际帧率与尺寸由设备和捕获来源决定。受保护、最小化或特殊 GPU 窗口可能无法录制。系统声音包含全部播放声音。
- 暂存加密不覆盖系统内存、交换/休眠文件；用户另存媒体为明文；导出中强制终止进程或断电可能在目标目录留下 .Clipper-export-*.part 明文片段。复制后只将文件引用放入历史；移动或删除媒体后该引用失效。
- 需要可用 H.264/AAC 编码器，缺少 Windows 媒体功能时明确报错。当前 Windows 11 通过，Windows 10/N、真人麦克风、物理多屏、睡眠恢复仍待验证。
- 区域录制、长截图、其他媒体导出格式、签名安装与自动更新继续实施；EXE 未签名。此前版本的真人 Hello、物理双机等未完成项继续保留。

重跑：npm run typecheck、npm test、npm run package、node scripts/verify-packaged.mjs；定向：npm run test:recording。
