# 0.49.2 资料页闲置字体缓存回收

肤色选择器直接置于分类栏顶部，距上方工具栏 8 px，不再叠加分类栏顶部留白。两种资料页共用同一布局，保留目录换行、右侧滚动条留白、自适应标签与搜索。

原生 Unicode 字体加载保持 0.49.1 的实现。离开资料页删除专用 FontFace 后，等待 2 秒没有用户输入，再在浏览器空闲回调中检查是否可回收。只有不存在资料页、加载占位或专用 Emoji 字体，且字体资源缓存至少为 8 MiB 时，才调用 Electron webFrame.clearCache 回收闲置资源。实际点击、滚轮、键盘、输入和中文输入法组合事件会重置等待；返回资料页会取消回收，迟到的字体加载完成后重新安排检查。没有循环轮询，不在显示中的资料页主动清空缓存。

回收入口不新增主进程 IPC，也不向页面暴露资源统计或任意缓存操作参数。复用现有字体来源能力，受信任窗口和来源校验保持。缓存有限的字体路径/随机令牌元数据并合并同时申请，避免每次重新打开页面都启动字体查询辅助进程。令牌上限仍为 64；刷新已安装字体会使来源查找失效，刷新前迟到的请求不会覆盖新代结果。

486 项核心回归与 TypeScript 检查通过。真实 Electron 检查覆盖快速离开再返回、资料页显示时不回收、连续输入延后回收、离开后回收、回收时保持图片预览、原图片和文字内容不变、三轮重新加载和肤色选择/复制、字体来源查询只执行一次。系统字体与文件字体外接边界、受限来源、Arial 文件加载以及五种速查主题的阅读和导航继续复测。

webFrame.clearCache 会清理闲置浏览器资源并触发内部回收，不能将采用此 API 后的结果描述为“纯自然回收、没有任何 GC”。没有添加显式 v8/heap 强制 GC 调用，也没有采样全机工作集。退出后缓存的改善不能代表总内存峰值已经下降。按用户要求不继续调查录音录屏性能。

实现参考 Electron 官方 webFrame 文档：https://www.electronjs.org/docs/latest/api/web-frame 。只在重资源页面退出且用户停止操作后使用，遵循其避免盲目清空缓存的说明。

旗帜的原生字形比较只检查字体文件路径是否与本机系统字体一致。本机 Segoe UI Emoji 的区域旗帜仍呈现两字母代码；复制保留原始 Unicode 序列。该比较不能证明本机支持所有彩色国旗。字体支持限制参考 https://bugzilla.mozilla.org/show_bug.cgi?id=1692498#c4 。

发布包 0.49.1 与 0.49.2 各 5 轮交替启动独立进程，资料为空、采集暂停。两版均等待本机 Emoji 文件字体就绪，然后测量 140 帧快速滚动、70 帧再次滚动、12 次受控滚轮输入、搜索和返回记录页后 10 秒驻留。每 250 ms 读取本次应用进程树工作集；中位数如下。

| 指标 | 0.49.1 | 0.49.2 |
| --- | ---: | ---: |
| 首轮滚动 p95 帧间隔 | 20.8 ms | 20.8 ms |
| 首轮最大帧间隔 | 48.6 ms | 34.8 ms |
| 再次滚动 p95 帧间隔 | 20.9 ms | 20.9 ms |
| 每轮最慢滚轮输入至两帧确认 | 127 ms | 123 ms |
| 输入搜索至目标条目出现 | 224 ms | 155 ms |
| 首次打开至条目出现 | 576 ms | 541 ms |
| 首次打开至文件字体就绪 | 660 ms | 639 ms |
| 相对打开前的峰值工作集增量 | 218.4 MiB | 214.5 MiB |
| 返回记录页 10 秒后的工作集增量 | 186.4 MiB | 119.5 MiB |

退出后 10 秒的增量减少约 66.9 MiB；峰值只差约 3.9 MiB，没有足够证据认为峰值问题已改善。两版窗口化 DOM 均最多 187 项。两版各有一轮首轮滚动出现 1 次长任务；再次滚动旧版有两轮各 1 次，新版有一轮 1 次，不能声称无论何时都没有长任务。返回记录页到 10 秒期间，两版所有轮次均没有观测到超过 50 ms 的长任务。滚轮值包含自动化传输和两帧确认，并非真实硬件输入延迟；首次进入的波动不能归因于重复查询缓存，缓存仅用于本次进程内再次申请。10 秒驻留不能替代长期使用与全应用内存验收。

实际发布包回收检查：三次回收后的重新进入至字体就绪分别 468、470、468 ms；字体资源统计每次回收后为 0 字节，当前显示的图片预览仍完整，原图片和文字保持；所有申请只启动一次字体来源查询辅助进程。等待实际输入结束才回收，快速返回资料页不会清理。五个主题原文复制与代码阅读、目录定位、肤色、专用字体注册与清理、150% 文字缩放和受限字体来源均通过发布包复测。
