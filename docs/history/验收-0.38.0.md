# Clipper 0.38.0

交付解压目录：Clipper-0.38.0-win-x64。保留整个目录，先从旧版托盘退出，再运行 Clipper.exe。安装器、签名与公开 GitHub 发布不在本轮交付中。

## 界面

按本机 One 0.16.9 的实际源码逐项核对基础组件及页面骨架，详细对照见《界面组件核对-0.38》与 ONE-UI-REVIEW-0.38.json。

新增统一的 dialog 标题、正文与操作栏骨架，表单和未保存确认共用；样式独立，避免被旧页面规则覆盖。正文使用可收缩的滚动区，长表单保持操作栏可见。关闭后恢复原控件焦点；仅在按下及释放都位于背景时关闭，避免从输入框拖出误关闭。标题作为文字显示，不能插入 HTML。异步保存错误、取消、重复关闭和复用仍保留原会话保护。

分类类型、截图模式与 OCR 语言选择补接入 One 分段组件，去掉旧的独立按钮边框。搜索框继续使用 One filter-field 的单一外层边界与透明内层输入。已有记录、最近记录、拖放、设置、数据、文本、局域网、网页及媒体页面沿用共用骨架，并重新检查；没有把沿用部分表述成重新从零设计。

## 自动记录

超过 32768 字符的正文、格式、图片、附件或路径/名称，将验证、哈希、序列化和 SQL 保存移至独立 worker；普通短文本保留同步快速路径。哈希按验证后 JSON 的相同字节顺序处理，二进制字符串分段更新，保留旧版内容去重标识。准备结果是不可伪造且只能使用一次的内部 token。

Worker 仅连接已经由主进程初始化的当前资料，避免每次记录重新迁移 schema；事务内检查重复与容量。返回正文/文件元信息预览，附件和格式原件留在数据库。完成、失败、取消或超时均等待线程退出，密钥副本清零；没有新的后台常驻线程或明文临时原件。

锁定、系统锁屏、资料切换及退出会取消未提交工作，并等待终止。共享原子标志在提交前定义明确的接受点：接受前可取消并回滚，接受后完成的本地记录不自动撤销；会话失效时不继续入栈、同步、网页发布或广播。重复制仍保留 ID、来源、收藏、标签、共享及仅本机标志。实际 SyncLedger/WebShare 观察者的发布、撤回与隐私行为有回归覆盖。

这条路径只用于自动记录。原始剪贴板提取与 nativeImage 缩略图仍在原路径，手动导入/保存、同步主动发送原件仍可能读取大内容。没有声称整个程序的峰值或驻留内存已降低。

## 实测

独立 Node 进程交替三轮，10 MiB 原始附件，每轮私有明文/加密资料；对照冻结的 0.37.0 源码，运行期间没有本任务其他构建或测试。验证原件与内容哈希相同。

| 项目 | 0.37 | 0.38 |
| --- | --- | --- |
| 主线程最大计时停顿 | 775.69–1309.33 ms | 16.21–17.44 ms |
| 整条记录返回大小 | 13,981,405 B | 433 B |
| 入库完成耗时 | 773.14–1308.92 ms | 719.00–2553.16 ms |

结果确认主线程停顿减少；worker 启动、加密连接和磁盘波动可能增加总完成时间，不据此声称所有保存更快。原始附件为 10 MiB，存储 payload 为 13,981,067 B；返回大小只衡量入库结果，仍有向 worker 传递原始内容的成本。各任务返回后 worker 数为零。测试没有覆盖完整应用 RSS、nativeImage、真实输入或真实剪贴板捕获的总响应。

- 类型检查；370 项逻辑测试，其中新增 13 项捕获验证，覆盖哈希、准备 token、格式/附件、明文/加密、重复制、取消、锁争用、回滚、错误恢复、密钥、超时、实际 poll 入口以及 LAN/Web 自动处理。
- 348 项全页面布局、120 项组件与窗口、16 项搜索、16 项实际 One 基础样式、20 项新 dialog 比对与行为；48 项媒体反馈、47 项异步操作、4 项弹窗生命周期、16 项全文阅读、4 项预览、4 项堆栈界面。
- 151 个双语绑定文件核查；缺失翻译与未绑定消息为零。
- 冻结源码独立依赖构建；包内源代码、资源、辅助程序与产物核对。实际包内 worker/原生依赖运行 13 项新捕获及 8 项堆栈性能逻辑测试，使用隔离宿主检查原有字体、搜索、图片/文本预览、剪贴板格式与传输能力。
- 交付目录逐文件 SHA-256 核对；复制后的实际 EXE 以 Node 模式读出版本；源码 ZIP 解压后逐文件核对。详细结果在交付校验 JSON 和源码 validation 目录。

无头浏览器与隐藏的私有 Electron 宿主验证不等于完整桌面验收；未操作用户键鼠、系统剪贴板、日常资料或日常程序。未测真实两设备与 DWM 像素。未签名，未公开发布。
