# 0.49.5 最近记录闲置窗口释放

对 0.49.4 的隔离长文本资料按操作阶段采样后，发现主进程在搜索结束和关闭最近记录后占用已下降，但隐藏的最近记录界面进程仍占约 143 MiB。样本中主进程工作集从约 173.6 降至 155.5 MiB，整个程序进程树却从打开前 420.3 增至关闭后 10 秒 556.2 MiB。该窗口原先隐藏后保留一分钟，退出页面的清空内容并没有释放整个界面进程。

最近记录窗口改为隐藏后连续闲置 8 秒再销毁。连续唤起继续复用已有界面；再次打开取消旧退休任务，再次关闭重新计时。活跃窗口不会被旧计时器销毁，锁定仍立即销毁窗口。已退休窗口的迟到加载回调不能改变新窗口的加载状态。查询取消、凭据撤销、原内容和搜索规则不变；不调整已验收的资料页间距，不调查录音录屏性能。

同时修复 0.49.4 内部版本号仍为 0.49.3 的遗漏。界面和存储升级恢复点的版本统一从 package.json 获取，避免手工维护两个版本号。首次核心回归因此暴露启动恢复点的版本断言失败，修正后完整 497 项核心检查和 TypeScript 检查通过。新增检查覆盖短时间复用、8 秒后释放、重新计时、活跃窗口保护、旧操作凭据失效、重建后记录保留、迟到加载、锁定与退出清理；原有升级恢复点检查继续核对当前版本。

诊断报告为 work/current/recent-search-memory-0-current/result.json，记录每个阶段的主进程堆、外部内存、Electron 进程类型、窗口身份和进程树工作集。没有强制 GC 或修改进程工作集。该带诊断的单轮搜索计时受采样影响，只用于定位驻留来源，不作搜索速度对照。

## 实际发布包对照

0.49.4 和 0.49.5 各运行五轮明文及三轮加密隔离资料。每轮含 1,500 条约 7,400 万字符的长文本、一个原图片和一个附件，暂停剪贴板追踪；完整 Unicode、来源、标签搜索和精确计数、收藏 500 条、邮件文件分类、默认 80 条摘要、原 PNG 和附件字节、查询取消及快速重开均通过。加密资料确认磁盘不是明文 SQLite，空闲回收后重新加载和查询期间锁定通过，锁定界面出现时间为旧版 234–291 ms、新版 225–253 ms。每个当前版本的实际设置界面显示 v0.49.5，并与 app.getVersion 一致；旧包显示 v0.49.3 的问题保留在记录中。

内存为整个被测进程树的工作集之和，每 250 ms 采样；增量相对于每轮打开前，闲置值为关闭后 10 秒。未强制 GC、修改进程工作集或暂停外部程序，不等同于独占物理内存。

五轮明文闲置增量旧版为 184.8–202.4 MiB、新版为 19.2–23.1 MiB；当前窗口均在闲置后释放，旧版仍保留。当前闲置后的重新打开为 194–300 ms。明文搜索旧版为 597–626 ms、新版为 587–947 ms，本轮没有修改搜索算法，不声称搜索速度提升。

加密新版闲置增量分别为 -6.8、222.9、-32.0 MiB，存在一次明显较高的驻留；峰值中位数也略高。因此不能用中位数宣称加密总内存稳定改善或任务峰值解决。加密搜索旧版为 831–1,624 ms、新版为 847–2,106 ms，少量样本受运行时回收和系统负载影响，不能把中位数下降归因于本次窗口保留时间修改。主窗口请求最慢值为明文新版 4–21 ms、加密新版 5–24 ms，主进程最大时钟间隔均约 17–20 ms；搜索总等待仍有波动。

## 测试干扰与交付范围

原生焦点检查发现 Snipaste 或 Codex 成为前台时，最近记录按既有规则失焦关闭，产生无效测量。失败轮次不计入正式汇总。测试改为核对实际点击命中本次隔离窗口后发送输入，并核对 Windows 原生前台身份；不点击被其他窗口遮挡的位置，不强行显示已关闭面板，不改变产品的失焦保护。加密资料准备结束后等待测量启动信号，让正式测量在一次工具等待内结束，避免工具的中途返回打断前台窗口。只提升本次被测窗口的层级，结束时恢复鼠标位置并关闭本次隔离程序，没有关闭用户的其他应用。

汇总为 work/current/recent-search-idle-summary/result.json，包含全部 16 个有效样本及对应报告路径，断言各轮窗口释放状态、版本、原内容、异常列表和锁定时限。原报告为 recent-search-idle-plain-0…4，以及 recent-search-idle-encrypted-0…2-baseline/current。完整 497 项核心检查、TypeScript 和 2,246 条自有语言字符串检查通过。0.49.5 发布包的 263 项构建文件校验一致，保留 0.49.5 和 0.49.4。开发监听正常重启到当前构建，实际 Electron 主程序在收尾时保持运行。

本轮完成最近记录较短闲置后的界面释放与窗口生命周期保护。快速连续唤起保留；超过 8 秒重新打开需要重建，成本约 0.2–0.3 秒。全应用峰值、长期驻留、加密高驻留轮次的来源、搜索总等待波动及其他日常场景仍未完成，持续目标保持进行中。已处理的肤色选择间距和录音录屏性能不重复处理。
