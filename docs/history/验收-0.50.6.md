# 0.50.6 解锁反馈与资料页验收

2026-10-04。解锁时只在提交按钮内显示旋转标识和“正在解锁”，移除卡片下方重复的加载提示。恢复密钥和 Windows Hello 分别在各自入口显示操作状态。设置中的“取消加密”提供可见入口；验证密码后建立明文资料，保留原加密目录，重启直接进入历史。表情符号页为 Windows 上不能原生显示的地区旗帜提供随包字体字形，显示为彩色旗帜，复制值仍为标准 Unicode。

Windows x64 目录包位于 `release/0.50.6/win-unpacked`。打包检查确认 260 项资源与源码一致，保留 0.50.6/0.50.5。`node tests/packaged-smoke.cjs 0.50.6` 使用隔离、暂停自动记录的资料启动实际程序，验证版本、主窗口、样式和原生组件。包内 `tests/emoji-font-native.cjs` 验证中国和英格兰旗帜呈现、Unicode 复制、肤色选择、字体加载与切页释放；包内 `tests/vault-ui.cjs` 验证真实加密、锁定、恢复、密码轮换、取消加密后历史保留及重启。`tests/unlock-loading.cjs` 验证普通解锁、恢复、Hello 的单处加载反馈，并目视核对截图。类型检查和发布目录保留规则测试通过。

这些检查使用此机的受控测试资料，不代表 Windows Hello 的真实生物识别交互、其他设备的旗帜字体显示或正式公开发布链路已验收。目录包未签名；此前要求收尾的性能及录音录屏性能调查不因此重开。

真实应用补充：`node tests/paste-terminal.cjs` 在独立新开的 Windows Terminal 中运行 Windows PowerShell，使用最近记录把包含中文和 emoji 的测试文本粘贴回终端。源码程序和 0.50.6 包内程序均确认窗口焦点返回、剪贴板原文完整、终端输入逐字一致。测试脚本只关闭自己的终端窗口，并恢复原剪贴板。PowerShell 5.1 默认输入编码在本机把 emoji 读成问号；该测试明确设置终端输入为 UTF-8。结果不代表旧代码页的程序能保留 emoji，也不覆盖管理员终端或其他 shell。
