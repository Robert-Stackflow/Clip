# v0.14 虚拟附件验收

2026-10-01，Windows 11 x64、Electron 44.5.1、150% 缩放。使用隔离资料与受控 OLE 源，真实桌面测试串行；结束后恢复支持的原剪贴板内容。

## 验证范围

真实 IDataObject 提供 Unicode/ANSI 文件组、HGLOBAL、IStream、IStorage；中文、空附件和文件时间经捕获、模板、重启及来源退出后复制保留。复合文档检查正文流、嵌套二进制流和根 CLSID，保存后的字节随历史/备份一致；不将复合容器重建称为源容器逐字节一致。

原名称另存只写新文件，已有目标不覆盖。真实 Windows 鼠标/OLE 拖到独立接收窗口，附件内容逐字节核验。格式与信息提供逐附件操作，浅深色截图核验。

覆盖整组异常拒绝、部分内容失败、错误声明长度、目录/路径/重复名称/设备名称、12 MiB 内容边界、HGLOBAL 分配填充、256 个空附件和 200 个临时组上限。来源排除和禁止历史标记不读取内容。暂停、序列变化和历史锁定中断读取；无响应来源到期后跳过并可继续捕获。

临时文件保留可用修改时间；清理仅在专用生成目录进行，根目录替换和子目录链接不得导致越界删除。外部应用独占临时文件时锁定/启动不失败，释放后重试清理。取消、源记录删除和锁定撤销迟到导出，不残留暂存。密码备份恢复附件和模板；历史加密后锁定清理临时副本，解锁继续采集。文件类共享拒绝。

schema 2 升级保留原记录，schema 5 由实际 0.4.1、0.12、0.13 程序拒绝打开，原数据库哈希不变。

## 限制与后续

尚未验证真实 Outlook/Office/浏览器邮件等应用组合。虚拟文件夹、其他应用私有格式、内部媒体/文档元数据、原始 DIB 色彩上下文继续待做；IStorage 容器布局可能改变。超过容量或无法完成的文件组会跳过。保留源时间/属性描述，不把创建时间或隐藏/只读/系统属性应用到临时文件。

复制/拖出及主动另存产生明文文件；锁定无法强制删除被外部应用占用的文件，运行时重试，退出后遗留在下次启动重试。系统锁屏/休眠流程采用事件模拟，真实系统事件与物理设备仍需单独验收。中英界面、安装/更新、签名、Windows 10、混合 DPI、多屏及长期满容量测试继续按开发计划推进。本版是未签名 x64 目录包。
