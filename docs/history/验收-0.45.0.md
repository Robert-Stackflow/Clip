# 0.45.0 设置与记录页重排

开发与交付均来自 `D:\Repositories\Clipper`。设计对照本地 One 的 settings-view、preferences、controls、segments 和 settings-card。当前控制器与样式继续复用已迁移的 One 组件；未复制完整工作区或依赖。

## 本次行为

- 界面语言并入基本设置，保存语言选择后立即更新主窗口并保留当前设置页。独立图片编辑和录制窗口不会因此被关闭。
- 设置页移除保存按钮。输入暂停 250 ms 后提交，离开输入框立即提交；开关、下拉选择和有效快捷键立即提交。写入顺序执行；基础设置采用最新状态加字段补丁，避免并发覆盖其他设置。无效数字不入库，失败显示错误并恢复对应值。
- 桌面交互分为托盘、边缘呼出、浮动拖放三张卡片；外观、记录与隐私、划词、搜索与快捷回复也按用途分组。
- 类型与来源应用使用同一行的分段组件；宽度不足时使用 One 下拉菜单，带图标及数量，并将已选应用留在分段中。列表、收藏、堆栈、容器和分类可组合过滤，堆栈重复副本保持原槽位。
- 记录卡片重新排版，以背景色显示选中状态，没有左侧边线。预览重排标题、来源和内容，信息与更多操作位于右上角，底部保留复制和粘贴。
- 信息浮层及统一操作菜单支持外部点击关闭、Escape、焦点恢复及菜单键盘导航。图片限制在预览视口内，避免底部裁切。
- 图标来自 Windows 观察到的本地程序路径和 Electron 原生图标读取。路径目录保存在当前数据库的本机元数据中，不随同步或历史备份传播；请求只接受当前历史的来源名称。图标缓存有上限，不可用时显示占位。

## 同批保留的后台优化

局域网发现保留同一设备的多个源地址，优先维持仍在线的地址，过期后切换到可用地址，减少双网卡造成的在线状态抖动。自动测试使用实际私网 multicast、配对、TLS 和附件传输；仅同一台 Windows 内的隔离实例，未验证两台实体电脑。

删除撤销改为压缩的 SQLite 内存快照。加密历史不产生明文临时快照，快照不进入备份，关闭连接即释放；删除、清空和失败回滚保留原始字节、标签和保护规则。

103 条记录（100 × 128 KiB 重复文本与 3 × 4 MiB 确定性高熵附件）的六次交替 Node/SQLite 对照中，撤销保留的 JS 堆增量由约 28.6 MiB 降至约 81 KiB，删除后的 RSS 样本约 133 MiB 降至 117 MiB。清空约 94–99 ms 变为 143–149 ms，撤销约 431–437 ms 变为 524–543 ms。内存收益存在 CPU 权衡；这是合成数据和离散 RSS 样本，不代表真实所有文件或整机峰值。
