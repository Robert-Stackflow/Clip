# 0.50.17 本机 Codex

2026-10-07。移除 `@openai/codex` 及其平台依赖，主安装包不再包含 Codex 原生运行时。

- 自动检测 PATH、npm 全局安装及 Codex 桌面应用附带的程序，直接启动本机原生可执行文件。
- 检查连接与账户接口，遇到无法启动或接口不兼容的程序时尝试其他检测结果；未安装时给出安装或选择程序的提示。
- AI 服务编辑窗口支持选择本机程序和恢复自动检测。授权资料由 Clipper 独立保存，沿用系统代理及只读会话行为。
- Codex 账户卡片统一间距和字号，路径与选择按钮同排，账户操作右对齐。

变更已通过 619 项核心测试、类型检查、构建及语言绑定检查；连接兼容性检查补充后，15 项 Codex 测试再次通过。本机 CLI 和桌面应用的两份 Codex 均通过连接、模型读取和只读会话检查，Electron 代理及中英文窄窗口界面检查通过。dev 中确认检测到本机程序、账户连接正常，验证未发送 AI 生成请求。

交付文件名为 `Clipper-0.50.17-Setup-x64.exe`。发布构建校验版本和全部编译资源，并保留构建一致性报告；这些检查不代表所有 Windows 环境的完整功能验收。
