# 0.50.20 启动与快捷面板设置

2026-10-08。本轮安装器包含启动、应用图标、开机托盘驻留及快捷面板预览设置的源码修改，保留此前 Codex 入口与模型刷新修复。

- 同版本启动改用轻量历史检查，升级、导入和恢复仍进行完整校验；更新服务初始化与资料打开并行。
- 刷新 Windows Store 应用路径，对读取失败的图标有限重试，并保留成功图标的本地缓存。
- 正式版启动时按已保存设置修正开机启动项。开机启动只驻留托盘，解锁和恢复窗口也等手动打开后显示。
- 「设置 → 桌面交互 → 快捷面板」新增「悬浮时展示预览弹窗」，默认开启。切换立即生效并自动保存，关闭时收起已有预览并阻止尚未处理的请求，重启后保留选择。
- 安装包继续不包含 Codex 运行时，使用本机已安装的程序。

632 项核心测试、类型检查、构建、语言绑定检查，以及中文/英文与窄窗口设置布局通过。隔离 Electron 验证预览关闭、恢复、原生边框阴影、边缘布局和重启记忆。启动与图标的验证细节见 [启动与托盘验收](验收-启动与托盘.md)。
