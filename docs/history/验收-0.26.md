# 0.26 程序版本回退验收

当前版本增加配套旧程序和数据格式回退，沿用 One 的分类设置、简洁列表及确认预览。仅支持当前用户安装版；未归档的历史程序不能补出。

296 项逻辑检查通过，包括 8 项回退数据专项和 2 项主窗口 IPC/保护边界。原始表、索引、视图、触发器、生成列、rowid、AUTOINCREMENT 序列、64 位整数、BLOB 与 schema 保留；加密来源保留原密码和恢复密钥，明文转加密不写明文中间库。预览及辅助程序接管前不切换资料指针，失败释放状态并保留当前历史。

12 项生产 C# 辅助程序隔离验证通过：更新成功、失败、摘要不符、退出超时；回退成功和准备/程序/登记/资料指针阶段失败；程序/资料指针阶段进程中断及独立恢复；篡改、未知文件、目录链接、明确删除与三个不同版本保留。登记检查包括嵌套项和多种值类型；原指针含 BOM 时也按原字节恢复。中断后来源或待切换副本改变仍可恢复原程序和资料。

48 组回退页面/操作检查覆盖中英、深浅主题及三种窗口/字号组合。密码与恢复密钥及时清除；校验过程中禁用其他回退操作，提交期间阻止关闭确认框。现有页面 288 组布局通过，隐藏 Electron 检查没有显示窗口或操作系统剪贴板。

全部流程使用独立程序身份、合成历史和私有测试进程，没有操作日常安装、用户历史、系统剪贴板或物理键鼠。首次全量检查受资源竞争影响出现两个启动超时，原测试单独复核与最终 296 项全量检查通过，原失败日志保留。

发布包对应的构建、原生模块和恢复工作线程校验另随交付生成。公开 GitHub Release 联网升级、签名、完整系统断电和干净 Windows 10/11、跨应用及物理设备验收仍待完成。
