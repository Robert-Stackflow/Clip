# 0.46.8 后台保存、PNG 缩略图与图片标注

## 改动

文件共享采用单个短期工作线程，最多四个等待/活动任务。主进程只排记录身份，线程读取锁定文件快照、校验、计算摘要、保存并更新索引；准备完成后进入原串行写入队列，在事务内复核原件身份和仅本机状态。正文、共享标记与目录原子提交，通知只返回身份和隐私字段，避免完整附件回传及重复保存。已接受的提交完成后才退场；接受前的取消回滚。原路径不发送，密钥副本清零。

PNG 缩略图通过原创 C++ WIC 控制台程序生成，避免主进程解码完整大图。输入分块写入，不产生明文暂存文件；一条活动任务、最多四条、64 MiB 编码引用上限、384 MiB 子进程内存上限、15 秒超时。校验 PNG 结构、CRC 和尺寸，解码上限 4,000 万像素；输出最多 280×180、不放大、最多 1 MiB，保留透明度。完成/失败/取消等待进程真正退出，缓存使用弱引用。

图片编辑首位新增指针，可选择本次编辑中绘制的画笔、箭头、文字和形状，移动、修改属性、删除；形状角点和箭头端点可以调整，文字可双击重编辑。裁剪/旋转后的标注仍能命中和调整。实色覆盖合并为形状的实色填充属性。形状使用一个下拉按钮，选择矩形、圆角矩形、椭圆、三角形或菱形后切换图标。编辑历史共享不可变标注，不为每步保留完整 PNG；保存仍输出原尺寸 PNG，已保存 PNG 中的既有像素不能重新分解为可选标注。

录屏来源按屏幕/窗口类别加载，仅录音不再刷新来源；开始录制复核已选来源的窗口进程、可执行文件或显示器配置，复用轻量来源对象，避免再次枚举。选择两分钟后失效，取消/关闭清除对象，不保留原生预览位图。修正仅录音模式的分割线间距。

## 回归

完整核心 **449 项**、类型检查通过，包含新增文件发布四组、原生缩略图三组、标注变换/命中两组和来源生命周期一组。明文/加密实际数据库覆盖附件逐字节、隐私变化回滚、容量与取消、密钥清理、线程退出和既有副本保留权。PNG 覆盖直通透明度、千万/近四千万像素、缓存、损坏/截断/超限、缺失解码器、超时、有界队列及停止等待退出。

生产渲染器在中英文、暗色和小窗口中检查单个形状下拉、五种形状像素、画笔/形状选取移动、大小调整、属性变化、删除撤销重做、旋转后选择、文字重编辑、透明 PNG 及工具栏等高。隔离的实际 Electron 编辑器通过私有 IPC 保存、原图不变、标签/仅本机继承和 PNG 原子导出检查；没有读取或写入系统剪贴板。实际目录包的原生程序、工作线程和运行库另复验，明细进入 `verified-build.json`。这些检查不代表全部桌面界面验收。

## 固定基线性能

文件发布基线为完整 `6059b95`（0.46.7）源码，每轮独立 SQLite、相同锁定 10 MiB 文件，五轮交替运行。范围包括读取、校验、准备、保存、索引和线程退场；不包括网络/UI。下表为系统 Node 22 中位数，包内 Electron/Node 的复验独立归档。

| 文件发布指标 | 基线 | 当前 |
| --- | ---: | ---: |
| 主进程事件循环最大超时 | 655.66 ms | 14.07 ms |
| 全部完成 | 750.15 ms | 389.21 ms |
| 串行写队列占用 | 638.39 ms | 252.52 ms |
| 主进程堆增长 | 93.47 MiB | 0.29 MiB |
| Windows 进程峰值工作集（含线程） | 432.51 MiB | 377.43 MiB |

写事务仍占用串行队列约 250 ms，其他写操作可能等待；主进程响应提升不等于所有操作即时完成。峰值从 Windows PeakWorkingSet64 读取，线程退出后的约 70 MiB 是隔离任务观测，不能证明应用长期驻留改善。

PNG 对照使用实际 Electron 44.5.1 / Node 24.21、相同 8000×4800（3,840 万像素）合成纯色 PNG，五轮交替独立主进程，无窗口。原路径为 nativeImage 完整解码/缩放，当前为 WIC 解码/缩放。

## 连续操作及剩余范围

隔离生产应用使用 800 条自有文字、六组 8 MiB 文件，通过证书固定的同机 TLS 连续同步，另接收两组 4 MiB 附件。发布期间执行最近记录私有 IPC 查询。长截图使用实际主服务与拼接工作线程，但画面由合成选区提供；录屏使用真实自有测试窗口，验证蓝/红画面和暂停/继续。最近记录测试临时关闭失焦自动隐藏，未证明物理焦点行为。

一次完整通过运行的最近记录最大查询为 11.6 ms，长截图暂停/继续为 0.7 ms，录屏点击至状态确认约 23.2 ms。主事件循环仍出现约 0.89 秒停顿，跟踪定位到 Electron 原生来源枚举；减少重复调用并未消除初次枚举的停顿。

应用工作集每 100 ms 采样所有 Electron 进程之和，该次峰值约 1,284 MiB，启动约 535 MiB，任务结束 60 秒后约 809 MiB；采样不保证捕获瞬时峰值，排除独立对端/测试源窗口/PNG 解码器。没有强制 GC，工作线程均退出，主进程堆约 14.76→14.91 MiB、工作集约 165→179 MiB。新增媒体服务进程在录屏后继续驻留，整体占用没有恢复到启动水平；当前只有单版本观测，不能宣称整体长期驻留已改善。

备份/升级恢复仍使用同步缩略图回调，JPEG 等转换、图片编辑完整原图校验及部分原生捕获仍在主进程。真实双物理设备、动态页面/长截图、多屏休眠、长时间重复操作、媒体进程驻留和初次来源枚举继续优化。持续目标保持进行中。

完整可运行目录为 `release/0.46.8/win-unpacked`，移动时保留整个目录；校验记录为 `release/0.46.8/verified-build.json`。没有改网络协议、数据库格式或新增第三方依赖。
