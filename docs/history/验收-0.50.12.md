# 0.50.12 PowerPoint 剪贴板兼容性

2026-10-04。本版将真实 PowerPoint 文本选区归为文字记录，即使剪贴板同时提供 PNG 预览。记录仍保留 Unicode 文本、HTML、RTF、PNG 和 `Art::Text ClipFormat`；关闭来源 PowerPoint 后重新复制，五类内容仍可回放。独立图片形状仍归为图片，关闭来源后 PNG 仍可回放。修正只影响新捕获记录，已有图片分类记录不自动改写。

0.50.12 Windows x64 目录包的 260 项资源与构建一致；隔离资料启动检查通过，主窗口、样式和原生组件正常。包内实际 PowerPoint 测试通过文字与图片来源捕获，以及最近记录向 PowerPoint 的中英混合纯文本、保留粗体/红色/18pt 的富文本、160×96 逐像素一致的图片回贴。富文本结果使用 PowerPoint 默认粘贴方式，未分别强制指定 HTML 和 RTF。

核心逻辑 510 项测试、类型检查和源码版 PowerPoint 文字/图片来源捕获已通过。保留 0.50.12 和 0.50.11 两版目录包。`Clipper.exe` 的 Authenticode 状态为 `NotSigned`；正式联网发布、签名、干净 Windows 系统、Outlook 实际邮件及管理员目标仍未验收。截图、录屏和录音优化按用户要求暂缓。

同版后续补充本机 Office 来源测试：`tests/capture-word-rich.cjs` 在临时 Word 文档中复制加粗、红色、18pt 文本，隔离资料的源码及包内程序均归为文字，保存 Unicode、HTML、RTF，关闭 Word 后仍可回放。`tests/capture-excel-private.cjs` 在临时 Excel 工作簿中复制单元格，发现 `ExcludeClipboardContentFromMonitorProcessing` 标记，隔离资料的源码及包内程序均按隐私规则跳过，历史数量不变。两项采用 COM `Range.Copy()`，临时文档未保存；前台 Excel 手动 Ctrl+C、Word 来源回贴到 Word 的显示结果不包含在此次结论中。
