# 0.21 主入口、同步与原生附件双语

2026-10-01。独立开发记录，完整中英界面、实际 Windows 验收及发布尚未完成。

## 已接入的行为

主入口中的窗口标题、文件选择提示、备份/存储反馈、未保存图片的确认、退出确认及自有操作错误使用本次启动语言。局域网发现、设备身份、配对、共享记录和传输层的自有提示也已接入。新增 114 条英文文案，目录现有 1569 条。

持久化来源名称继续保留原值，包括 AI/脚本处理、截图、OCR、拖入内容、录屏及局域网同步。来源筛选和已有历史依赖这些值；本批不改写它们，不迁移历史。实际主机名、用户保存的设备名、剪贴板正文、HTML/RTF 字节、路径、扩展名、协议字段和权限判断也保持原值。仅没有系统主机名且没有保存配置时的默认显示名称随启动语言生成。

配对设备和附近设备的名称可能在窄窗口中省略，现增加完整名称的悬停提示。提示直接取已渲染的名称文本，HTML 字样保持文字，不参与翻译或执行。

## 同步错误兼容

22 类已识别的自有同步错误使用固定代码，包括配对失效、信任撤销、内容校验、记录格式及共享限制。错误响应保留既有 error 字段和长度限制，新增可选 code。新接收端使用自己的启动语言显示已知代码；旧接收端仍可读取 error。未知代码、旧端返回的错误和外部诊断按原文显示，不通过文本匹配猜测译文。

文字/图片及富文本同步的数据、记录身份、配对码、指纹和协议版本不随语言改变。本批没有新增文件或附件同步，也不提供 OneClip 私有协议互通。

## 原生附件兼容

AttachmentHost 的 23 类自有错误附加固定代码；中文 error 字段继续兼容旧调用方。主程序只翻译已知代码，未知代码和外部错误保持原文。描述符解析、虚拟目录、内容介质、容量、序列校验、释放和超时流程沿用原实现。

原生辅助程序实际编译通过。隔离检查调用实际辅助程序的路径校验和内存读取函数，使用测试自己分配的内存；无效请求在初始化 OLE 前返回错误。测试没有读取系统剪贴板，也没有向实际应用请求附件。
