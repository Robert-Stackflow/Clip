日期：2026-10-01。Windows 11 x64（10.0.26200），当前单屏 150% 缩放，Electron 44.5.1。源码项目 D:\Repositories\Clipper。

## 本版交付

这是阶段 4 的数据管理基础：自定义本机存储迁移、自动备份、到期补做与失败重试、保留数量、可选密码加密、备份校验、预览后合并恢复。保留 v0.1–v0.3 已有功能。新增“数据与备份”页面，沿用 One 的浅深主题。

数据库保持 schema 2。备份升级为 JSON v3 并包含脚本；可选 `.clipper` 密码加密，仍可导入 v1/v2。旧版不支持 v3 备份，也不会读取自定义存储位置配置，不应在迁移后降级。

## 范围与限制

- 这是阶段 4 的第一批交付。局域网同步、历史数据库加密、Windows Hello、启动故障恢复向导仍未完成；备份加密不代表这些功能已实现。
- 当前历史数据库、迁移保留的原副本和 JSON 备份仍是明文。自动密码与 API 密钥使用 DPAPI，不能抵御同一 Windows 用户下的其他程序。
- 备份不包含源文件本体、API/服务配置、本机系统设置和堆栈/容器顺序；迁移完整数据库时会保留这些本机元数据。
- 自动备份仅在应用运行时执行。大数据备份与迁移可能暂时延迟采集，尚未完成满容量持续采集、真实断电、磁盘满或硬件故障测试；代码有失败回滚与恢复演练，不承诺硬件故障下绝不丢失。
- 当前自定义目录需为普通本机空文件夹，网络共享、目录链接和不可用路径不支持。目标不可用时请恢复原连接/路径，专门的启动恢复入口继续开发。
- 仍需多屏混合缩放、Windows 10、干净机器、长期驻留及更多 Office/Explorer/管理员应用兼容验证。
- AI 仍使用隔离协议服务验收，未验证真实模型推理质量或付费服务兼容性。加密格式未经过独立安全审计。

## 使用

1. 数据与备份 → 迁移目录 → 选择空文件夹 → 核对路径 → 开始迁移。
2. 选择备份位置、间隔、保留数量和加密密码 → 保存备份设置 → 立即备份。
3. 手动导出可生成 JSON 或加密 `.clipper`；请另行保管恢复密码。
4. 从文件恢复 / 校验与恢复 → 输入必要密码 → 核对数量 → 合并恢复。只想检查可在预览处取消。
