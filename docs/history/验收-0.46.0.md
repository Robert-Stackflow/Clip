# 0.46.0 集合页面统一优化

开发与构建位置为 `D:\Repositories\Clipper`。参考本地 One 的 `styles.css`、`components.css`、`interface-refinement.css` 中的控件反馈、浮层定位、分段组件和缓动；继续复用已迁移的 One 基础组件。

## 页面行为

- 全部记录、收藏、堆栈、拖拽容器、快捷回复及自定义分类移除底部记录数量栏。列表与预览区域上下对齐，列表填满可用高度。
- 主集合页面只保留纵向列表，移除网格、横向和排列选择；旧配置即使保存过其他视图，也会显示列表。方向键上下导航，搜索框左右移动光标。
- 顶部普通按钮使用统一的悬停、按下与选中背景。预览中的信息、更多、收藏、置顶、编辑、删除图标使用相同前景色。
- 信息与更多操作使用顶层浮层，距触发按钮 6 px；根据剩余空间向上或向下展开并限制在窗口内。进入动画为 180 ms，沿用 One 缓动；减少动画设置直接显示。保留外部点击、Escape 关闭、焦点恢复和操作菜单键盘导航。
- 批量选择工具栏使用浅色背景，无显式外框，进入和退出动画为 200 ms；勾选框位于完整宽度的卡片内部。进入或退出批量模式保留当前预览和全文读取器；操作完成清除实际勾选状态。无选中项时批量操作禁用。
- 无记录的集合使用单个居中空状态，不保留空的预览列；没有来源应用时隐藏应用栏。拖拽容器的额外拖入提示只在拖入文件时覆盖显示。
- 快捷回复使用统一卡片标题、两行内容摘要、类型与修改时间；快捷键在卡片及预览中显示。底部复制和粘贴并排且等宽，沿用实际回复操作。
- 修复列表在批量模式下将按钮替换为包含勾选框的容器时，复用逻辑使用已移除插入位置导致的异常。

## 应用图标查询

图标查询原先为了验证来源应用名称调用完整历史列表，反复将缩略图和摘要解析进 JS 堆。现在使用可重建的来源索引，只读取去重后的来源名称；请求限制和原生观察到的程序路径校验保留。

索引随现有摘要缓存的写入、编辑和删除在同一事务更新；支持旧数据库补建、旧版本写入、撤销与回滚。主记录、备份格式及数据库版本 7 不变，加密数据库的索引随数据库加密。只读旧库使用名称查询，不创建索引。

对照采用 6 个隔离 Node/SQLite 进程，3 轮交替运行；同样的 10,000 条合成记录，包括 5,000 张有效 PNG 图片，每轮 7 次查询。基线为 `97d4ac3` 的实际 AppIcons；候选为本次来源查询实现，测量时尚未升级版本号。固定原生图标返回值隔离来源验证开销，显式 GC 后开始每次查询。

| 查询指标 | 基线各轮中位 | 候选各轮中位 |
| --- | --- | --- |
| 响应时间 | 511.1 / 443.3 / 479.3 ms | 2.55 / 2.40 / 3.22 ms |
| 事件循环定时器延迟 | 511.1 / 443.4 / 479.3 ms | 2.57 / 2.45 / 3.24 ms |
| SQL 方法返回时采样的 JS 堆增量 | 约 328 MiB | 约 45 KiB |

这是指定合成历史下的查询开销，并非整个应用启动、待机内存或连续采样峰值。实际 One 与 Clipper 进程观测中，运行时间、窗口状态、内容和工作负载未控制，不能用于相同工作量的性能排名。
