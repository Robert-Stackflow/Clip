# OneClip 功能对齐与剩余工作

2026-10-01。依据 [OneClip 官方 README](https://github.com/One-Clip/OneClip) 的公开功能说明，以及 Clipper 当前源码、设计和逐版验收记录。公开早期源码与商业版功能说明不是同一实现；本表记录 Windows 等价流程，不宣称协议互通或所有来源格式完全兼容。

| 参考能力 | Windows 当前实现 | 仍需完成或补充证据 |
| --- | --- | --- |
| 剪贴板历史、文本/图片/文件、搜索与管理 | 核心历史、去重、分类、标签、收藏、置顶、编辑与撤销 | 实际 Office、邮件、终端、管理员目标的兼容性矩阵 |
| 全格式及元数据 | HTML/RTF 和常见注册图片格式，文件引用、OLE 附件与虚拟目录（0.18）；按需读取照片/媒体/PDF/Office 内部信息 | 具体来源应用私有格式、真实目录样本及应用兼容性验证；不将“常见格式”视为任意格式保证 |
| 栈粘贴板及按行拆分 | 有序队列与独立下一项热键；0.17 增加本次自动收集、条件筛选、批量预览及反转 | 真实多应用连续输入；当前队列按内容去重，不提供重复副本模式 |
| 快速面板与全局快捷键 | 主窗口、紧凑面板、可改热键、事务式冲突回滚 | 多键盘布局与实体输入法；更多动作独立热键可后续细化 |
| 菜单栏/托盘快捷访问、悬停预览 | 0.19 左键最近 80 项、全文/分类筛选、悬停预览、复制/原窗口粘贴及图片/文件夹拖出；右键控制菜单保留 | 实体多屏、混合缩放、自动隐藏任务栏与不同 Windows 托盘布局 |
| 快捷回复 | 文字/图片/文件/附件、变量、导入导出、独立热键与原窗口填写粘贴 | 真实应用兼容性；本机热键不随模板备份导出 |
| 拖拽容器、顶部拖放架 | 独立浮动架，顶部触发，文件/图片 OLE 拖入拖出 | 自动隐藏任务栏、混合缩放、第三方置顶窗口 |
| OCR、区域/屏幕/窗口截图、长截图 | Windows 本地 OCR、选区、独立窗口捕获、逐屏拼接和图像编辑 | 混合 DPI、复杂动态内容与更多 OCR 语言包；0.16 空窗口图在后续会话复测通过，具体环境原因未确认 |
| 录屏、录音 | 屏幕/窗口/区域，系统声音与麦克风、暂停、预览、导出 | 真人麦克风、多屏、长时满容量、物理休眠与故障存储 |
| 划词、翻译与 AI | Windows 只读选区，主动/自动菜单，本地及在线兼容接口，发送确认 | Word/PDF/终端/多浏览器选区实测及真实模型服务兼容性 |
| JS 脚本及 URL Scheme | 有界独立运行、显式权限预览，白名单动作和确认 | 继续按真实扩展用例验证，不开放未设计的宿主接口 |
| 备份、自定义存储 | 版本化备份、定时备份、密码加密、校验恢复、完整迁移、启动恢复向导 | 长期满容量与故障磁盘演练 |
| 本地隐私与生物识别保护 | 本地数据库/WAL 加密、密码/恢复密钥、Hello 互操作、生命周期锁定 | 真人 PIN/生物识别、真实系统锁定/休眠；硬件参与测试未完成 |
| 局域网同步和网页共享 | Clipper 设备配对、TLS、撤销/冲突，限时网页审批与共享 | 物理双机、路由/防火墙、移动浏览器、人工证书核对；不兼容 OneClip 私有协议 |
| 中英界面 | 当前中文界面 | 文案抽取、语言切换、日期/大小格式与所有窗口双语验收 |
| 视图、主题、边缘停靠 | 浅深主题、列表/三向卡片、四边停靠、悬停触发 | 可配置字体大小尚未实现；物理多屏和自动隐藏任务栏 |
| Finder 剪切移动 | Windows Explorer 原生已有 Ctrl+X/Ctrl+V，文件历史使用复制语义 | 无需替换 Explorer 原生移动行为；跨应用文件复制仍做兼容性验证 |
| 安装及自动更新 | 目前提供可解压运行的 x64 目录包 | 安装/卸载、更新/回退、签名和干净 Windows 10/11 验收 |

后续顺序：真实目录样本及具体私有来源格式 → 字体设置及紧凑布局 → 全窗口中英界面 → 安装、更新和回退。真实设备、实际应用及签名凭据相关项目保持待验收，不以自动化事件或工具占位替代。分发方案可先实现可验证的安装/回退，再接入经用户确定的发布来源与签名身份。

历史文档中的“后续阶段”“尚未实现”是对应版本的记录；当前状态以本表、最新开发计划及实际源码/验收为准。这里的“已实现”只说明功能存在，不替代各版本文档列出的验收限制。

界面复核补充：860×600 的主窗口中堆栈工具栏可用，但详情正文会因底部操作区换行而压缩，需要在后续字体/紧凑布局工作中优化预览区最小可用高度。
