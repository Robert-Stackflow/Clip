## 已修复的问题

- 旧容器仅允许图片/文件；本轮将文字纳入同一套容量、持久化和保留规则。
- 程序调整窗口尺寸没有触发仅面向用户操作的 `resized` 事件；改用 `move`/`resize`，并在迁移、加密、锁定、退出前保存待写位置。
- Windows 在非整数缩放下对原生边框取整，直接反复保存和恢复会产生尺寸漂移；恢复时按实际窗口尺寸纠正，几何验收容许原生边框的两逻辑像素误差。
- 迁移资料收尾时暂停桌面快捷键呼出，避免访问刚关闭的旧数据库；用延迟收尾的集成场景验证。
- 卡片排列的选择框保留原生键盘操作，不触发历史选择或粘贴。
- 将桌面/任务栏窗口排除出全屏应用判定，避免在桌面停留时误阻止呼出。

## 适用边界

- 负坐标、共享边界、任务栏与小工作区用纯几何测试覆盖；真实混合 DPI、多显示器热插拔与自动隐藏任务栏仍需人工验证。
- 顶部入口由左键按住、位置和停留时间触发，不读取全系统 OLE 数据。因此普通按住左键也可能呼出。窗口收到实际拖入后才保存内容。
- 悬停面板在用户点击取得焦点后保留，避免打断搜索；失去焦点后按自动收起设置处理。自动顶部窗口在释放并离开、且未获焦点时收起，手动窗口由用户关闭。
- 仅外部应用/桌面作为自动触发上下文；Clipper 自己获得焦点、截图、录入热键或历史锁定时停止自动呼出。剪贴板中的图片/文件仍可从主窗口加入容器。
- 本机桌面设置和屏幕位置不随 JSON/加密备份导出；完整资料目录迁移和历史加密保留它们。
- 划词菜单、录屏/录音、长截图、签名安装包和更新仍待实现；真人 Hello、物理跨设备和干净机器验收仍待补充。
