## 最新：格式显示与英文侧栏复核

英文侧栏随字号增加空间，导航及暂停恢复提示按完整单词换行；千条记录下的 Favorites、Capturing 和 Resume capture 可读。主窗口/托盘计数、录制大小及记录日期统一使用显示格式工具，原值、时间计算和接口参数不变。

文案绑定检查只接受真实导入且直接传入的文案，区分完整条件键与未翻译的模板参数。110 个 TS 文件及 15 处网页延迟翻译通过；60 处显式日期/数字/ISO/精度调用已分类。250 项逻辑、108 组针对性界面、中英文行为、类型/构建和限定源码审阅通过；本批样式变更后既有 304 组英文工作区、424 组中文布局，以及最终构建的 420 组数据/共享和 448 组文本工具布局也通过。

目录仍为 1569 条，120 个 TS/HTML 文件及两份标签表、1853 处引用无缺失，已盘点候选为 0。完整运行范围及 Windows 验收仍未完成，详见《中英界面-格式与侧栏复核》。以下数字与未完成项为各阶段当时记录。

## 本阶段成果

语言偏好支持简体中文、English 和跟随系统。现有配置缺失时继续使用简体中文，避免升级后突然改变界面。保存只决定下次启动语言，不重载窗口、不退出录制或编辑。启动语言传入各自有窗口与工作线程，解锁和恢复页面也能使用本机语言偏好。

消息支持带变量模板，并校验占位符数量与位置。翻译作用于产品文案；剪贴板正文、来源名称、路径、标签和用户模板保持原样。初始静态 HTML 在填入用户数据之前处理一次，不监听后续内容变化。目录中不存在的文字保留原文，不读取对象原型属性。

数据保护阶段目录达到 1101 条英文文案。此前已接入主要渲染窗口、数据/备份/加密/共享管理、文本工具、托盘菜单及首批后台服务。网页阶段增加网页访客的独立语言和网页服务自有提示。主入口其余错误和其他后台模块仍待接入。

网页默认跟随浏览器，也可即时选择简体中文或 English；语言切换不重载页面、不重新连接、不发送额外内容。只更新初始化时记录的产品模板节点和明确的状态文案，保留表单、选中文字、图片地址、进行中的请求及失败重试编号。偏好保存在当前来源的 localStorage；不同共享端口不共享该偏好，存储被禁止时仍可在当前页面切换。

网页接口增加固定错误代码，原有中文错误字段保持兼容；不同浏览器独立显示已知产品提示，未知或旧服务错误原样显示。主机自有操作错误使用主机语言，网页发送到历史的来源前缀 `网页 · ` 保持原值。内部异常仍返回通用提示，不暴露路径或正文。

脚本工作进程原有独立环境变量列表未包含界面语言，现显式加入本次语言，只传递既有系统和临时目录值及语言，不继承整个父进程环境。工作进程按启动语言生成自有错误，用户脚本抛出的原始错误仍保留。新建资料首次初始化内置脚本时，名称和说明使用当前语言；代码保持一致，已有脚本不迁移或改名。

托盘菜单根据锁定、自动入栈、暂停记录和历史加密状态生成文案；各操作仍调用原有主程序动作。自动入栈在托盘中采用完整的“开始/停止自动加入堆栈”说明，避免直接复用页面短按钮的英文缩写。脚本导入/导出的标题与文件类型显示名已翻译，文件格式和默认扩展名不变。

文本工具只翻译界面与自有校验错误。AI 请求中的输入、目标语言与自定义指令、模型名称、脚本代码及说明、输出结果、外部错误均保留原文。默认目标仍为“简体中文”，与界面语言分开，可由用户修改。历史来源 `AI 处理` / `脚本处理` 是已有存储与接口标识，继续保持；`clipper-win://` 示例中的中文参数也不改写。静态检查为这些值登记了明确保留原因，不使用运行时字符串替换。文本工具页的旧版本徽标已移除。

前批数据与共享页面的日期、时间、容量和计数按当前语言显示。备份文件名与路径、密码和恢复密钥、配对码和邀请链接、指纹、设备和浏览器名称、外部错误保留原值。三个功能页上残留的旧版本徽标已移除，应用版本继续由设置页显示。未修改备份格式、加密协议或共享权限规则。

前批截图复查发现恢复预览的四列统计在 150% 等宽字体下间距过小，已改为两列并增加数字列边界检查。网页阶段仅调整网页样式：标题和状态允许换行，网格列允许收缩，窄屏验证码按可用宽度调整字号与字距。

模板的 `{{日期}}` 和 `{{时间}}` 是已有内置变量名，英文帮助明确解释其用途，不改写模板或重新解释用户变量。元数据字段名称按界面语言显示，标题、作者、文档主题等实际值保持原样；中文字段名“文档主题”与界面的“主题”分开，分别译为 Subject 和 Theme。

内容信息服务与导出对话框的自有文案已接入。格式名称、文件扩展名、原始数据和用户文件名不变；`Unicode 文本` 作为原有非导出格式标识明确保留。消息检查从自有静态标签表读取元数据与格式的显示名称，不把实际元数据值作为待翻译文字。

主界面日期与容量、托盘时间与数字按当前界面语言显示。清除历史后的撤销提示改为显式行为参数；托盘分类失效使用固定 IPC 标记恢复，不再依赖中文错误文案。剪贴板内容不进入这些判断或翻译过程。

英文划词浮条使用更宽的常规尺寸；较窄工作区显示图标并保留提示、无障碍名称和键盘导航。前批已修复大字号英文标题描述挤出顶部按钮的问题，侧栏导航允许换行，最窄浮动窗口保留系统标题按钮空间。容器副标题缩短后，内容预览保持可用高度。
