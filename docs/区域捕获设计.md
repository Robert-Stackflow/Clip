# 区域录制与长截图（v0.11 实施基线）

日期：2026-10-01。参考 OneClip 的区域/屏幕捕获、录制与长截图能力，延续本地 One 的 Segoe UI、Lucide、浅深主题、原生标题栏。已按本方案实现；实测范围与未完成项见《验收-0.11》。

## 共用区域选择

复用冻结屏幕的选区覆盖层；截图保存、录制选区、长截图选区分别显示准确的操作文字。坐标按覆盖层逻辑大小映射到实际截图像素，再归一化；区域绑定显示器及其位置、大小、缩放和旋转。取消不写历史。锁定、休眠、退出、来源断开销毁覆盖层；迟到的捕获和选择不能重新打开旧窗口。

## 区域录制

先在录制页选择屏幕并划定区域，再显式开始。主进程保存选区，仅接受同屏幕会话令牌，不信任页面传来的任意裁剪矩形。获取所选屏幕视频，逐帧裁剪到 Canvas MediaStream；只有区域图像进入 MediaRecorder，不先把整屏写盘。保持原有系统音/麦克风混合、暂停、时长、加密暂存和 MP4 导出。

坐标根据实际媒体尺寸换算，输出偶数尺寸且不放大；最长边仍受 1920/2560 限制。整个屏幕视频轨道存在于本次捕获内存中，选区是编码/保存范围，不是操作系统层面的区域授权。显示器布局或媒体尺寸变化时停止并提示重新选区，不能继续录错位置。取消、迟到流、失败、锁定均释放源视频、Canvas 流和绘制循环。

## 长截图

独立窗口选择显示器和滚动内容区域，主动截取首屏；用户在目标应用向下滚动并追加后续画面。自动识别上一屏与当前屏的重叠，拼接新增底部，显示屏数和合成尺寸。重复画面不追加；无可靠重叠时保留原图并显示上下画面对照，让用户调整重叠行数并确认，禁止猜测后静默丢字。

支持撤销最近一次追加、停止后完整长图预览、另存 PNG、主动保存到历史并复制。截取时暂时隐藏所有 Clipper 窗口；滚动区域应避开固定标题、浮动按钮和滚动条。区域不能跨显示器；显示器配置变化须重新选择。限制单屏 1,200 万/总 2,400 万像素、最长边 16,384、30 屏和 15 分钟，沿用历史 PNG 容量约束；超限保留已完成结果并明确提示。

未保存像素只留本地内存，不写明文临时文件、不自动联网/共享；关闭、锁定、休眠、迁移、退出清理。停止不等于保存；历史提交和文件导出均需用户操作，进行代次校验并保护数据库及已有文件。复杂动态页面的对齐效果不以简单静态夹具代替证明。

## 验收计划

区域录制：真实屏幕夹具包含区域内外不同颜色、变化画面；解码输出确认尺寸、变化与范围，测试声音共存、暂停、取消重选、陈旧令牌、显示器变化、来源结束及加密锁定。几何单测覆盖负坐标与不同缩放，物理多屏另外标记。

长截图：真实滚动窗口分屏捕获并像素对照整篇原图；覆盖自动重叠、重复页、反向/过快滚动、手动对齐、撤销、保存取消/冲突、历史及剪贴板回放、锁定与迟到捕获。发布版回归原有 23 组并增加新模块用例，检查最终归档与受测文件相同。
