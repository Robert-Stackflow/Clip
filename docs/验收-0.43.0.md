# Clipper 0.43.0

运行 Clipper-0.43.0-win-x64/Clipper.exe，保留整个目录，先从旧版托盘退出。新交付在 E 盘，已有版本保留。

这轮逐项核对 One 0.16.15 的实际源码，23 份参考文件固定在 tests/fixtures/one-043，摘要见 ONE-UI-REVIEW-0.43.json。相对上一轮，参考的基础样式与控件没有变化，预览页新增了打开对话框时暂停页面快捷键的判断。该判断迁移到 Clipper 主页面、最近记录、拖放窗口、图片编辑、截图和划词窗口，保留控件本身的键盘操作。

最近记录复用同一记录的行、筛选按钮和预览内容。收藏、置顶、来源与标题等元数据刷新不再清空预览，文字选区、阅读位置、图片元素与键盘焦点保持。分段标签切换保留全部按钮，由 One 的指示器执行状态过渡。正文改变、当前记录消失或查询改变时正确重新读取或清空内容；晚到结果不能覆盖新查询。

托盘查询仍在每次刷新时作废旧操作凭据。新增的 previewKey 是当前会话内的随机内容标识，只用于复用预览，不包含正文哈希，也不能用于复制、粘贴或拖出。复制和拖出读取当前行的新 token。身份缓存只保留当前最多 80 行，内容改变、过滤移出和关闭会话后重新生成；旧凭据的有效期与失效检查保持。新增 4 项实际 Store/TrayHistory 检查覆盖这些边界。

拖放窗口复用记录行、缩略图和按钮。收到新记录时保留正在阅读的行；忙碌按钮更新后仍只执行一次操作，拖出和双击使用最新内容。隐藏或最小化时取消更新、丢弃行与缩略图元素、清空缓存和状态引用。只保存滚动数值、阅读记录的 ID 和相对位置；再次打开重新读取当前资料，并在隐藏期间有新记录到来时仍保持阅读位置。晚到的状态响应不能恢复隐藏内容。连续通知合并到一次更新。

48 项新增交互检查覆盖中英文、明暗主题下的行与控件复用、文本选区、图片、查询切换、操作凭据、忙碌状态、拖出、阅读位置、隐藏、晚到结果、空状态和对话框按键。另有 6 项原生桥接检查使用实际 shelf 预加载桥、AppearanceService、窗口状态控制器和私有 Store，确认预热时不读取内容、隐藏时清空、隐藏期间不读取以及晚到 IPC 响应丢弃。

与 0.42 实际 ASAR 在物理隐藏的原生 Electron 窗口中作三轮交替对照，各 8 项检查。连续五次最近记录元数据变化，旧版预览读取从 1 增至 6，新版保持 1；拖放窗口收到 200 次通知，旧版读取 200 次，新版读取 1 次。140 行窗口预热／显示／隐藏时，旧版行数为 140／140／140，新版为 0／140／0，隐藏后缩略图元素为 0。

资源指标是在双方相同强制回收条件下记录的渲染器样本。新版需要缓存行模板字符串，显示时 JS 堆约 2.13 MiB，旧版约 1.93 MiB；隐藏后新版约 1.89 MiB，旧版约 2.04 MiB。该小样本显示了缓存成本及隐藏后的释放，不证明完整应用内存下降，也不能代表大量图片的解码内存。单次更新时间包含新的 32 ms 通知合并等待，不作为速度通过门槛。

回归包括 391 项逻辑、144 项基础组件与窗口入口、32 项菜单字体、120 项组件页面操作、348 项双语布局、24 项搜索、20 项表单确认、16 项全文阅读、12 项异步操作页面、21 项主页面复用及 4 项动画。打包后再次执行本轮 48 项交互、8 项原生窗口、6 项预加载桥及 4 项凭据检查，并验证实际 ASAR 的既有菜单、预览、公共样式、隐藏释放、字体、加密恢复和 0.27 四项功能。

所有验证使用私有资料、无头浏览器或物理隐藏窗口。桥接测试的显示通知是模拟 IPC，隐藏／最小化通知通过实际窗口控制器发送；没有实际打开窗口、操作用户键鼠、系统剪贴板或日常资料。完整应用驻留内存、真实桌面阴影、跨应用粘贴和两台物理设备同步仍需实际回归。程序未签名，未公开发布。

本轮完成最近记录与拖放窗口更新机制及对话框按键隔离，继续逐项核对其它组件和页面，不宣称所有产品页面已完全等同 One。
