# Clipper 0.31.0

本轮在既有全部页面重构上，再次逐项校对 One 基础组件与布局，并减少隐藏窗口和大附件任务的多余工作。迁移来源、业务适配及各页骨架见 ONE-UI-MIGRATION.md；本次参考仓库为 One 0.16.1，文件摘要见 ONE-UI-REVIEW-0.31.json。

| 项目 | 结果 |
| --- | --- |
| 基础控件 | 实际 One styles.css、components.css、segments.ts 与构建后的 Clipper 控件在 Chromium 中比对，明暗主题 16 项一致；下拉和数值控件保留 Clipper 的数据绑定与动态更新 |
| 页面骨架 | 全部记录、收藏、分类、堆栈、容器、回复共用列表栏、内容画布与操作栏；设置、备份、文本工具共用分类导航和分组卡片；最近记录、拖放、媒体编辑及其他辅助窗口重新验证 |
| 搜索与反馈 | One 单层 filter-field，无内部输入边框；分段、tooltip、toast 和滚动条共用组件；保留键盘和减少动态效果支持 |
| 隐藏窗口 | 隐藏和最小化期间合并列表变更，恢复时刷新一次；独立工具窗口仍即时接收通知；关闭或隐藏时取消该窗口搜索 |
| 追踪任务 | 桌面边缘和自动划词关闭时停止定时器；禁用自动划词时，快捷键读取仍临时保留必要轮询与过期取消 |
| 原始格式与附件 | Base64 严格校验保持原有规范，无整份解码副本；保存文件每块最多解码 192 KiB，写后清零；继续使用临时文件、刷新、验证、提交及失败清理 |
| 长内容操作验证 | 数据库只查询哈希列，避免每个写入块重新解析整条记录；编辑、删除、存储切换和锁定仍取消旧操作 |

315 项逻辑测试通过，类型检查通过，语言检查覆盖 140 文件、未绑定项为零。重新执行 348 项布局、120 项界面、16 项 One 基础控件、16 项搜索、48 项媒体、144 项反馈、40 项隐藏 Electron 滚动条和四组动态效果检查。原生沙箱确认、实际字体服务及打包后加密恢复、文件同步、Rust 文档解析、重复堆栈和加密搜索另见交付验证报告。

隐藏 Electron 测试使用真实生产预加载、构建界面和私有 501 条 Store 数据。50 次变更期间，旧版发送 50 次通知并触发 41 次状态、41 次详情查询；新版隐藏期间三者为零。模拟恢复时三者各一次，最新记录正确显示。原生窗口一直保持隐藏，显示/恢复状态为模型模拟；这不是物理桌面验收或全应用驻留测量。

私有生成的 10 MiB 应用原始格式中，七次测试的格式信息中位值从约 3.39 ms 降至 0.03 ms，格式校验从约 23.44 ms 降至 9.26 ms；哈希检查从约 33.46 ms 降至 0.056 ms。等待另存为时，旧版提前分配 10 MiB 解码数据，新版为零；实际写入最大单块为 192 KiB。一次导出样本约 687→156 ms，输出字节一致；不能据此推断所有机器和所有格式的持续延迟。取消测试保留原目标并清除临时文件。这里测量解码 Buffer 分配，不代表整份字符串、全应用内存或峰值。

追踪测试使用实际控制器、真实 Node 定时器和模拟本机接口，持续 1.25 秒。关闭相关功能后，定时器由二个变为零，鼠标、按键、光标查询由各 16 次变为零；保留两个初始化设置读取。启停、自动划词、快捷键临时读取、阻止和销毁均验证。计数证明调度行为，不是实际 OS CPU 测量。

只读观察现有 One 十个进程，两个快照的工作集总和约 66 MiB、私有提交约 438 MiB；现有 Clipper 七个进程约 45 MiB、381 MiB。没有控制负载、窗口状态或运行版本，工作集包含共享页，不能将这些快照用作两个产品的性能对比，也不能代表本次构建的驻留消耗。

没有重新使用系统剪贴板、物理键鼠、双设备、硬件录制或干净系统进行验证。原生 DWM 外框效果未在本轮重新核对。软件没有签名或公开发布。运行完整目录里的 Clipper.exe，移动时保留整个目录；先从旧版托盘退出。原始项目及先前交付保持原样。
