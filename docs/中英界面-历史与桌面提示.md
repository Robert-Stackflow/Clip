# 0.21 历史与桌面提示双语

2026-10-01。独立开发记录，完整中英双语、实际 Windows 验收和新版本发布尚未完成。

## 功能行为

历史管理、模板与堆栈、附件读取与临时文件、文件复制和拖出、托盘、桌面浮窗、快捷键、划词读取及共用参数校验的自有提示使用本次启动语言。32 个后台/共用文件接入显式翻译调用；语言选择页面也加入静态覆盖范围。来源进程名、文件名、实际剪贴板格式名称和用户内容保持原值。

新捕获的图片、纯富文本、文件及附件记录按当前界面语言生成默认标题。已有记录不会因重启或重复捕获而重命名。备份恢复与撤销删除保留已有标题和预览；备份缺失这些字段或字段类型、长度异常时，沿用根据实际内容重新生成标签的行为。保存标题最长接受 33,000 字符，覆盖原来由 Windows 文件路径生成的标题；预览保持原有 240 字符上限。数据库版本和备份格式不变。

用户模板的 `{{日期}}`、`{{时间}}` 继续使用原变量名及格式。堆栈按行拆分的已有历史来源标识保持原值，避免影响用户按来源建立的分类和筛选。元数据/剪贴板格式的静态标签表保持原始键值，由显示层翻译；实际元数据值不翻译。

Windows 边界仅翻译 Clipper 自有错误和窗口/对话框显示名。原始格式注册名称、文件剪贴板 UTF-16 内容、粘贴按键顺序、选区状态码、令牌和权限检查不变。原生辅助程序返回的外部错误继续原样显示，其完整双语改造不在本批完成范围内。

## 界面修复

首次主窗口/托盘长路径检查出现 32 组横向溢出。提示区现支持长词换行，并限制显示高度，完整文字在提示区内滚动。聚焦提示后可用键盘阅读，阅读期间不执行历史导航、粘贴或删除快捷操作；鼠标悬停或键盘聚焦时暂停自动收起，离开后恢复原有收起时间。提示仍保留全部路径文字。

## 验证范围

测试使用隔离的内存或临时数据库、合成文件和无界面浏览器。原生窗口、剪贴板、Win32、附件辅助进程使用模拟接口，没有操作系统键鼠或真实剪贴板。

新增逻辑检查覆盖跨语言重启/恢复/撤销、重复捕获、旧备份兼容、模板变量、事务回滚、外部错误原样传递、快捷键回滚、堆栈令牌、托盘能力令牌、附件内容和目录取消、外观设置恢复，以及原生边界的窗口限制和原始字节。

主窗口/托盘检查直接使用实际 Store 输出与构建后的页面，覆盖中英文、新建/跨语言恢复、浅深主题及 100%/150% 字号。另验证长提示可键盘滚动、聚焦保留、离焦收起且不误触复制。时间推进只控制浏览器测试时钟，不改变系统时间。

整套逻辑测试曾出现划词测试辅助进程在 600 毫秒内未启动的超时。测试入口限制最多 4 个测试文件并发，保留原测试超时、生产超时和功能断言。模拟接口的首轮语法与浏览器全局对象缺失也已修正。最终通过结果以本批日志为准。

最终结果：227 项逻辑、32 组主窗口/托盘界面组合检查，以及既有工作区的两种语言行为回归通过；类型检查、构建、32 个后台源码范围审阅和静态文案检查通过。目录 1287 条、97 个文件及两份标签表、1498 处引用无缺失，剩余 271 条候选需审阅。最终英文新记录和跨语言恢复的截图已复核。

## 后续
