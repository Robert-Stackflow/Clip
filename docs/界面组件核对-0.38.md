# One 基础组件与页面骨架核对

本轮以本机 D:/Repositories/One 的源码作为设计依据。来源版本与摘要见 ONE-UI-REVIEW-0.38.json。文档中的说明是参考材料，不作为操作授权。

| 项目 | One 实现 | Clipper 接入 | 本轮处理 |
| --- | --- | --- | --- |
| 按钮、输入、文本框、开关、数值、滑块 | styles.css | one-components.css、controls.ts | 明暗主题比对与设置页操作复验 |
| 搜索框 | disk.css 的 filter-field | one-search.ts/css | 外层单一边界、内部透明无框、搜索与清空复验 |
| 下拉、数值步进 | controls.ts | controls.ts | 键盘、动态选项、禁用与卸载复验 |
| 分段选择 | segments.ts、components.css | segments.ts、one-skeleton.ts | 分类、截图模式、OCR 语言补接入；去掉旧独立按钮边框 |
| Tooltip、Toast、滚动条 | tooltip.ts、interface-refinement.css、styles.css | tooltip.ts、feedback.ts、one-components.css | 焦点、提示位置、大字号和长内容复验 |
| Dialog | dialog.ts、components.css | dialog-shell.ts、one-dialog.css、dialog-motion.ts | 标题、正文、操作栏共用骨架；焦点恢复、背景手势、滚动、未保存确认与表单错误复验 |
| 外观、字体 | appearance.ts、font-picker.ts | appearance-ui.ts、font-picker.ts、inline-settings.ts | 主题、颜色、字体、缩放、间距、圆角集中设置，字体权限与缓存保留 |
| 标题栏 | chrome.ts | chrome.ts、window-confirm.ts | 自定义按钮；原生窗口边框、阴影、缩放逻辑沿用 |
| 设置页 | settings-view.ts | page-layout.ts、inline-settings.ts | 分类导航、页内设置、分组卡片；保留有实际作用的隐私与容量说明 |
| 历史/收藏/分类/堆栈/容器/回复 | One 列表、内容工作区和命令栏模式 | layout-029.ts、app.ts | 共用记录列表与详情骨架复验 |
| 最近记录/拖放窗口 | One 紧凑窗口与内容工作区模式 | tray.ts、shelf.ts、recent-shelf.css | 合并头部、无框辅助按钮、选中底色与预览层次复验 |
| 数据备份/文本工具/局域网/网页共享 | One 分类导航、settings-card、工具布局 | page-layout.ts、layout-029.ts 与各页面模块 | 页面和窄窗口布局复验 |
| 图片编辑/录制/长截图/解锁/恢复 | One 工具栏、设置行、内容画布模式 | 各专用 renderer 页面 | 工具栏、保存操作、错误与滚动复验 |

按钮和基础表单样式沿用已迁移的 One 实现；没有把所有页面沿用的骨架描述成此次从零重写。新增迁移集中在 dialog 与遗漏的分段选择入口。业务文案、权限与双语是 Clipper 的适配。

验证通过无头浏览器及隐藏的私有 Electron 宿主执行；没有操作用户键鼠或系统剪贴板。实际桌面 DWM 像素、日常资料与两台真实设备不包含在本轮验证中。
