# Clipper 0.5 局域网同步验收

日期：2026-10-01。Windows 11 x64（10.0.26200）、150% 缩放、Electron 44.5.1。发布目录 release\0.5.0\win-unpacked。

## 本版内容

局域网设备发现、一次性配对码、双端确认、TLS 1.3、双向证书指纹固定、设备撤销、文字/富文本/PNG 双向同步、主动选择旧记录与可选自动同步新复制内容。接收内容只加入历史；私密内容可设为仅本机。

使用 Clipper 独立协议，不声称与 OneClip 商业版互通。数据库升级至 **schema 3**，避免不了解共享保留规则的旧版误清理记录；旧 schema 1/2 可升级，升级后不要降级直接打开。历史备份仍为 v3，既有备份兼容导入，备份不含设备私钥、信任关系或同步目录。

## 使用和兼容性限制

- 双端同步已在同一机器的隔离实例完成验证，不能据此声称两台物理电脑、所有防火墙、路由器、VPN、休眠恢复或多网卡场景均已验收。发现受网络多播规则影响，配对可选本机地址；不自动修改防火墙。
- IPv4 私网与链路本地地址，最多 8 台配对设备，不使用云中继。非兼容协议、网页实时分享、IPv6 和实际跨平台客户端仍未实现。
- 目录上限 20,000 条发布及删除标记；删除标记不会随时间回收。显式重建同步身份/目录的维护流程仍待实现，达到上限时停止新增共享并保留本机历史。
- 本机历史依旧明文；TLS 和 DPAPI 不等于历史数据库加密。Windows Hello、数据库加密、网页分享、录制、系统增强、签名和升级机制继续按计划推进。
- 独立安全审计、满容量长期网络同步、磁盘故障/断电和复杂网络故障尚未完成。AI 回归仍使用隔离协议服务，不代表真实模型质量。
