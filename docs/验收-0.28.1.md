# Clipper 0.28.1

本版修复 0.28 通知组件的实际问题，保留最近记录和拖放窗口的简洁布局。

修复前的生产页面检查显示：最近记录通知 position:static，矩形位于窗口外，文字与底色都是 rgb(32,32,32)；拖放窗口通知同样参与正文布局。

现在通知使用固定定位和手动 popover 顶层，在六种位置保持窗口内可见；正文与背景使用相反主题色。主窗口通知、模态窗口上方反馈、最近记录与拖放通知使用同一定位规则。长诊断可滚动，键盘方向键/Home/End 不触发历史导航，悬停或焦点阅读时暂停消失。

验收结果在源码 validation 和交付校验中保存；只有必要检查通过才交付。测试使用隔离数据、无头/隐藏窗口与模拟业务接口，没有操作真实键鼠、系统剪贴板或日常历史。双机、真实应用粘贴、DWM 阴影像素、干净系统与签名仍待验证。

按用户截图反馈移除最近记录底部操作说明；全局滚动条改为 8px 槽位、4px 可见滑块、无箭头、透明轨道、圆角及悬停/焦点增强。移除局部 scrollbar-width:thin，以免原生滚动条规则覆盖圆角样式。
