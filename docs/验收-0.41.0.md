# Clipper 0.41.0

运行 Clipper-0.41.0-win-x64/Clipper.exe，保留整个程序目录。先从旧版托盘退出。本轮新输出放在 E 盘，已有交付版本保留。

下拉菜单、字体选择器再次依据本地 One 0.16.13 的实际源码调整。option-list.ts 逐字迁移；控制器接入其 enabledOption、focusOption、revealOption。参考文件已固定在 tests/fixtures/one-041，摘要在 ONE-UI-REVIEW-0.41.json，后续 One 的独立变化不会影响这轮对照。

普通下拉菜单的方向键、Home/End 和文字匹配跳过禁用项；禁用行不接受鼠标焦点或选择。空列表显示 One 的简洁状态行，全禁用列表不设置无效活动项。更改选项、禁用或移除原表单时，弹出菜单正确关闭。保留原 select 的 value、options 和 change 接口，使既有设置保存逻辑继续生效。

字体列表使用 One 的前后两行焦点更新；不再遍历整个列表切换焦点。字体列表的定位规则也逐字迁移，选项以列表自身计算位置；键盘滚动完整显示活动行，不带动设置页。连续预览合并到动画帧；关闭菜单取消待执行帧和延迟任务，晚到字体结果不会重新打开菜单。搜索、未安装字体提示和显式系统字体加载保留。

新增 32 项实际渲染交互对照，使用当前 Clipper、固定的 One 原控制器和 0.40 实际 ASAR。2400 个字体、连续 200 次指针移动时，样式写入从每次 200 次降到 1 次；旧版约 81 ms，新版及 One 对照约 1 ms。时间是同一无头环境的诊断样本，按版本分组测量，未作为通过门槛，不能推断完整应用速度或内存。

验证包括 384 项逻辑、144 项基础组件状态对照、120 项页面与组件操作、348 项双语布局、24 项跨页面搜索、20 项表单与确认及 4 项动画。打包后再次使用实际 ASAR 验证菜单、字体、十个页面公共样式、全文和图片预览、窗口资源释放、原生字体、加密恢复及四项 0.27 功能。

所有验证使用私有测试资料、无头浏览器或物理隐藏窗口。本轮未使用用户键鼠、系统剪贴板或日常资料；真实桌面原生阴影、外部应用粘贴、两台物理设备和完整应用驻留内存仍需实际回归。程序未签名，未公开发布。

本轮完成上述共用组件的当前差异迁移，继续逐项核对其它页面，不宣称所有产品页面已完全等同 One。
