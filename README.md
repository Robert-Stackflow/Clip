## 运行

自定义安装器的上一版为 `Clipper-0.27.0-Setup-x64.exe`，点击「安装 Clipper」。安装在 `%LOCALAPPDATA%\Programs\Clipper`，可从开始菜单打开；卸载在 Windows「设置 → 应用」中进行。安装器使用 .NET Framework 4.8，支持 Windows 10/11 x64，不需要联网下载应用文件。安装器语言独立于已有应用语言设置，不会改写你的设置。

目录包也可解压后双击 `Clipper.exe`，保留全部配套文件。本轮打包目录为 `release\0.43.0\win-unpacked`。窗口关闭后驻留托盘，通过托盘退出；使用新版前先从旧版托盘退出。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+V | 打开主窗口 |
| Ctrl+Alt+V | 快速粘贴面板 |
| Ctrl+Alt+N | 粘贴堆栈下一项 |
| Ctrl+Shift+R | 打开快捷回复 |
| Ctrl+Shift+D | 浮动拖放窗口 |
| Ctrl+Alt+X | 读取外部应用选中文字并打开划词菜单 |
| Ctrl+F | 搜索 |
| ↑ / ↓ | 选择历史记录 |
| Enter / 双击 | 粘贴回原应用 |

全局快捷键可在设置中录入；与其他程序冲突时会报错并保留原设置。不占用 Windows 的 Win+V 和普通 Ctrl+V。

## 当前功能

- 文本、链接、代码、PNG 图片、Windows 文件路径与虚拟附件的自动记录；文字的 HTML/RTF 原始数据一起保留，另支持常见图片原始格式。启发式识别链接/代码，富文本按纯文本预览。
- 全文搜索、类型筛选、列表/卡片视图、内容详情、收藏、置顶、标签、文字编辑、删除撤销。
- 主窗口、紧凑粘贴面板、托盘、快捷键、恢复原应用焦点后粘贴。
- 堆栈入队、移除、上下排序、按行拆分、逐条粘贴；文件缺失或注入失败不会消耗队列。
- 文字、图片、文件快捷回复；{{姓名}} 等填写项和 {{日期}} / {{时间}} 自动变量，使用前预览。
- 自定义分类按类型、正文、来源、标签组合筛选；批量收藏、添加标签、入栈、删除与撤销。
- 拖拽容器与独立浮窗，文字/图片/文件共用；文件/图片原生拖出，图片另存为 PNG。
- 快速面板四边停靠、可选悬停呼出、显示器和停留时间；纵向、横向、网格卡片。
- Windows 本地 OCR，选择已安装语言、取消识别、编辑结果后保存文字。
- 选择显示器进行整屏或区域截图；冻结画面、鼠标选区、Enter 确认、Esc 取消。
- 暂停记录、进程排除、Windows 禁止历史标记、自动保留策略、开机启动开关。
- SQLite 持久化；手动导出/导入带版本的 JSON 备份。合并去重，不覆盖本机设置，导入失败整体回滚。
- 浅色、深色和跟随系统；Windows 原生标题栏按钮、Lucide 图标。
- AI 文字翻译、总结、改写、自定义指令；Ollama、LM Studio 和在线兼容接口，模型列表、结果预览、取消与超时。
- JavaScript 文本脚本、代码及权限预览、独立运行、导入导出；预置空白清理、按行去重、JSON 格式化。
- 可选 `clipper-win://` URL 入口；外部新增/复制文字先在应用中确认。
- 自定义数据目录迁移、完整副本校验、原目录保留与重启定位。
- 自动备份、保留数量、到期补做、失败重试；可选密码加密，恢复前校验和预览。
- Clipper 设备配对、局域网文字/图片同步、撤销信任与离线编辑冲突保留。
- 限时 HTTPS 网页共享、浏览器审批、文字/图片实时查看，以及单独授权的浏览器发送。

自动粘贴以 Windows 接受按键注入为完成依据，无法确认任意目标应用实际插入了内容。输入法正在组字或同时操作键鼠时可能影响结果；原始内容仍保留在历史中，可重新加入堆栈或手动粘贴。

## v0.19 托盘最近记录

左键点击系统托盘中的 Clipper 图标，显示最近 80 项；右键仍打开暂停、主窗口和退出等菜单。面板支持正文、来源、标签、文件名搜索，以及类型、收藏和自定义分类筛选。鼠标悬停或方向键查看正文、原图或已保存的文件夹层级。

面板内左键单击或 Enter 复制；右键单击或 Ctrl+Enter 粘贴到打开面板前的应用。也可使用底部按钮。图片、文件及已保存的文件夹可直接拖出。这里的 Enter 行为与主窗口不同，底部文字会提示。Esc、切换窗口、锁定或休眠会关闭面板。托盘图标悬停不会自动显示历史内容。

搜索范围涵盖全部历史，但列表最多显示最新 80 项；文字预览最多 32,768 字，复制保留完整内容。文件引用仅展示路径；预览不会读取原磁盘文件或生成附件缓存。目标窗口已关闭时可复制后手动粘贴。实际目标应用仍需支持所选格式。

## v0.18 虚拟文件夹

来源应用通过 OLE 提供目录及成员时，Clipper 保存完整的已枚举层级、空目录和文件内容。来源退出后仍可搜索相对路径、加入堆栈/拖拽容器或保存为模板。复制、粘贴及拖出只提供顶层文件与文件夹；目标应用可读取其中的全部已保存成员。

在“格式与信息”里点击“另存文件夹”，选择一个新的目录名称，保存该目录及全部子项。已有目标不会合并或覆盖；内部信息只允许选择文件。父目录未单独列出时，会根据已枚举的子项补建；不会主动扫描来源磁盘，也不能补出来源未提供的内容。

每组最多 256 个节点（含目录和补建父目录）、16 层、相对路径 259 个 UTF-16 单元，内容合计 12 MiB；历史原有容量限制继续生效。无效路径、重名、文件充当父目录、链接/设备属性、超限或读取失败会整组跳过。临时树在锁定/退出时清理，占用文件释放后重试。另存结果由用户管理。

数据库/备份升级至版本 6，0.17 及更旧版本拒绝打开新库；旧备份继续导入。首次升级前建议用旧版保留备份。文字/图片同步仍为版本 4，文件与目录不参与同步或网页共享。修复了未加密历史休眠恢复后，旧另存窗口仍能提交的问题。

已经验证受控真实 OLE 数据源和本机浏览器目录接收；Outlook、Office、资源管理器等实际来源/目标应用的兼容性仍需逐项验证。

## v0.17 堆栈规则

本次自动入栈可按类型、来源进程和包含词筛选，支持按行拆分、批量预览确认和队列反转。暂停、停止、锁定、休眠或退出结束收集；派生内容保持仅本机设置。详见 [堆栈规则设计](docs/堆栈规则设计.md)。

## v0.16 搜索历史与模板快捷键

搜索框旁的“搜索历史”可开启最近搜索记录，默认关闭。离开搜索框或使用结果时保存完整词条，最多 20 条、每条最多 512 字，去掉首尾空白并忽略大小写去重。选择词条后沿用当前页面与筛选；可以逐条删除、清空，关闭记录会清空。历史窗口里的操作立即保存。搜索词只存本机数据库，随数据库加密和完整迁移，不进入普通备份或设备同步。

Ctrl+Shift+R 或托盘“快捷回复”打开回复页。在“搜索与快捷回复”设置中可以改键或停用；编辑模板时可设置独立快捷键，最多 100 个。组合必须包含两个不同修饰键与字母、数字或 F 键；点击输入框录入，Delete 清除，Esc 取消录入。冲突会报错并保留原模板与按键；启动时被占用的键单独停用，其他键继续工作。释放占用后重新保存设置或重启即可重新注册。

在目标应用按模板热键：普通文字、图片、文件和已保存附件直接粘贴；包含填写项的模板先显示输入和预览，确认后返回最初的目标窗口。日期/时间变量在执行时替换。模板被修改或删除、目标窗口失效、取消、锁定、休眠或迁移会阻止旧预览继续执行；填写操作最长有效 10 分钟。目标应用拒绝自动粘贴时会明确提示。

同时修复选定录制区域时，迟到的来源刷新清空已选屏幕、导致再次启动录制失败的问题。

热键绑定是本机设置，不随模板备份或同步导入；完整数据目录迁移会保留。数据库/备份仍为 5，同步仍为 4。详见《效率功能设计》《验收-0.16》。

## v0.15 内部信息

打开记录的“格式与信息”，切换到“内部信息”，选择保存的原图、已保存附件或本机文件，再点击“读取内部信息”。可以查看照片参数、音视频时长与标签、PDF 页数及属性、DOCX/XLSX/PPTX 文档属性。切换对象、页签或关闭窗口会取消未完成读取。

照片位置默认不读取；勾选“包含照片位置信息”后重新读取才显示。属性只在当前窗口展示，不写入历史、备份或同步，也不改写原始内容。本机文件展示读取时的信息，保存的图片和附件展示历史中的内容。没有提供的字段不会推测；WebP/GIF/BMP 当前只显示格式与尺寸，EXIF 读取以 JPEG/TIFF/PNG 等支持的容器为限。

图片和文档最多 64 MiB，媒体最多 2 GiB，每次最多读取 15 秒；保存内容仍受历史原有容量限制。超时或解析失败可取消后重试，不阻塞剪贴板记录。本机读取仅支持本地盘上的普通文件，读取期间暂时阻止其他程序改写该文件。加密 PDF、加密 Office、旧版 DOC/XLS/PPT、私有标签及全部媒体格式暂未覆盖。

此功能不改变数据库、备份及同步版本：仍为 schema/备份 5、同步 4。详见《内部信息设计》《验收-0.15》。

## v0.14 虚拟附件

复制邮件等应用提供的虚拟文件后，Clipper 保存附件内容，不再依赖来源程序保持打开。在“文件”筛选中查看已保存附件，搜索文件名、加入收藏/堆栈/拖拽容器，或保存为快捷回复。“格式与信息”显示名称、大小及源时间，可逐个另存新文件。复制、粘贴及拖出提供普通 Windows 文件，保留名称和修改时间。

支持 Unicode/ANSI 文件描述以及 HGLOBAL、IStream、IStorage 内容；复合文档保留流、嵌套存储和类标识，生成的容器字节布局可能改变。最多 256 个普通附件、原始字节合计 12 MiB，同时受单条 16 MiB 和总历史 256 MiB 限制。0.14 仅处理平面附件；虚拟文件夹现已在 0.18 支持。来源超时、内容不完整、名称无效或超限时整组跳过；不会保存部分附件。暂停记录、进程排除和禁止历史标记继续有效。

附件内容随历史加密、快捷回复及密码备份保存。复制/拖出会生成未加密临时文件，限制 256 MiB、200 组；锁定或退出时清理，被其他程序占用的文件在释放后重试，强制退出的残留在下次启动清理。主动另存的文件由用户管理。文件路径和虚拟附件不参与局域网同步或网页共享。

0.14 的数据库和备份版本为 5，0.13 及更旧程序拒绝打开该版本的新库；旧备份仍可导入。文字/图片同步协议继续使用版本 4。已验证受控真实 OLE 数据源、来源退出后的复制与拖出；Outlook 等实际应用及全部私有格式仍需逐项验证；目录支持见 v0.18。详见《虚拟附件设计》《验收-0.14》。

## v0.13 格式保真与内容信息

在记录详情点击“格式与信息”，查看保存的格式、字节量、图片尺寸及 HTML 来源。PNG 保留原始编码；JFIF/JPEG、GIF、TIFF、WebP、BMP 注册格式与 HTML/RTF 原始字节分别保留。复制时同时提供原格式和可生成的兼容表示；“复制纯文本”仅写文字。没有可用解码器的图片仍可复制和另存，界面提示无预览。是否使用原格式取决于目标应用。

“另存”输出所选格式的新文件，不覆盖已有文件；HTML 上下文保存为 .cfhtml。单张 JPEG/GIF/WebP/BMP 文件拖入后保留原始编码，拖出时优先使用原格式，PNG 文件不重编码；GIF 动画字节保留，界面与编辑只使用静态预览。图片编辑另建 PNG 结果，原图保留。原始格式可随快捷回复、备份、加密恢复与新版设备同步；网页共享只发送文字与重新生成的 PNG，不携带原始格式和 PNG 注释。

文件仍保存路径。“读取本机文件信息”按需查看当前文件大小、修改时间和类型，不读取文档正文。文件状态不是复制时快照。原格式可能含来源、注释和 EXIF；主动另存的文件没有加密，须自行管理。

v0.13 引入数据库/备份版本 4；当前 v0.18 为版本 6，0.17 及更旧程序拒绝打开新库。首次使用前可用旧版导出备份。旧设备继续同步兼容内容，新格式等待另一端升级至 0.13；不会静默丢弃原始表示。原始数据和预览共同计入单项 16 MiB 与总 256 MiB 限制。未知应用私有格式和全部来源应用兼容性仍待扩展；虚拟附件见 v0.14。

## v0.12 窗口截图与图片编辑

截图对话框选择“独立窗口”，刷新列表后点选缩略图，再开始截图。Clipper 自身和最小化窗口不会列出。窗口选择有效期两分钟；关闭、最小化或名称变化需刷新。输出来自目标窗口，最长边 2,560 像素、约 400 万像素上限；受保护或特殊渲染的应用可能无法捕获。

在图片详情点击“编辑图片”，支持裁剪、右转 90°、水平翻转、画笔、矩形、箭头、文字与实色遮盖。预览可适应窗口或选择比例；修改按原图像素输出。Ctrl+Z 撤销，Ctrl+Y 重做，Ctrl+S 保存副本，Esc 取消裁剪选区。最多 100 步，单笔 1,000 个点、共 20,000 个点；编辑图片最多 1,600 万像素、单边 16,384 像素。

“保存副本”保留原图并加入历史，继承标签和仅本机标记，不自动发布共享；与已有图片相同的结果按历史去重。如果仅本机原图的结果与已共享图片相同，先要求将已有记录设为仅本机。复制结果不会自动保存修改，另存 PNG 只写新文件名。未保存修改只在内存，关闭时确认，锁定或休眠清除；原记录被删除或更改后不能提交。详见《图片工作台设计》及《验收-0.12》。

## v0.11 区域录制与长截图

区域录制：打开“录制”，在“屏幕”中选择显示器，点击“选定录制区域”，拖动框选并确认，再点击开始。可恢复整屏或重新选择；区域画面在编码前裁剪，输出偶数尺寸，沿用暂停、系统声音/麦克风及 MP4 导出。显示器位置、缩放、旋转或媒体尺寸变化时停止，需重新选区。Windows 授权范围仍是整个显示器，只有选区画面进入录制文件。

长截图：点击“截图 → 滚动长截图”，选择显示器并框选滚动正文，避开固定标题和滚动条。首屏捕获后在目标应用向下滚动，保留至少约 20% 重叠，再点击“追加一屏”；识别成功后自动拼接，未变化画面不重复添加。可撤销最近一次追加。快速跳页、反向滚动、重复图案或动态内容可能需要手动对齐；对照两屏、调整重叠像素并检查接缝预览，确认后才追加。

完成后查看整张长图，主动另存 PNG，或“加入历史并复制”。最多 30 屏、2,400 万总像素、最长边 16,384、单屏 1,200 万像素、会话 15 分钟；历史仍受单项约 16 MiB 限制，大图可另存文件。截图只留内存，退出、锁定和休眠会清除；主动导出的 PNG 为明文，强制终止导出可能在目标目录留下 .Clipper-image-*.part。数据迁移前须先保存或放弃。不同显示器之间不能拼接，显示器变化会停止并保留已完成结果。

已验证当前机器真实区域视频和滚动画面拼接，物理混合 DPI、多屏热插拔、真实休眠和复杂页面兼容性仍待补充。此版不自动滚动其他应用，滚动由用户控制；不要把有意跳过的正文当作已捕获内容。

## v0.10 录屏与录音

在主窗口点击“录制”，或从托盘打开“录屏与录音”。选择屏幕或窗口，分别勾选系统声音、麦克风；声音默认关闭。仅录音模式必须选择至少一种声音来源。系统声音会包含电脑播放的所有声音，麦克风权限和设备不可用时明确报错。

点击开始后显示小型控制窗口，可暂停、继续、停止。停止后播放和拖动预览，再另存为新文件名：录像为 H.264/AAC MP4，录音为 AAC M4A，不覆盖已有文件。保存后点击“复制文件”才写入文件剪贴板并加入历史；文件本体不进入历史数据库、备份或同步。

支持 15/30/60 fps，最长边 1920/2560 像素；实际帧率由硬件和来源决定。单次最多 60 分钟或约 1 GiB，先达到上限时停止；整个会话（含暂停）超过 2 小时也停止。未保存内容加密暂存，锁定、休眠和正常退出会清除；异常退出后无法恢复，重启会清理遗留加密片段。退出或关闭前对未保存内容确认，数据迁移和加密转换需先保存或放弃录制。导出的媒体文件没有加密。

已验收真实窗口画面变化、屏幕捕获、系统声音和 MP4/M4A 解码；麦克风及混音采用受控测试输入，真人麦克风、多显示器和长时间满容量仍待补充。区域录制与长截图见 v0.11；0.27 已增加 WebM/VP9、WebM/Opus 与 WAV 导出；真实录制设备边界仍保留。

## v0.9 划词菜单

先在其他应用中选中文字，再按 Ctrl+Alt+X。用 Tab、左右键和 Enter 选择复制、保存、翻译、总结或脚本，Esc 关闭。在“设置 → 划词菜单 → 配置”可开启鼠标选中后自动显示；默认关闭，开启后不会抢原应用焦点。可调整等待时间、快捷键和忽略的应用，也沿用剪贴板的排除规则。

读取选区不发送 Ctrl+C，不改写剪贴板，不自动保存历史或联网。点击复制才写入剪贴板；点击保存才加入历史。翻译、总结、脚本打开现有预览窗口，由你点击开始后执行，结果不会直接替换外部文字。暂停记录时停止自动菜单，主动快捷键仍可用。

只读取 Windows UI Automation 提供的选区，最多 32,768 个字符。密码控件会跳过；不提供选区接口的应用可先复制，再使用历史中的文本工具。输入、切换应用、关闭或 30 秒未操作后菜单失效；执行前重新确认选区。截图、迁移、锁定及系统休眠停止读取，解锁不恢复旧选区。此功能依赖系统 .NET Framework 4.x 桌面组件。

已实测当前 Chromium 的普通文字/输入框和 Windows 原生 RichTextBox；不承诺所有浏览器、Word、PDF、终端或管理员窗口兼容。敏感字段仍建议加入排除应用，不能仅凭密码控件标记保证识别所有敏感文字。

## v0.8 桌面交互

在“设置 → 桌面交互 → 配置”开启边缘停靠，选择左、右、上、下及显示器。默认跟随鼠标所在屏幕，停留 450 毫秒呼出；共享的显示器边界和四角不触发。悬停展开保留原应用焦点，点击后可搜索；关闭后离开触发区才会再次打开。全屏应用、截图、录入快捷键和历史锁定期间暂停自动触发。

卡片视图旁可选纵向、横向或网格。横向用滚轮或方向键浏览；网格按实际列数移动。搜索框中的左右键仍用于移动光标，内容刷新时保留滚动位置。

在“拖拽容器 → 浮动窗口”、托盘或 Ctrl+Shift+D 打开独立窗口，可置顶、移动、调整大小。拖入文字或文件，点击复制、双击粘贴；图片和文件可拖到其他应用。移出容器保留历史和原文件。顶部入口需单独开启：按住左键到工作区顶部中央停留，会在不抢焦点的情况下呼出窗口，继续拖入窗口后松开。普通按住左键也可能呼出，只有实际拖入才新增内容。

浮窗与主窗口共用容器，最多 200 项；文件仍只引用原路径。关闭浮窗保留内容，锁定会销毁窗口；解锁不会自动显示之前的浮窗。完整资料迁移保留桌面设置，备份不携带本机显示器和窗口位置。

## v0.7 历史保护

在“数据与备份 → 历史保护”设置至少 12 字符的密码，保存并填写独立恢复密钥，然后生成加密副本。确认可解锁后点击“清理原明文副本”。清理只删除原数据库和日志，已有导出文件仍由你管理。

支持手动锁定、锁屏/休眠事件锁定和系统空闲自动锁定。锁定后停止记录和共享，销毁历史窗口并关闭数据库；用密码或恢复密钥重新打开。恢复密钥解锁要求更改密码。不要同时丢失密码与恢复密钥。Windows 剪贴板不清空，已导出的内容不会撤回。

Windows Hello 是可选的本机快捷验证，使用当前 Windows 账户 DPAPI 保存凭据；不是 TPM 绑定的数据加密。可用性已实测，真人 PIN/生物识别验收待补充。历史加密不覆盖系统内存、交换/休眠文件、外部源文件和主动导出。完整边界见《历史加密设计》。

搬移完整加密资料时，必须同时保留数据库与 `history-vault.json`；使用应用迁移入口以保证一致性。v0.6 及更旧程序不能直接打开加密库。

## 数据与边界

历史、模板和设置默认位于 `%APPDATA%\Clipper\history.sqlite`，可在“数据与备份”迁移；当前路径由默认目录的 `storage-location.json` 记录。运行中同时存在 SQLite WAL 文件，迁移或备份请使用应用入口。历史数据库默认未加密，可在“历史保护”主动加密；JSON 备份仍是明文，`.clipper` 备份使用独立密码加密。剪贴板核心不发送网络请求；AI 仅在主动查询模型或发送本次文字时访问已配置服务。

首次启动不采集已在剪贴板中的内容，只记录后续变化。默认 1,000 条普通历史、30 天；收藏、置顶、堆栈和拖拽容器内容不自动删除。总内容预算 256 MiB，文字最多 1 MiB，单项序列化内容最多 16 MiB，PNG 最多 4,000 万像素且单边不超过 16,384，文件最多 256 个路径，堆栈最多 200 项。PNG 以 Base64 存储，因此可接受的原始 PNG 文件略小于 16 MiB。所有模板也计入容量限制。

普通文件引用保存路径，不备份文件本体；源文件移动/删除后不能继续粘贴。OLE 虚拟附件/目录则保存来源提供的内容，来源退出后仍可复用；Outlook 等实际应用兼容性仍待验证。剪切文件的历史回放按复制处理，不触发文件移动。图片回放同时提供支持的原始格式和可生成的 PNG/位图表示；0.27 已保留原始 DIB/DIBV5 色彩数据和可持久化应用注册格式；活跃 OLE/COM 对象及部分私有句柄仍不持久化，实际来源应用回放需继续验证。

约 350 ms 检查 Windows 剪贴板序列，极快连续复制可能只记录最终状态。进程排除基于剪贴板所有者，不保证识别代理进程、所有密码框或全部敏感数据；可从托盘主动暂停。禁止历史标记和默认密码管理器排除已接入。

自动粘贴可能被管理员应用、特殊输入控件或焦点限制阻止，遇到失败会提示手动 Ctrl+V。成功发出按键事件不代表目标应用已确认插入。自动粘贴与普通复制都会保留所选内容在系统剪贴板。编辑文字后转为纯文本。删除撤销仅限当前运行会话内最近一次历史删除/清除，不恢复堆栈和拖拽容器位置；快捷回复删除需要确认且不能撤销。

保留策略在启动、捕获新记录与保存设置时执行。导入会完整合并备份，下一次保留策略执行时按当前本机设置清理普通记录。自动清理不提供撤销；可先收藏或备份重要内容。

## v0.2 使用说明

在内容预览中点击“保存为快捷回复”图标即可保存文字、图片或文件；在“快捷回复”中新增文字可写 {{姓名}} 这样的填写项。图片随模板保存；文件模板只保留路径。使用变量模板时先填写再复制或粘贴，填写内容按原样插入，不递归执行其他变量。

侧栏“自定义分类”的 + 可设置规则。已填写的条件须同时满足；分类只组织视图，不搬动或复制原记录。顶部勾选按钮进入批量选择，最多一次处理 500 条；堆栈和拖拽容器各最多 200 项。

向“拖拽容器”拖入本地文件；单张 PNG/JPEG/WebP/BMP/GIF 保存图片及可解码的静态预览，其他文件或多文件保留为路径组。自 v0.13 起同时保留支持的原始编码，拖出优先使用原格式（含 GIF 动画字节）；旧版已转换的记录无法恢复丢失信息。拖出图片生成本次运行的临时文件，退出或下次启动时清理；临时图片额外限制为 256 MiB。原文件不会移动或删除。

选中图片后点击“识别文字”图标。OCR 使用 Windows 已安装的语言组件，不下载模型、不上传图片；缺少语言时有提示。结果可以修改，点击“保存文字”才新增到历史；关闭识别窗口会取消当前任务。识别准确率受语言包和图片质量影响。

顶部“截图”可选择整屏或区域。Clipper 隐藏后捕获选定显示器；区域界面基于冻结画面，鼠标拖出选区，尺寸显示实际输出像素。Esc 取消不新增记录。受系统保护的视频窗口可能显示黑色，截图采用系统显示捕获结果，未承诺 HDR 色彩精度。

v0.2 会升级本地数据库版本；升级前建议从 v0.1 导出备份。v0.2 可合并导入 v0.1/v0.2 备份；旧版不支持读取升级后的数据库。备份包含历史、图片/文件模板和分类规则，不恢复堆栈/容器顺序，也不覆盖本机设置。

## v0.3 文本工具

先在侧栏“文本工具”添加服务。Ollama 默认地址为 `http://127.0.0.1:11434`，LM Studio 为 `http://127.0.0.1:1234/v1`；需自行启动相应模型服务并安装/加载模型。在线服务填写兼容聊天接口的基础地址、模型和密钥，通常以 `/v1` 结尾。远程服务要求 HTTPS，不跟随重定向。可从模型列表选择，也可手动填写模型名称。

从文字详情点击“翻译”或“总结”，在处理窗口切换改写/自定义指令。左右对照输入与结果；点击“开始处理”才发送文字。在线兼容服务还需勾选发送确认。处理完成后可编辑结果，再复制、另存或替换原记录；不会自动覆盖。替换会转为纯文本，期间原记录被编辑则拒绝覆盖。图片 OCR 完成后可点击“翻译文字”，只将可编辑的识别文字带入预览，图片不发送给模型。

服务支持输出 token 上限、等待时间、可选温度，以及 `max_tokens` / `max_completion_tokens`。接口差异仍可能导致服务拒绝参数；不自动重试计费请求。模型的实际运行位置、计费、数据保留和输出质量由所连接服务决定。当前只支持非流式聊天文本接口，不执行模型工具调用。输入最多 256 KiB，输出最多 1 MiB，最多两个并发请求。

API 密钥通过 Windows DPAPI 加密保存，界面只能读取“是否已保存”。改变服务地址时需重新填写或清除旧密钥。历史导出不包含服务配置与密钥；更换设备后需重新配置。此保护不等于历史数据库加密，也不隔离同一 Windows 用户下的其他程序。

文字详情的“脚本”可运行预置或自建转换。脚本使用 `input` 字符串与 `return`，不提供 Node、文件、网络或剪贴板接口；每次在独立工作进程中的 QuickJS 运行时执行。限制脚本堆内存 32 MiB、调用栈 512 KiB、运行 100–5,000 毫秒、输出 1 MiB。编辑代码后旧预览失效。脚本可单独导入/导出，导入不执行；v0.4 的历史备份也包含脚本。

URL 入口默认关闭，可在文本工具中启用。支持 `clipper-win://open`、`clipper-win://search?q=关键词`、`clipper-win://add?text=文字`、`clipper-win://copy?text=文字`；文本请使用 URL 编码。打开和搜索直接切换界面，新增和复制先确认。入口不支持命令、文件、脚本执行或自动粘贴。移动解压目录前先停用入口，在新位置运行后再启用。

本版已验证协议与实际 Windows 集成；尚未在真实 Ollama / LM Studio 模型或付费模型上验证推理质量。详细测试范围见 [v0.3 验收](docs/验收-0.3.md)。

## v0.5 局域网同步

两台电脑安装 Clipper 0.5，在“局域网同步”中填写名称并启用。此功能默认关闭；Windows 防火墙需允许专用网络中的 Clipper，应用不会自动添加防火墙规则。

1. 一台电脑选本机局域网地址并生成配对码，交给另一台电脑。配对码五分钟有效、仅用一次，不要交给不信任的人。
2. 另一台粘贴配对码并请求配对，原电脑核对名称后点击“允许配对”。附近发现只帮助查看设备，不会自动授权。
3. 在同步页或记录详情点击“共享此条”；也可单独勾选自动同步以后新复制的文字和图片。原有历史不自动发送。
4. 接收到的内容进入历史，之后由你选择复制或粘贴。文本、HTML/RTF、PNG 可同步；文件条目、模板、设置、脚本、服务密钥和原文件不发送。
5. “仅本机”保留当前内容、撤回共享发布并阻止相同内容重新自动分享。撤销设备信任后不再同步，但已收到的内容仍保留。

共享记录受自动清理保护，手动删除会同步删除其已知发布。离线同时编辑保留双方新文字，不用某台电脑的时间覆盖另一台内容；同一发布的旧副本不能复活已删除内容。再次主动共享是新的发布。若接收内容与原有本机记录重复，远端删除保留本机原件及其收藏/标签。最多 8 台配对设备、20,000 条发布及删除标记；达到同步目录上限后仍保留本机资料，但停止新增共享，不能靠删除普通历史重置目录。

v0.5 引入 schema 3；当前资料使用 schema 7，较旧资料自动升级；旧版会拒绝直接打开，请勿降级使用。通信使用 TLS 1.3 和双向证书指纹核对，私钥通过 Windows DPAPI 保存；历史数据库可独立启用加密。使用 Clipper 独立协议，暂不与 OneClip 商业版互通。IPv4 私网及链路本地地址；不使用云中继；网页共享见下节。跨两台物理电脑及不同防火墙/路由器尚待补充验收。

## v0.6 网页共享

1. 在侧栏“网页共享”选择本机局域网地址和时长，点击“开启网页共享”。默认不共享任何历史，也不会自动恢复上次会话。
2. 在同一局域网的浏览器打开邀请链接。首次会遇到自签名证书提示：在浏览器的证书详情中核对 SHA-256，必须与桌面端显示的完整指纹一致，然后才继续访问；无法核对时不要继续。每次开启会话都会更换证书。应用不会修改系统信任或自动添加防火墙规则。
3. 浏览器填写名称并请求连接，电脑端核对双方的六位验证码后允许。默认只有接收权限；需要发送时，在这次确认中单独勾选发送权限。改变权限需断开后重新邀请。
4. 在电脑端逐项“加入共享”，或独立启用“持续共享之后新复制的文字与图片”。已批准的所有浏览器看到同一内容池。邀请链接五分钟有效，只能用一次；每个新浏览器需要新的邀请。
5. 浏览器点击内容后复制文字/PNG，或选中文字、另存 PNG。可发送时支持文字及 PNG/JPEG/WebP，图片转换为 PNG。新接收记录标为仅本机；不改写系统剪贴板，不自动转发。相同内容合并时保留已有本机记录的权限。

每次 5–120 分钟，界面提供 15、30、60、120 分钟；最多 4 个已授权浏览器、8 个待确认请求、100 项共享内容。发送每浏览器每分钟最多 10 次；文字 1 MiB、单项序列化 16 MiB、PNG 4,000 万像素限制与本机一致。共享池满后停止自动加入新内容，撤回旧项后可继续。

编辑、删除、自动清理或设为仅本机会撤回网页内容；网页共享不为普通历史增加保留保护。结束、到期、锁屏、休眠、迁移或退出时关闭会话，重启后不恢复。浏览器令牌仅在当前页面内存，重载需要新邀请；短暂断线会重连，超过约 90 秒需重新邀请。已经复制或另存的副本无法撤回。

网页只发送纯文字和 PNG，不发送 HTML/RTF、文件路径、进程来源、设置或密钥，也不读取浏览器系统剪贴板。浏览器对剪贴板权限的限制不一，复制不可用时使用选中文字或另存图片。Edge/Chrome 桌面隔离测试通过；测试证书例外仅用于测试上下文，实际证书核对操作、手机浏览器及跨物理设备仍需验证。

## v0.4 数据与备份

在侧栏“数据与备份”查看当前目录。点击“迁移目录”，选择普通本机空文件夹，确认后生成并校验数据库副本，再立即切换。历史、模板、分类、堆栈、容器、脚本和本机服务配置一起保留；正在运行的 AI / 脚本会结束。原目录保留，新内容只写新目录；源文件不搬动。目录不可用或配置损坏时应用拒绝创建空历史，请恢复原目录/磁盘连接后重试。目前不支持网络共享路径或目录链接。

自动备份默认关闭。选择文件夹，设置 1–168 小时间隔和 1–100 份保留数量，保存后在一分钟内执行首份，也可点击“立即备份”。仅在应用运行时执行；重新打开或系统恢复后补做一份到期备份。失败显示原因，15 分钟后重试。新文件通过恢复校验后才清理过期自动备份；其他文件和手动导出不被清理。

可使用至少 12 字符的密码加密。自动备份密码由 Windows DPAPI 保存，手动导出密码不保存；请另外保管密码，忘记后无法恢复。更换密码只影响新备份，旧备份仍需旧密码。备份与历史数据库分别设置加密，两个密码相互独立。

点击“手动导出”可以选择加密或明文。“从文件恢复”支持 v1/v2/v3 JSON 和本版 `.clipper`；输入密码后先校验并展示历史、模板、分类和脚本数量，点击“合并恢复”才写入。重复内容去重，新写入的本机内容保留；失败整体回滚。备份不含 API 密钥、本机服务/系统设置、堆栈/容器顺序或源文件本体。旧版不支持 v3 备份；自定义目录迁移后不应降级到忽略位置配置的旧版。

若使用同一磁盘存放历史和备份，磁盘故障可能同时影响两者；可选择另一块本机磁盘，并另外保存需要长期保留的加密备份。v0.4.1 已将导出移至后台，备份期间仍可采集；迁移和导入仍会短暂占用资料处理流程。尚未完成满容量长期运行和真实断电测试。局域网同步已在 v0.5 实现；历史数据库加密及可选 Windows Hello 见 v0.7 说明。

### v0.4.1 启动故障恢复

资料目录断开、数据库损坏或位置配置无法读取时，Clipper 会打开恢复窗口，并暂停启动剪贴板记录。你可以重新连接磁盘后点击“重试原目录”，或选择已有 Clipper 资料目录、JSON 备份或加密备份。

先校验并查看记录数量，再点击“复制恢复并打开”。恢复会在默认用户目录中创建独立的 `recovered-*` 资料副本，保留原数据库与备份；旧位置配置另存为 `storage-location.before-recovery-*.json`。恢复副本暂时关闭自动记录和自动备份，检查内容后可在设置中重新启用。v0.5 起恢复会清除同步设备身份与信任，需要重新配对。已有目录恢复保留设置、堆栈和服务配置；从备份恢复的范围与备份格式一致，不包含服务密钥或源文件本体。

校验失败时不会覆盖原历史；来自较新数据库版本的资料需使用相应新版 Clipper。预览十分钟后过期，需重新选择。退出会等待已经开始的备份完成。

## 开发

需要 Windows x64、Node.js 22+、Rust stable、Visual Studio 2022 C++ x64 与 Windows SDK，以及 .NET Framework 4.x 和 WPF UI Automation 组件。请在 Visual Studio 的 x64 Native Tools Command Prompt 中执行构建命令，以完整加载编译器和 SDK 环境：

```powershell
npm ci
npm run start
npm run typecheck
npm test
npm run test:ui
npm run test:integration
npm run test:advanced
npm run test:capture
npm run test:drag
npm run test:text-tools
npm run test:data
npm run test:selection
npm run package
```

测试在 `work/` 下创建隔离用户目录；真实系统剪贴板用例结束后恢复原内容。测试前先从托盘退出日常 Clipper；测试期间暂时停用键鼠，不要并行运行另一组 UI 测试，以免抢占快捷键或剪贴板。发布包测试可设置 `CLIPPER_PACKAGED_EXE` 为 EXE 完整路径，再运行对应测试脚本。

先运行 `npm test` 生成测试用导出模块，再运行 `npm run test:tray` 检查托盘入口、面板、生命周期及真实拖出。

`npm run test:folders` 检查虚拟目录、真实拖放与目录生命周期，`npm run test:efficiency` 检查搜索历史、模板热键及原窗口粘贴，`npm run test:metadata` 检查内部信息及读取生命周期，`npm run test:attachments` 检查虚拟附件及生命周期，`npm run test:formats` 检查原始格式与导出边界；`node scripts/verify-packaged.mjs` 顺序检查当前发布包。升级保护用例还需在 `release/0.4.1/win-unpacked`、`release/0.12.0/win-unpacked`、`release/0.13.0/win-unpacked` 和 `release/0.17.0-final/win-unpacked` 放置对应旧版程序，用于验证真实旧版本拒绝读取新资料。旧版二进制不包含在源码 ZIP 中。

目录：`src/main` 系统与数据服务、`src/preload` 固定接口、`src/renderer` 页面、`src/shared` 模型校验、`tests` 自动化、`docs` 产品文档。

## 自动入栈与批量规则（0.17）

打开“堆栈”，在“堆栈规则”中选择类型、来源进程名、包含词和整条/按行模式。点击“开始自动入栈”后，符合条件的新复制内容会追加到队尾，默认按内容去重；0.27 可开启“保留重复副本”，每份独立排队和移出。点击停止或在托盘停止；暂停记录、锁定、休眠、迁移和退出也会结束本次收集，恢复后需重新开始。

“批量入栈”先预览已有历史，选择由旧到新或由新到旧，确认后追加。“反转顺序”调整全部队列；清空只移出队列，保留历史。按行拆分生成纯文本并跳过空行；队列最多 200 项，超限整批拒绝。规则仅存本机，不进入普通备份/同步。粘贴继续使用 Ctrl+Alt+N（可修改），普通 Ctrl+V 行为保持。
